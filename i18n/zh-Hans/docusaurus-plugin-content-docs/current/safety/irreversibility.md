# 删除是永久的

**linux-cleanup 调用的是 `rm -rf`。没有撤销，没有回收站目录，没有快照，也没有备份步骤。**
路径一旦被删除，这个工具就无法把它找回来，您传给它的任何参数也不能。

:::danger 第一次执行删除前请阅读
- 被删除的文件**不会**进入回收站。
- 没有 `--undo`，没有恢复命令，也没有在任何地方保留隐藏副本。
- 本地日志可以帮您回溯一次运行；引导流程的记录会汇总它的步骤。两者都不是逐个文件的备份。
- 如果某个文件无可替代而您又没有备份，它就没有了。

这个工具的安全完全来自一开始就[拒绝删除错误的东西](./guards.md)。
:::

## “可再生成”到底承诺了什么

这个工具删除的大部分内容都被描述为可再生成。这个词的含义很精确，值得说清楚它意味着什么、不意味着什么。

| 它意味着 | 它不意味着 |
|---|---|
| *另一个*程序可以重新生成这些数据 | linux-cleanup 能重新生成它 |
| 下一次 `yarn install` 会重新下载软件包 | 这些字节仍在您磁盘的某处 |
| 浏览器会在您浏览时重建缓存 | 删除是可逆的 |
| 重新生成可能需要网络、时间或两者 | 重新生成是免费或即时的 |

Playwright 的浏览器包是可再生成的——但重新下载要花几分钟和几百兆字节的流量。离线的机器根本无法重新生成。“可再生成”说的是数据可以从哪里来，而不是取回它有多方便。

## 真正无可替代的类别

有三类目标可能包含无法再生成的数据。三者都是[仅限交互式](./guards.md#guard-3--personal-data-is-interactive-only)，在回答提示时都值得认真对待。

| 目标 | 为什么没有任何办法能找回 |
|---|---|
| `~/Downloads` 或已配置的未受保护根目录中的**个人文件** | 没有可重新获取的来源。如果那是唯一的副本，它就是唯一的副本。 |
| **未完成的下载**（`.crdownload`、`.part`……） | 只有原来的浏览器会话才能续传，而那通常早已结束。 |
| **长期未用的 `node_modules` 中未提交的修改** | 很少见，但您就地修改过的依赖不在任何仓库里。 |

第一类才是真正让人丢数据的。`~/Downloads` 不是受保护路径——它*不可能*是，因为清理它是核心功能——所以挡在那里的文件和删除之间的，只有您对候选列表的阅读。

## 为什么没有撤销

设计理由，直说如下：

1. **撤销日志会在您想腾出空间的磁盘上放大写入。** 为了回收 20 GB 而保留 20 GB，什么也没得到。
2. **它会制造虚假的安心感。** 看起来可逆的工具会招致粗心使用，而可逆性充其量也只是部分的——能恢复 90% 情况的撤销，在另外 10% 中最危险。
3. **预防比恢复更值得投入。** [白名单](./guards.md#guard-1--the-path-allowlist)、[闲置阈值关卡](./guards.md#guard-2--the-staleness-gate)和交互确认会阻止错误的删除发生，这严格优于事后撤销。

对缓存来说，这是合理的取舍。在把这个工具指向 `~/Downloads` 之前，您应该理解这个取舍。

## 事后您真正拥有什么

如果某次删除让您意外，请查看可用的本地记录。两者都不是备份。

| 产物 | 位置 | 内容 |
|---|---|---|
| 会话日志 | `~/.linux-cleanup/logs/cleanup-<timestamp>.log` | 本次运行的可读输出，除非日志已被删除 |
| JSON 报告 | `~/.linux-cleanup/reports/report-<timestamp>.json` | 引导流程的步骤摘要，除非关闭了报告 |

它们可以帮您确认所用的模式和所选目标，但不会列出每个被删除的文件，也不包含任何被删除的内容。

完整步骤：[恢复](../recovery.md)。

## 运行前降低风险

```bash
# 1. 确认防护在这次安装中有效
npx linux-cleanup --self-test

# 2. 看看能回收多少——不删除任何内容
npx linux-cleanup --scan

# 3. 运行引导流程，对任何没把握的项回答 'n'
npx linux-cleanup
```

此外：

- **为任何无可替代的东西做好备份。** 无论用不用这个工具都是如此；只有备份能让删除变得可恢复。
- **不要把个人文件模式用在您没有检查过的机器上。** 先运行 `--scan`。
- **把 `--all-safe -y` 留给您已经信任的机器上的缓存。** 它碰不到个人文件，但在结束之前也什么都不给您看。
- **把 `--purge-all` 当作重装系统前的工具**，而不是日常使用。

:::tip 值得养成的一个习惯
每次在 `--all-safe` 之前都先运行 `--scan`。它只花一分钟，而且是唯一一个在结果还只是假设时就让您看到它的步骤。
:::
