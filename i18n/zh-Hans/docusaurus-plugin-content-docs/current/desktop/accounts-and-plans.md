# 账户与套餐

每个套餐都有完整的全安全清理、不限次数的试运行，以及相同的受保护列表。不同的是实际运行的次数和围绕它的附加功能。

| | 免费 | Pro | Team |
|---|---|---|---|
| 实际运行 | 每台电脑每月 15 次，登录后再加 15 次 | 没有每月限制 | 没有每月限制，每个席位都是 |
| 同步的清理回执（仅数字） | 否 | 最多 5 台电脑 | 每个席位最多 5 台电脑 |
| 计划 | 否 | 是 | 是 |
| 导出 | 否 | 是 | 是 |
| 团队报告 | 否 | 否 | 是 |

价格和限额设在应用和网站都读取的套餐记录中；[价格页面](https://linux-cleanup.aoneahsan.com/pricing)显示当前的数字。

只能用 Google 登录。登录会增加实际运行次数、在您的各台电脑之间保留清理回执，并保存您的套餐。在 **账户** 中删除账户，会从我们的服务器上删除您的账户和同步的数字；您电脑上的清理回执、日志和报告保持原样。
