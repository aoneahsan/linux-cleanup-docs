# 速度诊断

**`--speed` 会报告机器把时间花在了哪里。** 它读取温度计数器、CPU、内存和 I/O 压力、占用高的进程以及启动信息，还能找出自行启动的容器、服务和登录应用。

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

试运行会报告它将询问的更改，但不会应用。正常运行在每项拟议更改前都会单独询问，默认回答是“否”。`--yes` 不会授权这些修复。

部分被接受的修复会停止容器、禁用服务或更改用户登录设置。它们不会删除缓存文件，但会影响下次启动时运行的内容。应用更改后，命令行会打印一条撤销命令。更改系统服务时可能会出现 sudo 提示。

一项发现只是一个测量结果或一种状态，并不能证明某个应用有问题。接受更改之前，请看清所指的进程或服务，并判断您是否需要它。

shell 启动中缺少运行时命令时，请使用单独的[诊断](./doctor.md)模式。要处理磁盘空间，请先做一次[扫描](./scan.md)。
