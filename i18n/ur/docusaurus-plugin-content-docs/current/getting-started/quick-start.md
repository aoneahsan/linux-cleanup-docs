# فوری آغاز

**حذف سے پہلے حفاظتی رکاوٹیں جانچیں، اسکین دیکھیں اور چنے ہوئے موڈ کا پری ویو کریں۔** کتنی جگہ واپس ملے گی، یہ اس مشین کے پاتھس اور فائلوں پر منحصر ہے۔

:::caution مرحلہ 1 اور 2 نہ چھوڑیں
ان میں دو منٹ لگتے ہیں، اور یہی فرق ہے اس صفائی میں جو آپ کے قابو میں تھی اور اس میں جس کا پتا بعد میں چلا۔ یہ ٹول [مستقل طور پر حذف کرتا ہے](../safety/irreversibility.md)۔
:::

## مرحلہ 1 — انسٹال جانچیں {#step-1--verify-the-install}

```bash
npx linux-cleanup --version
npx linux-cleanup --self-test
```

`--version` بتاتا ہے کہ آپ کے پاس کون سا بلڈ ہے۔ `--self-test` انحصارات اور شیل سنٹیکس جانچتا ہے اور تصدیق کرتا ہے کہ حفاظتی رکاوٹیں واقعی چلتی ہیں۔ کامیاب رن کامیابی کے پیغام پر ختم ہوتا ہے؛ کوئی بھی تصدیق ناکام ہو تو غیر صفر کوڈ آتا ہے اور آپ کو وہیں رک جانا چاہیے۔

## مرحلہ 2 — جانچ، کچھ بھی حذف کیے بغیر {#step-2--audit-deleting-nothing}

```bash
npx linux-cleanup --scan
```

`--scan` صرف پڑھتا ہے۔ یہ کیش کی جڑیں اور ان کا موجودہ سائز، ساتھ میں دوسرے امیدوار اور سسٹم کے مشاہدات دکھاتا ہے۔ یہ نہ کچھ حذف کرتا ہے نہ JSON سیشن رپورٹ لکھتا ہے۔

آگے بڑھنے سے پہلے پاتھس پڑھیں۔ کسی کیش جڑ کا سائز یہ دعویٰ نہیں کہ پورا فولڈر حذف کے لائق ہے۔ ہر غیر متوقع پاتھ اور ہر ذاتی فائل کے امیدوار کو الگ سے جانچیں۔

## مرحلہ 3 — صفائی کا پری ویو {#step-3--preview-the-cleanup}

```bash
npx linux-cleanup --all-safe --dry-run
```

یہ فائلیں حذف کیے یا سیٹنگز بدلے بغیر مکمل محفوظ کیش موڈ سے گزرتا ہے۔ مجوزہ کام پڑھیں، پھر طے کریں کہ چلانا ہے یا نہیں۔ اصل حذف کی کوئی واپسی نہیں۔

## مرحلہ 4 — گائیڈڈ واک تھرو چلائیں {#step-4--run-the-guided-walkthrough}

```bash
npx linux-cleanup
```

بغیر فلیگ کا مطلب ہے [گائیڈڈ واک تھرو](../modes/walkthrough.md): دس مراحل، ہر مرحلہ کچھ کرنے سے پہلے پوچھتا ہے، اور واپس ملے بائٹس کا جاری مجموعہ دکھاتا ہے۔

ہر مرحلے پر آپ کے پاس تین انتخاب ہیں:

| کلید | اثر |
|---|---|
| `a` | یہ مرحلہ چلائیں (ڈیفالٹ — Enter دبانے سے یہی چنا جاتا ہے) |
| `s` | یہ مرحلہ چھوڑیں |
| `q` | واک تھرو ابھی بند کریں |

مرحلے کے اندر ہر ہدف کی اپنی `[Y/n]` تصدیق ہوتی ہے۔ یعنی دو سطحیں ہیں: پورا زمرہ چھوڑ دیں، یا زمرہ قبول کر کے مخصوص چیزوں سے انکار کریں۔

دس مراحل، ترتیب سے:

1. پیکیج مینیجر کیش
2. ایپلیکیشن کیش
3. ڈویلپر ٹولز کا ڈیٹا
4. ایڈیٹر کی پرانی ایکسٹینشنز
5. پرانے `node_modules`
6. ادھورے / لاوارث ڈاؤن لوڈز
7. پرانی ذاتی فائلیں
8. سسٹم کی صفائی (sudo)
9. آخری سائز کی جانچ
10. پڑھنے لائق رپورٹ بنانا

:::tip مرحلہ 6 اور 7 پر آہستہ چلیں
ان سے پہلے کا سب کچھ دوبارہ بن سکتا ہے۔ ادھورے ڈاؤن لوڈز اور پرانی ذاتی فائلیں نہیں — پورا گروپ قبول کرنے کے بجائے ہر امیدوار پڑھیں۔ اگر آپ انہیں بعد میں الگ سے دیکھنا چاہیں تو پہلے رن میں دونوں کو `s` سے چھوڑ دیں۔
:::

`Ctrl-C` واک تھرو کو کوڈ `130` کے ساتھ روکتا ہے۔ اس سے پہلے ہونے والا حذف مستقل ہی رہتا ہے۔ رکنے سے پہلے کون سے مراحل چلے، یہ لاگ میں دیکھیں۔

## مرحلہ 5 — رپورٹ پڑھیں {#step-5--read-the-report}

سیشن ایک خلاصے پر ختم ہوتا ہے جس میں اس کے لاگ کا اور، اگر بنی ہو تو، رپورٹ کا پاتھ ہوتا ہے۔ ہر انسٹال طریقے کے لیے ایک مقررہ جگہ فرض کرنے کے بجائے اپنے رن میں دکھائے گئے پاتھس پڑھیں۔

گائیڈڈ واک تھرو JSON رپورٹ لکھتا ہے، جب تک آپ `--no-report` یا `--dry-run` نہ دیں۔ موجودہ رپورٹ کو پڑھنے یا محفوظ کرنے کے لیے بدلنے کو `jq` انسٹال کریں اور چلائیں:

```bash
linux-cleanup --export both latest   # JSON کے ساتھ Markdown اور HTML
linux-cleanup --reports              # انٹرایکٹو رپورٹس مینیجر
```

دیکھیں [رپورٹس](../modes/reports.md)۔

## مرحلہ 6 — بھروسا ہو جائے تو خودکار بنائیں {#step-6--automate-it-once-you-trust-it}

صرف ایک ایسے دستی رن کے بعد جس سے آپ مطمئن ہوں:

```bash
linux-cleanup --install-alias   # کہیں سے بھی `cleanup` ٹائپ کریں
linux-cleanup --install-cron    # ہر اتوار 03:00 بجے --all-safe -y
```

cron جاب `--all-safe -y` چلاتی ہے، جو **صرف دوبارہ بن سکنے والے کیش** کی خود بخود تصدیق کرتا ہے۔ یہ ذاتی فائلیں نہیں چھو سکتی — [وہ موڈز `--yes` کو نظرانداز کرتے ہیں](../safety/guards.md#guard-3--personal-data-is-interactive-only)۔

ہر ایک ٹھیک ٹھیک کیا لکھتا ہے اور اسے کیسے ہٹائیں، اس کے لیے [ایلیاس اور cron](../guides/alias-and-cron.md) دیکھیں۔
