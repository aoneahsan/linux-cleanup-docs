# ہوم کی جانچ

**`--audit`، `$HOME` کی 20 سب سے بڑی چیزیں سائز کی ترتیب سے دکھاتا ہے۔** یہ کچھ حذف نہیں کرتا، اور اسے اس سے غرض نہیں کہ ٹول جو ملا اسے صاف کر سکتا ہے یا نہیں۔

```bash
linux-cleanup --audit
```

## یہ `--scan` سے کیسے مختلف ہے {#why-this-is-different-from---scan}

[`--scan`](./scan.md) ان زمروں کو ناپتا ہے جنہیں linux-cleanup صاف کرنا جانتا ہے۔ `--audit` آپ کا ہوم فولڈر ناپتا ہے، بس۔

یہی فرق اصل بات ہے۔ اگر آپ کی ڈسک اصل میں 60 GB کی VM امیج، ڈاؤن لوڈ کیے گئے ڈیٹا سیٹ یا Steam لائبریری سے بھری ہے، تو `--scan` اس کا ذکر کبھی نہیں کرے گا اور `--audit` اسے فہرست میں سب سے اوپر رکھے گا۔

| | `--audit` | `--scan` |
|---|---|---|
| دائرہ | `$HOME` میں سب کچھ | صرف صاف ہونے لائق زمرے |
| جواب دیتا ہے | میری ڈسک کس نے بھری؟ | یہ ٹول کیا واپس دلا سکتا ہے؟ |
| JSON سیشن رپورٹ لکھتا ہے | نہیں | نہیں |
| حذف کرتا ہے | کبھی نہیں | کبھی نہیں |

## عام طریقہ {#the-usual-workflow}

```bash
linux-cleanup --audit    # بڑا کیا ہے؟
linux-cleanup --scan     # یہ ٹول کیا واپس دلا سکتا ہے؟
```

اگر جانچ کی سب سے اوپر کی چیزیں اسکین میں نظر آئیں تو ٹول مدد کر سکتا ہے۔ اگر نہیں، تو آپ نے کچھ زیادہ کام کا جان لیا — جگہ ایسی جگہ ہے جہاں یہ ٹول نہیں جاتا، اور آپ اسے براہ راست سنبھال سکتے ہیں۔

عام بڑی چیزیں جنہیں linux-cleanup صاف **نہیں** کرے گا:

- VM امیجز اور کنٹینر اسٹوریج (`~/.local/share/libvirt`، `~/.local/share/docker`)
- گیم لائبریریاں (Steam، Lutris)
- ڈیٹا سیٹس، ماڈل ویٹس، میڈیا لائبریریاں
- `~/Documents`، `~/Pictures`، `~/Music`، `~/Videos` میں کچھ بھی — سب [محفوظ](../reference/protected-paths.md)

## کسی نتیجے کے پیچھے جانا {#following-up-on-a-finding}

```bash
du -sh ~/.local/share/*      | sort -rh | head -20
du -sh ~/*                   | sort -rh | head -20
```

`--audit` تیز پہلی نظر ہے؛ کہاں دیکھنا ہے پتا چل جائے تو `du` دائرہ چھوٹا کرتا ہے۔
