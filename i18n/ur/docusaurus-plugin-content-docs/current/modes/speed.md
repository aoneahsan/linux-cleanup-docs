# رفتار کی تشخیص

**`--speed` بتاتا ہے کہ مشین اپنا وقت کہاں لگا رہی ہے۔** یہ درجہ حرارت کے کاؤنٹر، CPU، میموری اور I/O کا دباؤ، بھاری عمل اور بوٹ کی معلومات پڑھتا ہے۔ یہ خود بخود شروع ہونے والے کنٹینرز، سروسز اور لاگ اِن ایپس بھی ڈھونڈ سکتا ہے۔

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

آزمائشی رن وہ تبدیلیاں بتاتا ہے جن کے بارے میں وہ پوچھتا، مگر لاگو نہیں کرتا۔ عام رن ہر مجوزہ تبدیلی سے پہلے الگ سے پوچھتا ہے؛ ڈیفالٹ جواب نہیں ہے۔ `--yes` ان اصلاحات کی اجازت نہیں دیتا۔

کچھ قبول شدہ اصلاحات کسی کنٹینر کو روکتی ہیں، سروس بند کرتی ہیں یا صارف کی لاگ اِن سیٹنگ بدلتی ہیں۔ یہ کیش فائلیں حذف نہیں کرتیں، مگر اگلی بار کیا شروع ہوگا اس پر اثر ڈالتی ہیں۔ تبدیلی لاگو ہونے کے بعد CLI واپسی کا ایک کمانڈ دکھاتا ہے۔ سسٹم سروس کی تبدیلی پر sudo کا سوال آ سکتا ہے۔

کوئی نتیجہ ایک پیمائش یا حالت ہے، اس بات کا ثبوت نہیں کہ کوئی خاص ایپ خراب ہے۔ تبدیلی قبول کرنے سے پہلے بتایا گیا عمل یا سروس پڑھیں اور طے کریں کہ آپ کو اس کی ضرورت ہے یا نہیں۔

شیل کے آغاز میں غائب رن ٹائم کمانڈز کے لیے الگ [ڈاکٹر](./doctor.md) موڈ استعمال کریں۔ ڈسک کی جگہ کے لیے [اسکین](./scan.md) سے شروع کریں۔
