# واک تھرو (ڈیفالٹ)

**بغیر فلیگ `linux-cleanup` چلانے سے گائیڈڈ واک تھرو شروع ہوتا ہے: ہر صفائی زمرے سے گزرتے دس مراحل، ہر ایک کچھ کرنے سے پہلے پوچھتا ہے۔** ٹول کو انٹرایکٹو طور پر استعمال کرنے کا یہی تجویز کردہ طریقہ ہے۔

```bash
linux-cleanup          # یا: linux-cleanup -w / --walkthrough
```

## دس مراحل {#the-ten-steps}

| # | مرحلہ | کیا حذف کرتا ہے | نوٹس |
|---|---|---|---|
| 1 | پیکیج مینیجر کیش | دوبارہ بن سکنے والا | yarn، npm، npx، pnpm، pip، composer، bun، deno |
| 2 | ایپلیکیشن کیش | دوبارہ بن سکنے والا | براؤزرز، Gradle، Cypress، Playwright، Zoom، ایڈیٹر VSIX |
| 3 | ڈویلپر ٹولز کا ڈیٹا | صرف پرانا | Android AVDs، pub-cache، Dart analysis، flatpak |
| 4 | ایڈیٹر کی پرانی ایکسٹینشنز | پرانا + نئے سے بدلا | VS Code / Cursor |
| 5 | پرانے `node_modules` | **انٹرایکٹو** | حد سے زیادہ غیر استعمال شدہ پروجیکٹس |
| 6 | ادھورے / لاوارث ڈاؤن لوڈز | **انٹرایکٹو** | `.crdownload`، `.part`، `.fdmdownload` |
| 7 | پرانی ذاتی فائلیں | **انٹرایکٹو** | `~/Downloads` اور آپ کے مقرر کردہ ذاتی روٹس میں بڑی غیر استعمال شدہ فائلیں |
| 8 | سسٹم کی صفائی (sudo) | سسٹم | apt، جرنل، snap، `/tmp`، پیج کیش |
| 9 | آخری سائز کی جانچ | کچھ نہیں | صرف پڑھنے والا خلاصہ |
| 10 | پڑھنے لائق رپورٹ بنانا | کچھ نہیں | Markdown / HTML ایکسپورٹ — `jq` چاہیے |

مراحل 5، 6 اور 7 [صرف انٹرایکٹو](../safety/guards.md#guard-3--personal-data-is-interactive-only) ہیں۔ ان کی خود بخود تصدیق نہیں ہو سکتی، اور پورے ٹول میں مرحلہ 7 واحد ہے جو واقعی ناقابل تلافی چیز حذف کر سکتا ہے۔

## سوال کیسے کام کرتے ہیں {#how-the-prompts-work}

تصدیق کی دو سطحیں۔

**ہر مرحلے پر** آپ طے کرتے ہیں کہ پورے زمرے کا کیا کرنا ہے:

| کلید | اثر |
|---|---|
| `a` | یہ مرحلہ چلائیں۔ یہی ڈیفالٹ ہے — Enter اسے چنتا ہے |
| `s` | یہ مرحلہ مکمل طور پر چھوڑ دیں |
| `q` | اب تک کی پیش رفت رکھتے ہوئے واک تھرو ابھی بند کریں |

**ہر ہدف پر**، جس مرحلے کو آپ نے چلانا چنا اس کے اندر ہر چیز کی اپنی `[Y/n]` یا `[y/N]` تصدیق ہوتی ہے۔ بڑا حرف ڈیفالٹ ہے۔

یعنی مرحلے کی سطح پر `a` کا مطلب یہ نہیں کہ آپ نے اس میں سب کچھ حذف کرنے کی ہامی بھر لی — آپ پھر بھی ہر ہدف دیکھتے اور اس کا جواب دیتے ہیں۔

## جاری مجموعے {#running-totals}

ہر چلے مرحلے کے بعد ٹول اس کی ناپی گئی تبدیلی اور اب تک کا سیشن مجموعہ دکھاتا ہے۔

آخری خلاصہ پہلے اور بعد کی خالی ڈسک جگہ بتاتا ہے۔ یہ عدد `df` سے ناپا جاتا ہے، اس لیے مشین پر ہونے والی ہر چیز اس میں جھلکتی ہے — اگر آپ کے سیشن کے دوران کوئی بلڈ چلا تو بتائی گئی بچت مراحل کے مجموعے سے کم، بلکہ منفی بھی ہو سکتی ہے۔ یہ خرابی نہیں؛ دیکھیں [مسائل کا حل](../troubleshooting.md#disk-usage-grew-during-the-session)۔

## جلدی رکنا {#quitting-early}

کسی بھی مرحلے کے سوال پر `q`، یا کسی بھی وقت `Ctrl-C`، سیشن کو صاف طریقے سے ختم کرتا ہے:

- پہلے ہونے والے حذف مستقل رہتے ہیں؛ رکنے سے پہلے آزمائے گئے مراحل لاگ میں دیکھیں
- `Ctrl-C` کوڈ `130` کے ساتھ ختم ہوتا ہے، جسے [کریش ٹریپ جان بوجھ کر نظرانداز کرتا ہے](../reference/exit-codes.md#how-the-crash-trap-decides)، اس لیے کوئی کریش بنڈل نہیں لکھا جاتا
- جن مراحل تک نہیں پہنچے وہ رپورٹ میں چھوڑے گئے درج ہوتے ہیں

## سیشن رپورٹ {#the-session-report}

واک تھرو JSON رپورٹ `~/.linux-cleanup/reports/report-<timestamp>.json` میں لکھتا ہے، جب تک `--no-report` یا `--dry-run` نہ لگا ہو۔ اس میں ہر مرحلے کی حالت اور خالی ہوئے بائٹس، پہلے/بعد کی ڈسک اور میموری، اور سیشن کے مجموعے ہوتے ہیں۔ فیلڈز کی مکمل فہرست: [رپورٹ اسکیما](../reference/report-schema.md)۔

مرحلہ 10 اختیاری طور پر اسے Markdown اور HTML میں بدلتا ہے۔ اس مرحلے کو `jq` چاہیے؛ اس کے بغیر مرحلہ `skipped (jq missing)` درج ہوتا ہے اور JSON پھر بھی لکھا جاتا ہے۔

```bash
linux-cleanup --no-report    # JSON بنانا چھوڑیں؛ لاگز پھر بھی لکھے جاتے ہیں
```

## ساتھ ملانے لائق آپشنز {#options-worth-combining}

```bash
linux-cleanup -d 30          # 100 کے بجائے 30 دن کی غیر فعالیت کی حد
linux-cleanup --purge-all    # غیر فعالیت کی رکاوٹ مکمل بند
linux-cleanup --no-color     # سادہ آؤٹ پٹ
linux-cleanup --cleanup-logs # آخر میں اس رن کا لاگ حذف کریں
```

:::danger `--purge-all` بدل دیتا ہے کہ مراحل 1–4 کیا حذف کرتے ہیں
[غیر فعالیت کی رکاوٹ](../safety/guards.md#guard-2--the-staleness-gate) بند ہونے پر کیش والے مراحل غیر استعمال شدہ فائلیں چھانٹنے کے بجائے اپنے اہداف پورے صاف کر دیتے ہیں۔ اس میں Gradle wrapper ڈسٹری بیوشنز، Playwright براؤزرز اور Cypress بائنریز بھی آتی ہیں جو شاید آپ کو اب بھی چاہئیں۔ رن سے پہلے کا بینر بتاتا ہے کہ کون سی حکمت عملی چالو ہے۔
:::
