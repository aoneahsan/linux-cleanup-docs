# موڈز کا جائزہ

**linux-cleanup کا ایک ہی داخلی راستہ ہے اور موڈ ایک فلیگ سے چنا جاتا ہے۔** بغیر فلیگ چلانے پر [گائیڈڈ واک تھرو](./walkthrough.md) ملتا ہے۔

موڈز ایک دوسرے کو خارج کرتے ہیں — ایک ہی دیں۔ `--days` اور `--yes` جیسے آپشنز ان کے ساتھ ملتے ہیں۔

## صرف پڑھنا — کبھی کچھ حذف نہیں کرتا {#read-only--never-deletes-anything}

یہ موڈز صفائی کے اہداف حذف نہیں کرتے۔ یہ پھر بھی مقامی لاگ لکھ سکتے ہیں، اور آن لائن ہونے پر ریلیز جانچ ایک عوامی ریکارڈ پڑھ سکتی ہے۔

| موڈ | فلیگ | دکھاتا ہے |
|---|---|---|
| [اسکین](./scan.md) | `-s` `--scan` | ہر کیش زمرہ موجودہ سائز کے ساتھ |
| [ہوم کی جانچ](./home-audit.md) | `--audit` | `$HOME` کی 20 سب سے بڑی چیزیں |
| [گلوبل پیکیجز کی جانچ](./globals-audit.md) | `--globals` | npm/pnpm/yarn/bun/deno کے گلوبل پیکیجز |
| اہداف کی فہرست | `--list-targets` | ہر پاتھ جسے ٹول چھو سکتا ہے، اور محفوظ فہرست |
| خود جانچ | `--self-test` | انحصار، سنٹیکس اور حفاظتی جانچ |
| ورژن | `-V` `--version` | ورژن اور مصنف |

## صفائی — دوبارہ بن سکنے والا ڈیٹا {#cleanup--regenerable-data}

یہ موڈز صفائی کے اہداف حذف کر سکتے ہیں۔ `--yes` صرف `--all-safe` میں بیچ کی تصدیق چھوڑتا ہے؛ دوسرے موڈز اپنے سوال رکھتے ہیں۔

| موڈ | فلیگ | رویہ |
|---|---|---|
| [واک تھرو](./walkthrough.md) | _(ڈیفالٹ)_ `-w` | دس گائیڈڈ مراحل، ہر ایک سے پہلے سوال |
| [مینو](./menu.md) | `-m` `--menu` | نمبر والا مینو — ایک زمرہ چنیں |
| [TUI](./tui.md) | `-t` `--tui` | وہی، whiptail/dialog ڈائیلاگ کی صورت |
| [مکمل محفوظ](./all-safe.md) | `-a` `--all-safe` | ہر دوبارہ بن سکنے والا کیش ایک ہی بار میں |
| [ایڈیٹر ایکسٹینشنز](./editor-extensions.md) | `--editor-ext` | VS Code / Cursor کے پرانے ہو چکے ورژنز |
| [سسٹم کی صفائی](./system-cleanup.md) | `--system` | apt، جرنل، snap، `/tmp`، پیج کیش — `sudo` چاہیے |

## صفائی — صرف انٹرایکٹو {#cleanup--interactive-only}

ذاتی یا پروجیکٹ ڈیٹا۔ یہ **`--yes` کو نظرانداز کرتے ہیں** اور ہر اندراج کی تصدیق مانگتے ہیں۔ دیکھیں [رکاوٹ 3](../safety/guards.md#guard-3--personal-data-is-interactive-only)۔

| موڈ | فلیگ | ڈھونڈتا ہے |
|---|---|---|
| [پرانی ذاتی فائلیں](./personal-stale-files.md) | `-p` `--stale` | `~/Downloads` اور ترتیب دی گئی غیر محفوظ جڑوں میں بڑی غیر استعمال شدہ فائلیں |
| [ادھورے ڈاؤن لوڈز](./partial-downloads.md) | `--partials` | `.fdmdownload`، `.crdownload`، `.part` |
| [node_modules کی تلاش](./node-modules-finder.md) | `--node-modules` | N+ دن سے غیر استعمال شدہ پروجیکٹ ڈیپنڈنسی فولڈرز |

## آؤٹ پٹ، مرمت اور سیٹ اپ {#output-repair-and-setup}

| موڈ | فلیگ | مقصد |
|---|---|---|
| [رپورٹس](./reports.md) | `--reports` | پچھلی سیشن رپورٹس کی فہرست، تبدیلی اور دیکھنا |
| [ایکسپورٹ](./reports.md#exporting) | `--export FMT ID` | بغیر سوال کے تبدیلی |
| [ڈاکٹر](./doctor.md) | `--doctor` | nvm، pnpm، bun، deno، cargo کی ٹوٹی شیل ابتدائی ترتیب ٹھیک کریں |
| [رفتار کی تشخیص](./speed.md) | `--speed` | دباؤ اور آغاز کا کام ناپیں؛ اختیاری اصلاحات الگ سے پوچھتی ہیں |
| فیڈبیک | `--feedback` | خرابی رپورٹ کی ہدایات، اختیاری mailto مسودہ |
| ڈی بگ بنڈل | `--debug-bundle` | تازہ لاگ اور رپورٹ ایک tar.gz میں پیک کریں |
| ایلیاس انسٹال | `--install-alias` | شیل ایلیاس `cleanup` شامل کریں |
| cron انسٹال | `--install-cron` | ہر اتوار 03:00 بجے `--all-safe -y` |
| ایلیاس / cron ان انسٹال | `--uninstall-alias` `--uninstall-cron` | دونوں میں سے کسی کو ہٹائیں |

## موڈ کا انتخاب {#choosing-a-mode}

| مقصد | موڈ |
|---|---|
| ٹول کا پہلی بار استعمال | `--self-test`, `--scan`, `--all-safe --dry-run` |
| ابھی جگہ چاہیے، قابو کے ساتھ | _(ڈیفالٹ واک تھرو)_ |
| ابھی جگہ چاہیے، بغیر سوالوں کے | `--all-safe -y` |
| کوئی ایک خاص زمرہ | `--menu` / `--tui` |
| ہفتہ وار بغیر نگرانی دیکھ بھال | `--all-safe -y` + `--install-cron` |
| سسٹم دوبارہ انسٹال کرنے سے پہلے زیادہ سے زیادہ جگہ | `--all-safe -y --purge-all` |
| پتا کریں ڈسک کون کھا رہا ہے | `--audit`, `--scan` |
| پرانے ضمنی پروجیکٹس جمع ہو رہے ہیں | `--node-modules` |
| انسٹال کے بعد `command not found` | `--doctor` |

## موڈز کے ساتھ ملنے والے آپشنز {#options-that-combine-with-modes}

| آپشن | ڈیفالٹ | اثر |
|---|---|---|
| `-d N` `--days N` | 100 | غیر فعالیت کی حد۔ کم ہو تو زیادہ سخت |
| `--purge-all` | بند | غیر فعالیت کی رکاوٹ بند — مکمل صفائی |
| `-y` `--yes` | بند | دوبارہ بن سکنے والے کیش کی خود بخود تصدیق۔ صرف `--all-safe` کے ساتھ |
| `--no-report` | بند | JSON رپورٹ چھوڑیں۔ لاگز پھر بھی لکھے جاتے ہیں |
| `--cleanup-logs` | بند | آخر میں اس رن کا لاگ حذف کریں۔ رپورٹس ہمیشہ رکھی جاتی ہیں |
| `--no-color` | بند | ANSI رنگ بند کریں۔ `NO_COLOR` بھی مانا جاتا ہے |
| `-n` `--dry-run` | بند | چنی ہوئی صفائی سے حذف کیے بغیر گزریں؛ مقامی لاگ اور اپ ڈیٹ جانچ کی حالت پھر بھی لکھی جا سکتی ہے |
| `--json-events` | بند | `--scan` یا غیر انٹرایکٹو `--all-safe --yes` کے لیے NDJSON |

مکمل تفصیل: [CLI فلیگز](../reference/cli-flags.md) اور [موڈز کا جدول](../reference/modes-matrix.md)۔
