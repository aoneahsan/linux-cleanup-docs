# اسکین (صرف پڑھنا)

**`--scan` فائلیں حذف کیے بغیر پاتھس اور ان کا موجودہ سائز دکھاتا ہے۔** یہ مشین پر پہلی نظر ہے۔ مجوزہ کام دیکھنے کے لیے چنے ہوئے صفائی موڈ کا آزمائشی رن کریں۔

```bash
linux-cleanup --scan
```

## یہ کیا دیکھتا ہے؟ {#what-does-it-inspect}

اسکین کیش اور بلڈ ٹولز کی جڑوں کی ایک جدول دکھاتا ہے: پیکیج مینیجرز، براؤزرز، Gradle، ٹیسٹ رنرز، Android ٹولز اور دوسری ترتیب دی گئی جگہیں۔ یہ ادھورے ڈاؤن لوڈز، ممکنہ دہرے ڈاؤن لوڈز، بڑی پرانی ذاتی فائلوں کے امیدوار اور سسٹم کے چند مشاہدات بھی دکھاتا ہے۔ یہ پیکیج مینیجر کی صفائی نہیں چلاتا اور `sudo` نہیں مانگتا۔

فہرست میں دی گئی کسی کیش جڑ کا سائز اس میں اس وقت موجود سب کچھ ہے۔ یہ وہ مقدار **نہیں** جو ٹول حذف کرے گا۔ چنا ہوا موڈ، غیر فعالیت کی حد، موجودہ استعمال اور انکار کے اصول طے کرتے ہیں کہ کیا بچے گا۔

اسکین ایک مقامی سیشن لاگ لکھتا ہے۔ یہ واک تھرو کی [JSON سیشن رپورٹ](../reference/report-schema.md) نہیں لکھتا۔

## موڈ چننے سے پہلے پاتھس پڑھیں {#read-the-paths-before-choosing-a-mode}

جو پاتھ آپ نہ پہچانیں اسے جانچیں۔ سم لنک اپنے ظاہری نام سے مختلف جگہ کی طرف ہو سکتا ہے؛ صفائی سے پہلے اسے `realpath` سے دیکھیں۔ محفوظ پاتھس کی حفاظت بھی حذف سے پہلے سم لنکس حل کرتی ہے۔

ذاتی فائلوں کے امیدوار صرف دیکھنے کے لیے دکھائے جاتے ہیں۔ روزمرہ کی `--all-safe` صفائی انہیں نہیں چنتی۔ کیش صفائی کا پری ویو کرنے کے لیے:

```bash
linux-cleanup --all-safe --dry-run
```

آزمائشی رن اس موڈ سے حذف کیے بغیر گزرتا ہے۔ یہ پھر بھی مقامی لاگ اور اپ ڈیٹ جانچ کی حالت لکھ سکتا ہے۔ اصل حذف کی کوئی واپسی نہیں۔

## مشین کے پڑھنے لائق اسکین {#machine-readable-scan}

```bash
linux-cleanup --scan --json-events > scan.ndjson
```

[ورژن 1 کا ایونٹ سلسلہ](../reference/json-events.md) stdout پر جاتا ہے؛ پڑھنے والا متن stderr پر۔ اس میں مکمل مقامی پاتھس ہو سکتے ہیں۔ اسے اسی مشین پر رکھیں اور مکمل رن اور رکے ہوئے سلسلے میں فرق کرنے کے لیے ایگزٹ کوڈ دیکھیں۔

## صرف پڑھنے والے دوسرے منظر {#other-read-only-views}

| کمانڈ | کس سوال کا جواب |
|---|---|
| `--list-targets` | کوئی موڈ کن ترتیب دیے گئے پاتھس کو ہدف بنا سکتا ہے یا رد کرے گا؟ |
| `--audit` | `$HOME` میں کون سی چیزیں سب سے بڑی ہیں، چاہے کوئی صفائی موڈ انہیں سنبھالے یا نہیں؟ |
| `--globals` | کون سے گلوبل رن ٹائم پیکیجز انسٹال ہیں؟ |
| `--self-test` | کیا ضروری کمانڈز، سنٹیکس اور حفاظتی رکاوٹوں کی تصدیقیں پاس ہوتی ہیں؟ |

ترتیب کے لیے [حذف سے پہلے پری ویو](../safety/preview-first.md) پڑھیں، پھر موڈ کے آپشنز کے لیے [CLI فلیگز](../reference/cli-flags.md)۔
