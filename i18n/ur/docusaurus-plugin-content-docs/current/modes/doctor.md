# ڈاکٹر

**`--doctor` وہ رن ٹائمز ڈھونڈتا ہے جو ڈسک پر موجود ہیں مگر آپ کی شیل ترتیب سے جڑے نہیں، اور غائب ابتدائی بلاک شامل کرنے کی پیشکش کرتا ہے۔** [1.1.0](../changelog.md#110--2026-05-10) میں شامل ہوا۔

```bash
linux-cleanup --doctor
```

یہ وہ موڈ ہے جب آپ اچھی طرح جانتے ہیں کہ pnpm انسٹال کیا تھا، پھر بھی `pnpm: command not found` نظر آتا ہے۔

## صرف شامل کرتا ہے {#additive-only}

:::note Doctor کبھی موجودہ لائن حذف یا تبدیل نہیں کرتا
یہ صرف ایک معیاری ابتدائی بلاک **آخر میں شامل** کرتا ہے، اور وہ بھی آپ کی تصدیق کے بعد۔ یہ آپ کی شیل ترتیب میں پہلے سے موجود کسی چیز کو نہ بدلتا ہے، نہ آگے پیچھے کرتا ہے، نہ ہٹاتا ہے۔

شیل کی ابتدائی فائلیں حذف کی سطح پر بھی الگ سے محفوظ ہیں: `safe_rm` ہر اس پاتھ کو رد کرتا ہے جس کی فائل کا نام `.bashrc`، `.zshrc`، `.profile`، `.bash_aliases` یا ایسا ہی ہو، چاہے وہ کہیں بھی ہو۔ دیکھیں [محفوظ پاتھس](../reference/protected-paths.md#protected-basenames)۔
:::

## یہ کیا جانچتا ہے {#what-it-checks}

| رن ٹائم | پہچان | کیا شامل کرتا ہے |
|---|---|---|
| `nvm` | `~/.nvm` موجود، `NVM_DIR` کی ابتدائی ترتیب نہیں | nvm کا معیاری لوڈر بلاک |
| `pnpm` | `~/.local/share/pnpm` موجود، `PATH` پر نہیں | `PNPM_HOME` ایکسپورٹ اور `PATH` میں اضافہ |
| `bun` | `~/.bun` موجود، `PATH` پر نہیں | Bun کا ابتدائی بلاک |
| `deno` | `~/.deno` موجود، `PATH` پر نہیں | Deno کا `PATH` میں اضافہ |
| `cargo` | `~/.cargo` موجود، `PATH` پر نہیں | `. "$HOME/.cargo/env"` |

## یہ عموماً کیسے ہوتا ہے {#how-this-usually-happens}

کوئی انسٹالر اپنا ابتدائی بلاک ایسی فائل میں لکھتا ہے جسے آپ کا شیل نہیں پڑھتا۔ `~/.profile` صرف لاگ اِن شیل پڑھتے ہیں؛ `~/.bash_profile` موجود ہو تو اسے چھپا دیتا ہے؛ `~/.bashrc` کی تبدیلی کبھی `zsh` سیشن تک نہیں پہنچتی۔ رن ٹائم ٹھیک سے انسٹال ہوتا ہے اور پھر غائب لگتا ہے۔

یہ مشینوں کے درمیان dotfiles ریپوزٹری لے جانے کے بعد، یا لاگ اِن شیل بدلنے کے بعد بھی ہوتا ہے۔

## اس کے بعد {#afterwards}

اپنا شیل دوبارہ لوڈ کریں، ورنہ لگے گا کہ تبدیلی کام نہیں آئی:

```bash
source ~/.bashrc     # یا ~/.zshrc
```

پھر تصدیق کریں:

```bash
command -v pnpm && pnpm --version
```

## گلوبل پیکیجز کی جانچ سے اس کا تعلق {#its-relationship-to-the-globals-audit}

[`--globals`](./globals-audit.md) تب بھی کام کرتا ہے جب کوئی پیکیج مینیجر `PATH` پر نہ ہو، کیونکہ یہ فائل سسٹم دیکھنے پر لوٹ آتا ہے۔ اس لیے اگر جانچ pnpm کے گلوبل پیکیجز دکھائے مگر خود `pnpm` نہ ملے، تو `--doctor` ہی حل ہے۔
