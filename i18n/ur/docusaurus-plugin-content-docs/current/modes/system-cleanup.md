# سسٹم کی صفائی (sudo)

**`--system` شروع کرنے سے پہلے sudo مانگتا ہے، پھر ہر سسٹم مرحلے کے بارے میں پوچھتا ہے۔** یہ پیکیجز کے کام کے لیے براہ راست `apt` اور `dpkg` استعمال کرتا ہے، اس لیے پورا موڈ Debian اور Ubuntu کے لیے ہے۔ دوسرے ڈسٹروز پر جرنل یا `/tmp` والے حصے چل سکتے ہیں مگر پیکیج کمانڈز ناکام ہوں گی؛ دیکھیں [ڈسٹرو سپورٹ](../distro-support.md)۔

```bash
linux-cleanup --system --dry-run
linux-cleanup --system
```

آزمائشی رن صفائی کے اہداف حذف کیے یا سیٹنگز بدلے بغیر مجوزہ کمانڈز دکھاتا ہے۔ یہ پھر بھی مقامی لاگ اور اپ ڈیٹ جانچ کی حالت لکھ سکتا ہے۔ اصل رن سے پہلے اسے دیکھیں، کیونکہ اس کی کوئی واپسی نہیں۔

## چھ مراحل {#the-six-steps}

| مرحلہ | تصدیق کے بعد کوڈ کیا چلاتا ہے | ڈیفالٹ |
|---|---|---|
| apt | `sudo apt autoremove --purge -y`, `sudo apt clean` | ہاں |
| جرنل | `sudo journalctl --vacuum-size=100M` | ہاں |
| Snap | `sudo snap remove` سے اہل بند ریویژنز | ہاں |
| کرنلز | `dpkg` سے انسٹال شدہ `linux-image-*` پیکیجز کی فہرست | کچھ حذف نہیں |
| `/tmp` | `sudo find /tmp -mindepth 1 -atime +7 -delete` | ہاں |
| پیج کیش | `sudo sync`, `sudo sysctl -q -w vm.drop_caches=3` | نہیں |

جرنل کا ہدف 100 MB اور `/tmp` کی عمر 7 دن ہے؛ دونوں `--days` کو نہیں مانتے۔ Snap مرحلہ بند واپسی والی ریویژن کو تب تک رکھتا ہے جب تک اس کی جگہ لینے والی ریویژن مقررہ عمر کی حد پوری نہ کر لے، جب تک `--purge-all` نہ لگا ہو۔ کرنلز کی فہرست صرف معلومات کے لیے ہے؛ apt اپنے پہلے مرحلے میں پرانے کرنل پیکیجز حذف کر سکتا ہے۔

`/tmp` مرحلہ رسائی کے وقت پر انحصار کرتا ہے۔ اگر فائل سسٹم انہیں قابل اعتماد طور پر درج نہیں کرتا تو ٹول عمر کی بنیاد پر حذف چھوڑ دیتا ہے۔ پیج کیش خالی کرنے سے RAM خالی ہوتی ہے، ڈسک نہیں، اور کیش دوبارہ بھرنے تک بعد کی پڑھائی سست ہو سکتی ہے۔

## حدود {#boundaries}

یہ موڈ چلتے وقت sudo کی اسناد کیش کرتا ہے تاکہ اپنی الگ الگ کمانڈز چلا سکے۔ اگر آپ ان کمانڈز کو دیکھنے کے لیے تیار نہیں تو سسٹم کی صفائی شروع نہ کریں۔ `--speed` کی الگ اختیاری اصلاحات بھی sudo مانگ سکتی ہیں؛ CLI میں sudo والا راستہ صرف سسٹم موڈ نہیں۔

کتنی جگہ واپس ملے گی، یہ مشین پر منحصر ہے۔ رن کے بعد ناپی گئی ڈسک کی تبدیلی میں دوسرے عمل کی لکھائی بھی شامل ہو سکتی ہے۔ ٹول نے کون سی کمانڈز چلانے کی کوشش کی، یہ لاگ میں پڑھیں۔
