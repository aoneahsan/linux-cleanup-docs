# مینو

**`--menu` ہر زمرے کی نمبر والی فہرست دکھاتا ہے اور آپ کا چنا ہوا چلاتا ہے۔** اسے تب استعمال کریں جب آپ جانتے ہوں کہ کیا چاہیے اور دس مراحل کے دورے کی ضرورت نہ ہو۔

```bash
linux-cleanup --menu     # یا: -m, -i, --interactive
```

## یہ واک تھرو سے کیسے مختلف ہے {#how-it-differs-from-the-walkthrough}

| | مینو | [واک تھرو](./walkthrough.md) |
|---|---|---|
| ترتیب | آپ چنتے ہیں | مقررہ، دس مراحل |
| دائرہ | ہر انتخاب میں ایک زمرہ | سب کچھ، ترتیب سے |
| دہرانا | بعد میں مینو پر لوٹتا ہے | آخر تک چلتا ہے |
| رپورٹ | ہر کارروائی کی | پورے سیشن کی ایک |
| کس کے لیے بہتر | مخصوص صفائی | پہلے رن، مکمل صفائی |

حفاظتی ماڈل بالکل وہی ہے۔ ہر زمرہ ویسا ہی برتاؤ کرتا ہے جیسا واک تھرو میں — [اجازت فہرست](../safety/guards.md#guard-1--the-path-allowlist)، [غیر فعالیت کی رکاوٹ](../safety/guards.md#guard-2--the-staleness-gate) اور ہر ہدف کی تصدیق سب لاگو رہتی ہیں۔ مینو سے ذاتی ڈیٹا کا زمرہ چننے پر بھی ہر اندراج کے لیے پوچھا جاتا ہے، اور `--yes` کا اس پر اب بھی کوئی اثر نہیں۔

## آپشنز پھر بھی لاگو ہوتے ہیں {#options-still-apply}

```bash
linux-cleanup --menu -d 30        # جو بھی چنیں اس کے لیے 30 دن کی حد
linux-cleanup --menu --purge-all  # غیر فعالیت کی رکاوٹ بند
linux-cleanup --menu --no-color   # سادہ آؤٹ پٹ
```

## TUI کب استعمال کریں {#when-to-use-the-tui-instead}

[`--tui`](./tui.md) وہی مینو ہے، whiptail یا dialog باکس کی صورت میں۔ اس کے لیے ان میں سے ایک انسٹال ہونا چاہیے؛ `--menu` کو bash کے سوا کچھ نہیں چاہیے اور یہ ہر کنکشن پر چلتا ہے، سادہ ٹرمینل یا ایسے `ssh -T` سیشن میں بھی جہاں فل اسکرین ڈائیلاگ گڑبڑ کرے۔
