# پرانی ذاتی فائلیں

**`--stale`، `~/Downloads` اور ترتیب دی گئی غیر محفوظ جڑوں میں تقریباً 10 MB سے بڑی وہ فائلیں ڈھونڈتا ہے جو `--days` یا زیادہ دن سے استعمال نہیں ہوئیں، اور انہیں ایک ایک کر کے حذف کرنے کی پیشکش کرتا ہے۔**

```bash
linux-cleanup --stale         # یا: -p
linux-cleanup --stale -d 180  # صرف 180+ دن سے غیر استعمال شدہ فائلیں
```

:::danger ذاتی فائلیں ناقابل تلافی ہو سکتی ہیں
`~/Downloads` اور آپ کی ترتیب دی گئی غیر محفوظ جڑوں میں وہی ہوتا ہے جو آپ نے وہاں رکھا — کبھی کبھی کسی اہم چیز کی واحد کاپی بھی۔

ٹول اس انسٹالر کو، جسے آپ پھر کبھی نہیں کھولیں گے، اس دستاویز سے الگ نہیں کر سکتا جس کی ابھی ضرورت نہیں پڑی۔ وہ کوشش بھی نہیں کرتا۔ **ہر امیدوار پڑھیں۔**
:::

## اصولاً انٹرایکٹو {#interactive-by-policy}

ہر فائل یا ہر رینج کی تصدیق لازمی ہے۔ یہاں `--yes` نظرانداز ہوتا ہے اور ہمیشہ ہوگا، اور یہ موڈ [`--all-safe`](./all-safe.md) کا حصہ نہیں۔ دیکھیں [رکاوٹ 3](../safety/guards.md#guard-3--personal-data-is-interactive-only)۔

کچھ بھی پوچھنے سے پہلے امیدواروں کی پوری فہرست دکھائی جاتی ہے، اس لیے موڈ چلا کر سب کچھ رد کرنا بھی ان فولڈرز کو جانچنے کا ایک جائز طریقہ ہے۔

## کوئی فائل امیدوار کب بنتی ہے {#what-makes-a-file-a-candidate}

تینوں شرائط ایک ساتھ:

1. وہ کسی ترتیب دی گئی ذاتی جڑ میں ہے — ڈیفالٹ طور پر `~/Downloads`؛ `~/Desktop` جیسی محفوظ جڑیں نظرانداز ہوتی ہیں
2. وہ تقریباً 10 MB سے بڑی ہے
3. `atime` اور `mtime` دونوں `--days` (ڈیفالٹ 100) سے پرانے ہیں

ذاتی جڑیں `$XDG_CONFIG_HOME` (ڈیفالٹ `~/.config`) کے تحت `personal-roots.txt` سے ترتیب دی جا سکتی ہیں۔ دیکھیں [ماحولیاتی متغیرات](../reference/environment-variables.md)۔

:::note `~/Downloads` محفوظ فہرست میں کیوں نہیں
ہو ہی نہیں سکتا — اسے صاف کرنا ہی اس موڈ کا پورا مقصد ہے۔ [اجازت فہرست](../safety/guards.md#guard-1--the-path-allowlist)، `~/Documents`، `~/Pictures`، `~/Music` اور `~/Videos` کی حفاظت ٹھیک اسی لیے کرتی ہے کہ جس ایک فولڈر تک یہ پہنچے وہ وہی ہو جس کی آپ توقع کرتے ہیں۔

اگر آپ اہم چیزیں `~/Downloads` میں رکھتے ہیں تو انہیں کسی محفوظ جگہ منتقل کریں — یہی پائیدار حل ہے، اور یہ انہیں اس ٹول سے زیادہ چیزوں سے بچاتا ہے۔
:::

## امیدواروں کی فہرست پڑھنا {#reading-the-candidate-list}

ہر اندراج پاتھ، سائز اور غیر استعمال شدہ دن دکھاتا ہے۔ رک کر سوچنے لائق:

| قسم | غور کریں |
|---|---|
| انسٹالرز، ISOs، `.deb`/`.AppImage` | عموماً محفوظ — دوبارہ ڈاؤن لوڈ ہو سکتے ہیں |
| جو کچھ آپ نے خود بنایا، ڈاؤن لوڈ نہیں کیا | رکھیں، یا کسی محفوظ جگہ منتقل کریں |
| کلائنٹ یا کام کی فراہم کی جانے والی چیزیں | رکھیں۔ Downloads ان کی جگہ نہیں |
| بغیر واضح ماخذ والا میڈیا | قبول کرنے سے پہلے تحقیق کریں |
| آرکائیوز جو کبھی نہیں کھولے | پہلے اندر کا مواد دیکھیں |

## زیادہ محفوظ ترتیب {#a-safer-sequence}

```bash
linux-cleanup --audit            # $HOME میں اصل میں بڑا کیا ہے
linux-cleanup --stale -d 365     # صرف واقعی بہت پرانی فائلیں
```

365 دن سے شروع کر کے نیچے آنے سے پہلے ایک مختصر، واضح فہرست ملتی ہے۔ وہ نمٹ جائے تو حد کم کریں۔
