# TUI (بصری مینو)

**`--tui` زمروں کا مینو فل اسکرین whiptail یا dialog باکس میں دکھاتا ہے۔** [1.3.0](../changelog.md#130--2026-05-10) میں شامل ہوا۔ رویہ [`--menu`](./menu.md) جیسا، بس دکھاوٹ مختلف۔

```bash
linux-cleanup --tui      # یا: -t, -g, --gui
```

## یہ کیسے کام کرتا ہے {#how-it-behaves}

کوئی اندراج چننے پر ڈائیلاگ سے باہر آ کر وہ زمرہ عام CLI آؤٹ پٹ اور سوالوں کے ساتھ چلتا ہے، پھر مینو پر واپس آتا ہے۔ یعنی ڈائیلاگ بس شروع کرنے کا ذریعہ ہے — اصل تصدیقیں اب بھی عام متنی سوال ہیں، اور ہر حفاظتی رکاوٹ ویسی ہی ہے۔

TUI میں ایک **About** ڈائیلاگ بھی ہے جو ورژن، رابطے کی تفصیل، لائسنس اور رازداری کی ضمانت دکھاتا ہے۔

## ضروریات اور متبادل {#requirements-and-fallback}

`whiptail` یا `dialog` چاہیے۔ دونوں نہ ہوں تو ٹول ہر ڈسٹرو کے لیے انسٹال کا اشارہ دکھاتا ہے اور عام CLI مینو پر لوٹ جاتا ہے — ناکام نہیں ہوتا۔

```bash
sudo apt install whiptail     # Debian / Ubuntu
sudo dnf install newt         # Fedora / RHEL
sudo pacman -S libnewt        # Arch
```

RPM اور Arch سسٹمز پر `whiptail`، `newt` / `libnewt` پیکیجز کے اندر آتا ہے، اسی لیے پیکیج کا نام کمانڈ کے نام سے نہیں ملتا۔

:::note صرف یہیں ٹول آپ کا ڈسٹرو پہچانتا ہے
اوپر کا انسٹال اشارہ ڈسٹرو کے حساب سے ہے۔ linux-cleanup میں اور کچھ ایسا نہیں کرتا — خاص طور پر [`--system`، Debian/Ubuntu فرض کرتا ہے](../distro-support.md)۔
:::

## سادہ مینو کب استعمال کریں {#when-to-use-the-plain-menu}

`--tui` کو ایسا ٹرمینل چاہیے جو فل اسکرین ڈائیلاگ دکھا سکے۔ محدود کنکشن پر، CI لاگ کے اندر، یا بغیر TTY والے `ssh -T` سیشن میں [`--menu`](./menu.md) استعمال کریں — اسے bash کے سوا کچھ نہیں چاہیے۔
