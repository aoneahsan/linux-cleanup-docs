# سوچ سمجھ کر جگہ واپس لیں

**پہلے ناپیں۔ صفائی کا وہ سب سے چھوٹا دائرہ چنیں جو آپ کو ملے پاتھس کو سنبھالے۔** بتایا گیا کیش جڑ کا سائز اس بات کا وعدہ نہیں کہ صفائی اسے پورا حذف کر سکتی ہے یا اسے کرنا چاہیے۔

## 1. بڑے پاتھس ڈھونڈیں {#1-find-the-large-paths}

```bash
linux-cleanup --audit
linux-cleanup --scan
```

`--audit`، `$HOME` کی بڑی چیزیں دکھاتا ہے، ان سمیت جنہیں یہ ٹول صاف نہیں کر سکتا۔ `--scan` ترتیب دی گئی کیش جڑیں اور دوسرے امیدوار حذف کیے بغیر دکھاتا ہے۔ اگر ڈسک کا بڑا حصہ کوئی VM امیج، ڈیٹا سیٹ یا گیم لائبریری ہے تو غیر متعلقہ صفائی موڈز چلانے کے بجائے اسے براہ راست دیکھیں۔

## 2. روزمرہ کیش کا پری ویو {#2-preview-routine-caches}

```bash
linux-cleanup --all-safe --dry-run
```

ڈیفالٹ مکمل محفوظ موڈ 100 دن کی غیر فعالیت کی حد کے بعد اہل دوبارہ بن سکنے والے کیش کی چھانٹی کرتا ہے۔ پری ویو حذف کیے بغیر ان اصولوں سے گزرتا ہے۔ مقامی لاگ اور اپ ڈیٹ جانچ کی حالت پھر بھی لکھی جا سکتی ہے۔

اگر ہر مجوزہ پاتھ ایسا ہے جسے آپ دوبارہ بنا یا ڈاؤن لوڈ کر سکتے ہیں تو `linux-cleanup --all-safe` چلائیں اور اس کی تصدیق دیکھیں۔ `--yes` اس بغیر نگرانی رن کے لیے ہے جب آپ یہ مشین پہلے ہی جانچ چکے ہوں۔

## 3. پروجیکٹ ڈیپنڈنسیز الگ سے دیکھیں {#3-review-project-dependencies-separately}

```bash
linux-cleanup --node-modules --dry-run
```

پروجیکٹ ڈیپنڈنسی موڈ انٹرایکٹو ہے۔ اصل حذف سے پہلے پروجیکٹ کا پاتھ اور اس کی لاک فائل جانچیں۔ `node_modules` کے اندر کی گئی مقامی تبدیلی ڈیپنڈنسیز دوبارہ انسٹال کرنے سے واپس نہیں آتی۔

## 4. سسٹم اسٹوریج الگ سے دیکھیں {#4-review-system-storage-separately}

```bash
linux-cleanup --system --dry-run
```

مکمل سسٹم موڈ apt اور dpkg استعمال کرتا ہے، اس لیے یہ Debian اور Ubuntu کے لیے ہے۔ یہ sudo مانگتا ہے اور اس میں جرنل کی صفائی، `/tmp` کی پرانی فائلیں اور ایک اختیاری پیج کیش مرحلہ شامل ہے۔ پیج کیش کا مرحلہ RAM پر اثر ڈالتا ہے، ڈسک پر نہیں۔ دیکھیں [سسٹم کی صفائی](../modes/system-cleanup.md)۔

## 5. عمر کی حد صرف ایک اور پری ویو کے بعد بدلیں {#5-change-the-age-threshold-only-after-another-preview}

`--days N` بدلتا ہے کہ کون سی غیر استعمال شدہ فائلیں یا پوری کیش اکائیاں اہل ہیں۔ اسے 100 سے 30 کرنے پر وہ مواد حذف ہو سکتا ہے جو آپ نے حال ہی میں استعمال کیا، اس لیے پہلے چنی ہوئی قدر کے ساتھ ایک آزمائشی رن دیکھیں۔ `--purge-all` عمر کی حفاظت بند کرتا ہے؛ یہ کوئی Gradle ڈسٹری بیوشن یا ٹیسٹ براؤزر حذف کر سکتا ہے جسے آپ کو دوبارہ ڈاؤن لوڈ کرنا پڑے گا۔

## 6. ذاتی فائلوں کو الگ فیصلہ رکھیں {#6-keep-personal-files-as-a-separate-decision}

`--stale` بڑی غیر استعمال شدہ ذاتی فائلوں کے امیدوار دکھاتا ہے اور ہر حذف کے لیے پوچھتا ہے۔ کوئی پرانا ڈاؤن لوڈ آپ کی واحد کاپی ہو سکتا ہے۔ `--yes` اس موڈ کی منظوری نہیں دیتا۔ دیکھیں [پرانی ذاتی فائلیں](../modes/personal-stale-files.md) اور [حذف مستقل ہے](../safety/irreversibility.md)۔

کتنی جگہ واپس ملتی ہے، یہ مشین پر اور رن کے دوران لکھنے والے دوسرے عمل پر منحصر ہے۔ کوئی اور موڈ چاہیے یا نہیں، یہ طے کرنے سے پہلے آخری لاگ اور رکھے گئے پاتھس دیکھیں۔
