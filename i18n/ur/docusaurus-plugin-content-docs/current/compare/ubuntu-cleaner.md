# linux-cleanup اور Ubuntu Cleaner

*2026-11-22 کو <a href="https://github.com/basantmandal/ubuntu-cleaner" target="_blank" rel="noopener noreferrer nofollow">Ubuntu Cleaner کا اپنا صفحہ</a> سے جانچا گیا۔*

**یہ کیا ہے:** Ubuntu، Debian اور Linux Mint کے لیے Bash کلینر، پیکیج اور ڈیولپر کیش کی دیکھ بھال کے ساتھ۔

**وہاں قیمت:** جانچے گئے صفحات پر درج نہیں۔ **یہاں قیمت:** کمانڈ لائن MIT لائسنس کے تحت مفت ہے۔ ڈیسک ٹاپ ایپ کے پلانز [قیمتوں کے صفحے](https://linux-cleanup.aoneahsan.com/ur/pricing) پر ہیں۔

## Ubuntu Cleaner کس کے لیے بہتر ہے {#who-is-better-served-by-ubuntu-cleaner}

Debian خاندان پر توجہ اور Docker کی دیکھ بھال کے لیے Ubuntu Cleaner چنیں۔

## linux-cleanup کہاں آگے ہے {#where-linux-cleanup-is-ahead}

اگر آپ چاہتے ہیں کہ صفائی آپ کے عام یوزر کے طور پر چلے اور سسٹم پیکیجز ایک الگ، واضح --system موڈ پر چھوڑے، تو linux-cleanup چنیں۔

## یہاں کہاں سے شروع کریں {#where-to-start-here}

ایک ٹول سے دوسرے میں کوئی امپورٹ نہیں: ہر ایک اپنے اصول رکھتا ہے۔ linux-cleanup آپ کے کمپیوٹر پر کیا کرے گا، یہ دیکھنے کے لیے [حذف سے پہلے پری ویو](../safety/preview-first.md) سے شروع کریں اور `npx -y linux-cleanup --all-safe --yes --dry-run` چلائیں، جو کچھ حذف نہیں کرتا۔
