# linux-cleanup اور CleanMate

*2026-11-22 کو <a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">CleanMate کا اپنا صفحہ</a> سے جانچا گیا۔*

## CleanMate کس کے لیے بہتر ہے {#who-is-better-served-by-cleanmate}

اگر آپ کو اس کی Ubuntu ڈیسک ٹاپ ایپ، Space Lens، یا ذاتی فائلوں کے لیے ری سائیکل بن اور واپسی کا طریقہ چاہیے تو CleanMate چنیں۔

## linux-cleanup کہاں آگے ہے {#where-linux-cleanup-is-ahead}

اگر آپ کو JSON ایونٹ اسٹریم والی اسکرپٹ ایبل کمانڈ لائن چاہیے، اور ہر اصل رن لوکل JSON رپورٹ میں درج ہو، تو linux-cleanup چنیں۔

## یہاں کہاں سے شروع کریں {#where-to-start-here}

ایک ٹول سے دوسرے میں کوئی امپورٹ نہیں: ہر ایک اپنے اصول رکھتا ہے۔ linux-cleanup آپ کے کمپیوٹر پر کیا کرے گا، یہ دیکھنے کے لیے [حذف سے پہلے پری ویو](../safety/preview-first.md) سے شروع کریں اور `npx -y linux-cleanup --all-safe --yes --dry-run` چلائیں، جو کچھ حذف نہیں کرتا۔
