# linux-cleanup اور TuxCleaner

*2026-11-22 کو <a href="https://github.com/debba/tuxcleaner" target="_blank" rel="noopener noreferrer nofollow">TuxCleaner کا اپنا صفحہ</a> سے جانچا گیا۔*

**یہ کیا ہے:** صفائی، ایپ ان انسٹال، ڈسک تجزیے اور اسٹیٹس کے لیے Linux CLI۔

**وہاں قیمت:** جانچے گئے صفحات پر درج نہیں۔ **یہاں قیمت:** کمانڈ لائن MIT لائسنس کے تحت مفت ہے۔ ڈیسک ٹاپ ایپ کے پلانز [قیمتوں کے صفحے](https://linux-cleanup.aoneahsan.com/ur/pricing) پر ہیں۔

| | linux-cleanup | TuxCleaner |
|---|---|---|
| کمانڈ لائن انٹرفیس | ہاں | ہاں (<a href="https://github.com/debba/tuxcleaner" target="_blank" rel="noopener noreferrer nofollow">ماخذ</a>) |
| حذف سے پہلے پری ویو | ہاں | ہاں (<a href="https://github.com/debba/tuxcleaner" target="_blank" rel="noopener noreferrer nofollow">ماخذ</a>) |
| آزمائشی رن | ہاں | ہاں (<a href="https://github.com/debba/tuxcleaner" target="_blank" rel="noopener noreferrer nofollow">ماخذ</a>) |
| کیش کی صفائی | ہاں | ہاں (<a href="https://github.com/debba/tuxcleaner" target="_blank" rel="noopener noreferrer nofollow">ماخذ</a>) |
| ڈپلیکیٹ فائلیں ڈھونڈنا | جزوی | جانچے گئے صفحات پر درج نہیں |

## TuxCleaner کس کے لیے بہتر ہے {#who-is-better-served-by-tuxcleaner}

ڈسٹری بیوشن کے لحاظ سے پیکیج اڈاپٹرز اور ایپ ان انسٹال کے لیے TuxCleaner چنیں۔

## linux-cleanup کہاں آگے ہے {#where-linux-cleanup-is-ahead}

اگر آپ بغیر بلڈ کے npx سے Bash اسکرپٹ چلانا پسند کرتے ہیں، اور پورے Gradle اور Android Studio یونٹس کے لیے صرف غیر فعال ہونے پر حذف کے اصول رکھنا چاہتے ہیں، تو linux-cleanup چنیں۔

## یہاں کہاں سے شروع کریں {#where-to-start-here}

ایک ٹول سے دوسرے میں کوئی امپورٹ نہیں: ہر ایک اپنے اصول رکھتا ہے۔ linux-cleanup آپ کے کمپیوٹر پر کیا کرے گا، یہ دیکھنے کے لیے [حذف سے پہلے پری ویو](../safety/preview-first.md) سے شروع کریں اور `npx -y linux-cleanup --all-safe --yes --dry-run` چلائیں، جو کچھ حذف نہیں کرتا۔
