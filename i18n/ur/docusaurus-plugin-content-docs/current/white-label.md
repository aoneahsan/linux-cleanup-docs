# وائٹ لیبل اور لائسنسنگ

## حاصل کرنے کے دو طریقے {#two-ways-to-have-it}

| | لائسنس | مکمل خریداری |
|---|---|---|
| آپ کو کیا ملتا ہے | آپ کے نام سے بلڈز، جنہیں ہم چلاتے ہیں | ڈیسک ٹاپ ایپ کا سورس اور بیک اینڈ، آپ کے حوالے |
| سورس کوڈ | شامل نہیں | ڈیسک ٹاپ ایپ بنانے والی ہر ریپوزٹری |

2. ادائیگی کے صفحے پر جائیں۔ وہاں ہماری Wise تفصیلات ہیں؛ ٹرانسفر اور اس کا حوالہ وہیں بھیجیں۔
3. ٹرانسفر کی تصدیق ہوتے ہی لائسنس یا مکمل خریداری جاری ہوتی ہے اور ای میل سے آپ تک پہنچتی ہے۔
4. ہمیں اپنے پروڈکٹ کا نام، نشان، رنگ اور ڈومین یا ریلیز چینل بھیجیں۔ ہم بناتے، سائن کرتے، شائع کرتے ہیں اور ہر مرحلہ ای میل سے بتاتے ہیں۔
