# linux-cleanup

**linux-cleanup، Linux پر دوبارہ بن سکنے والے کیش حذف کرنے سے پہلے پاتھس دکھاتا ہے۔** یہ پیکیج مینیجرز، براؤزرز اور بلڈ ٹولز کے کیش کا احاطہ کرتا ہے، اور سسٹم کے کام اور ذاتی فائلوں کے امیدواروں کے لیے الگ موڈز رکھتا ہے۔ اصل صفائی چننے سے پہلے صرف پڑھنے والے اسکین یا آزمائشی رن سے شروع کریں۔

linux-cleanup حاصل کریں: [npm پر](https://www.npmjs.com/package/linux-cleanup) · [ویب سائٹ](https://linux-cleanup.aoneahsan.com) · [تمام جگہیں](/apps)

یہ ایک **حذف کرنے والا ٹول** ہے۔ ہر حذف مستقل ہے، اور واپسی نہیں ہوتی۔ اس کی حفاظت اس بات سے آتی ہے کہ یہ شروع ہی سے غلط چیزوں کو چھونے سے انکار کرتا ہے، نہ کہ انہیں واپس رکھ سکنے سے۔

:::danger یہ ٹول فائلیں مستقل طور پر حذف کرتا ہے
کوئی واپسی، ری سائیکل بن یا بیک اپ مرحلہ نہیں۔ اصل صفائی چنی ہوئی فائلیں ہمیشہ کے لیے حذف کر دیتی ہے۔ تصدیق سے پہلے چنے ہوئے موڈ کا پری ویو `--dry-run` سے کریں۔

اسے کچھ بھی حذف کرنے دینے سے پہلے **[یہ کیا حذف کرتا ہے](./safety/what-it-deletes.md)** پڑھیں اور **[صرف پڑھنے والا پری ویو](./safety/preview-first.md)** چلائیں۔

## یہ کس میں اچھا ہے {#what-it-is-good-at}

- **امیدوار دکھانا۔** اسکین کیش کی جڑوں اور ان کے موجودہ سائز کے نام بتاتا ہے۔ آزمائشی رن چنی ہوئی صفائی سے گزر کر مجوزہ کام بتاتا ہے۔
- **غلط چیز حذف نہ کرنا۔** ایک [پاتھ اجازت فہرست](./reference/protected-paths.md) سم لنکس حل کرنے کے بعد `~/Documents`، `~/.ssh`، `~/.config`، `/etc` اور ایسے ہی فولڈرز کو سختی سے رد کرتی ہے۔
- **حال میں استعمال ہوئی فائلیں چھوڑ دینا۔** 1.2.0 سے ڈیفالٹ *چھانٹی* ہے، پورا صاف کرنا نہیں: کسی کیش میں صرف 100+ دن سے نہ چھوئی گئی فائلیں حذف ہوتی ہیں۔ دیکھیں [غیر فعالیت کی رکاوٹ](./safety/guards.md#guard-2--the-staleness-gate)۔
- **رن درج کرنا۔** CLI ایک مقامی لاگ رکھتا ہے۔ گائیڈڈ واک تھرو ایک [JSON سیشن رپورٹ](./reference/report-schema.md) لکھتے ہیں جب تک بند نہ کیا جائے؛ آزمائشی رن نہیں لکھتے۔
- **اپ ڈیٹس جانچنا۔** شروع ہونے پر، دستیاب ہو تو CLI، HTTPS پر ایک عوامی ریلیز ریکارڈ پڑھتا ہے۔

## یہ کیا نہیں ہے {#what-it-is-not}

حدود کے بارے میں صاف رہنا فیچرز کی فہرست سے زیادہ کام کا ہے۔

- **بیک اپ ٹول نہیں۔** یہ حذف کرتا ہے؛ کبھی محفوظ نہیں کرتا۔ اس کا حذف کیا ہوا ٹول کے اندر سے واپس نہیں آ سکتا۔
- **واپسی کا ٹول نہیں۔** [`--scan`](./modes/scan.md) صرف پڑھتا ہے؛ `--dry-run` چنی ہوئی صفائی کا پری ویو کرتا ہے؛ اصل رن کے بعد دونوں میں سے کوئی فائلیں واپس نہیں لا سکتا۔
- **سیکیورٹی اسکینر نہیں۔** یہ راز، میلویئر یا کمزوریاں نہیں ڈھونڈے گا۔
- **کراس پلیٹ فارم نہیں۔** صرف Linux۔ npm پیکیج `"os": ["linux"]` ظاہر کرتا ہے۔
- **ہر ڈسٹرو پر مکمل نہیں۔** `$HOME` کے اندر کیش کی صفائی کہیں بھی چلتی ہے، مگر [`--system` موڈ صرف Debian/Ubuntu کے لیے ہے](./distro-support.md) — یہ براہ راست `apt` اور `dpkg` چلاتا ہے۔
- **آپ کی سمجھ کا متبادل نہیں۔** تصدیق سے پہلے پڑھیں کہ یہ کیا تجویز کرتا ہے۔

## 30 سیکنڈ کا ورژن {#the-30-second-version}

```bash
# 1. دیکھیں کتنی جگہ واپس مل سکتی ہے۔ کچھ حذف نہیں کرتا۔
npx linux-cleanup --scan

# 2. چنی ہوئی صفائی کا پری ویو، حذف کیے بغیر۔
npx linux-cleanup --all-safe --dry-run

# 3. گائیڈڈ واک تھرو چلائیں۔ حذف سے پہلے ہر انتخاب دیکھیں۔
npx linux-cleanup
```

مرحلہ 3 ڈیفالٹ موڈ ہے۔ یہ دس زمروں سے گزرتا ہے، ہر ایک سے پہلے پوچھتا ہے، واپس ملے بائٹس کا جاری مجموعہ دکھاتا ہے، اور آخر میں ایک رپورٹ لکھتا ہے۔ دیکھیں [واک تھرو](./modes/walkthrough.md)۔
