# حذف سے پہلے پری ویو

**`--scan` سے شروع کریں، پھر صفائی کا موڈ `--dry-run` کے ساتھ چلائیں۔** اسکین حذف کیے بغیر پاتھس اور سائز دکھاتا ہے۔ آزمائشی رن چنی ہوئی صفائی سے گزر کر وہ کام دکھاتا ہے جو وہ کرتا، مگر فائلیں حذف نہیں کرتا اور سیٹنگز نہیں بدلتا۔ دونوں پھر بھی ایک مقامی سیشن لاگ بناتے ہیں۔

```bash
linux-cleanup --self-test
linux-cleanup --scan
linux-cleanup --all-safe --dry-run
```

`--self-test` انحصارات، Bash سنٹیکس اور محفوظ پاتھس کی حفاظت جانچتا ہے۔ اگر یہ ناکام ہو تو رک جائیں۔

## اسکین کیا دکھاتا ہے؟

`--scan` کیش کی جڑیں، ادھورے ڈاؤن لوڈز، ممکنہ دہرے ڈاؤن لوڈز، بڑی اور طویل عرصے سے غیر استعمال شدہ ذاتی فائلوں کے امیدوار، اور سسٹم کے بارے میں مشاہدات کی فہرست دیتا ہے۔ کسی کیش جڑ کا جو سائز یہ دکھاتا ہے وہ **وہاں اس وقت موجود سب کچھ** ہے، نہ کہ وہ مقدار جو بعد کی صفائی حذف کرے گی۔ 100 دن کی ڈیفالٹ غیر فعالیت کی حد، موجودہ استعمال اور ہر موڈ کے اصول اس کا زیادہ تر حصہ رکھ سکتے ہیں۔

اسکین JSON سیشن رپورٹ نہیں بناتا۔ مشین کے پڑھنے لائق اسکین چاہیے تو `linux-cleanup --scan --json-events` استعمال کریں۔ ایونٹس میں مکمل مقامی پاتھس ہو سکتے ہیں؛ انہیں اپنی مشین پر ہی رکھیں۔

## آزمائشی رن کیا دکھاتا ہے؟

`--dry-run` چنی ہوئی صفائی سے گزر کر مجوزہ کام دکھاتا ہے۔ مثال کے طور پر:

```bash
linux-cleanup --all-safe --dry-run
linux-cleanup --all-safe --yes --dry-run --json-events > preview.ndjson
```

پہلا کمانڈ اصل رن کی طرح تصدیق مانگتا ہے۔ دوسرا غیر انٹرایکٹو ہے اور ورژن والے JSON ایونٹس stdout پر لکھتا ہے؛ پڑھنے والا متن stderr پر جاتا ہے۔ دونوں میں سے کوئی فائلیں حذف نہیں کرتا۔ آزمائشی رن JSON سیشن رپورٹ نہیں لکھتا۔

پری ویو اس وقت کی مشین کی ایک جھلک ہے، بعد کے رن کا وعدہ نہیں۔ پری ویو اور تصدیق کے درمیان فائلیں استعمال، تبدیل یا حذف ہو سکتی ہیں۔ اس ٹول میں نہ واپسی ہے نہ بیک اپ۔

## اصل رن سے پہلے حد جانچیں

`--list-targets` ڈسک ناپے بغیر ترتیب دی گئی ہدف جڑیں اور محفوظ پاتھس دکھاتا ہے۔ اس سے معلوم ہوتا ہے کہ کوئی فولڈر دائرے میں ہے یا نہیں۔ [محفوظ پاتھس کا حوالہ](../reference/protected-paths.md) رد کرنے کے اصول بتاتا ہے۔

ذاتی فائلوں اور پروجیکٹس سے متعلق موڈز روزمرہ کی کیش صفائی سے الگ ہیں۔ ان کے امیدوار ایک ایک کر کے دیکھیں۔ `--yes` صرف `--all-safe` پر لاگو ہوتا ہے؛ یہ ذاتی فائلیں حذف کرنے کی منظوری نہیں دیتا۔

جب پری ویو آپ کے ارادے سے میل کھائے تو اپنا موڈ چنیں اور اس کی تصدیق پڑھیں۔ اصل حذف مستقل ہے۔
