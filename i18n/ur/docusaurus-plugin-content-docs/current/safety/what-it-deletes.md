# یہ کیا حذف کرتا ہے

**linux-cleanup چنے ہوئے کیش اور بچی کھچی فائلیں مستقل طور پر حذف کرتا ہے۔** ہدف موڈ پر منحصر ہے۔ اسکین پاتھس اور ان کا موجودہ سائز بتاتا ہے؛ آزمائشی رن چنی ہوئی صفائی سے گزر کر مجوزہ کام دکھاتا ہے۔ دونوں میں سے کوئی بیک اپ نہیں۔

```bash
linux-cleanup --list-targets
linux-cleanup --scan
linux-cleanup --all-safe --dry-run
```

[محفوظ پاتھس کی حفاظت](../reference/protected-paths.md) سم لنکس حل کرنے کے بعد ترتیب دی گئی ذاتی اور سسٹم جگہوں کو رد کرتی ہے۔ اصل رن سے پہلے ہر مجوزہ پاتھ پڑھیں۔

## پیکیج مینیجر کیش {#package-manager-caches}

روزمرہ کی مکمل محفوظ صفائی ان کیش جڑوں کی چھانٹی کر سکتی ہے۔ بعد میں کوئی پیکیج دوبارہ انسٹال کرنے پر ڈاؤن لوڈ کی ضرورت پڑ سکتی ہے۔

| کیش | ہدف جڑ |
|---|---|
| Yarn Berry | `~/.yarn/berry/cache` |
| npm | `~/.npm/_cacache` |
| npx | `~/.npm/_npx` |
| pnpm store | `~/.local/share/pnpm/store` |
| pnpm cache | `~/.cache/pnpm` |
| bun | `~/.bun/install/cache` |
| deno | `~/.cache/deno` |
| Composer | `~/.cache/composer` |
| pip | `~/.cache/pip` |

Yarn v1 کے کھولے گئے پیکیجز `~/.cache/yarn` میں پورے اندراج کی صورت چھانٹے جاتے ہیں۔ گلوبل انسٹال شدہ پیکیجز اور پیکیج مینیجرز کی انسٹال جڑیں ان کیش سے الگ ہیں۔

## براؤزر اور ایپلیکیشن کیش {#browser-and-application-caches}

روزمرہ کے اہداف میں ترتیب دیے گئے براؤزر کیش، Gradle ورژن اکائیاں، Cypress اور Playwright بائنریز، اور TypeScript واچر کیش شامل ہیں۔ اگلی بار استعمال پر براؤزر یا بلڈ ٹول کو حذف شدہ مواد دوبارہ بنانا یا ڈاؤن لوڈ کرنا پڑ سکتا ہے۔ موجودہ Gradle ڈسٹری بیوشن اور موجودہ Android Studio ورژن اپنے اصولوں سے محفوظ رہتے ہیں؛ اہل پرانی اکائی پوری حذف ہوتی ہے تاکہ آدھی حذف شدہ انسٹالیشن پیچھے نہ رہے۔

فائل کی سطح پر چھانٹی سے پہلے موڈ آخری رسائی اور ترمیم کا وقت جانچتا ہے۔ جس فائل سسٹم میں رسائی کا وقت قابل اعتماد نہ ہو وہاں عمر کی بنیاد پر چھانٹی نہیں ہوتی۔ `--purge-all` عمر کی یہ رکاوٹ ہٹا دیتا ہے اور اس کے لیے الگ فیصلہ چاہیے۔

## ڈویلپر ٹولز کا ڈیٹا {#developer-tool-data}

اسکین Android AVDs، Flutter pub کیش، Flatpak یوزر ڈیٹا اور دوسری بڑی جڑیں دکھا سکتا ہے۔ **کسی پاتھ کا اسکین میں دکھنا اس بات کا وعدہ نہیں کہ `--all-safe` اسے حذف کرے گا۔** چنا ہوا موڈ اصل میں کیا ہدف بناتا ہے، یہ جاننے کے لیے اس موڈ کا صفحہ اور آزمائشی رن کا نتیجہ پڑھیں۔ Android ایمولیٹرز اور انسٹال شدہ Flatpak ایپس روزمرہ کیش نہیں ہیں۔

## ایڈیٹر ایکسٹینشنز {#editor-extensions}

`--editor-ext` VS Code اور Cursor کے ان ایکسٹینشن ورژنز کو دیکھتا ہے جن کی جگہ نیا ورژن آ چکا ہو۔ اس کے لیے نیا ورژن اور غیر استعمال شدہ پرانا ورژن ضروری ہے؛ موجودہ ورژن رکھا جاتا ہے۔ دیکھیں [ایڈیٹر ایکسٹینشنز](../modes/editor-extensions.md)۔

## پروجیکٹ اور ذاتی فائلیں — صرف انٹرایکٹو {#project-and-personal-files--interactive-only}

پرانے پروجیکٹس کے `node_modules`، ادھورے ڈاؤن لوڈز اور بڑی غیر استعمال شدہ ذاتی فائلوں کے امیدوار الگ انٹرایکٹو موڈز استعمال کرتے ہیں۔ `--yes` ان موڈز کی منظوری نہیں دیتا۔ کوئی ادھورا ڈاؤن لوڈ یا `~/Downloads` کی فائل آپ کی واحد کاپی ہو سکتی ہے۔ تصدیق سے پہلے ہر پاتھ اور اس کا نتیجہ پڑھیں۔

## سسٹم کی صفائی (sudo درکار) {#system-cleanup-requires-sudo}

`--system` اپنے apt، جرنل، Snap، `/tmp` اور پیج کیش کے مراحل سے پہلے پوچھتا ہے۔ اس کے پیکیج کمانڈز `apt` اور `dpkg` استعمال کرتے ہیں؛ یہ Fedora، Arch یا openSUSE کے مطابق نہیں بدلتے۔ کرنل کا مرحلہ انسٹال شدہ ورژنز کی فہرست دیتا ہے؛ کسی کو براہ راست حذف نہیں کرتا۔ جرنل کی صفائی کا ہدف 100 MB ہے، اور `/tmp` کے لیے عمر 7 دن ہے چاہے `--days` کچھ بھی ہو۔ پیج کیش خالی کرنے کا اثر RAM پر ہوتا ہے، ڈسک کی جگہ پر نہیں۔ دیکھیں [سسٹم کی صفائی](../modes/system-cleanup.md) اور [ڈسٹرو سپورٹ](../distro-support.md)۔

## یہ کیا حذف کرنے سے انکار کرتا ہے {#what-it-refuses-to-delete}

حفاظت روٹ اور محفوظ ہوم پاتھس، جیسے `~/Documents`، `~/Pictures`، `~/.ssh`، `~/.config` اور `~/.claude`، کو رد کرتی ہے۔ مکمل فہرست اور اس کے استثنا [محفوظ پاتھس](../reference/protected-paths.md) میں ہیں۔ `--self-test` انسٹال شدہ کاپی میں چند منتخب انکار کی صورتیں جانچتا ہے۔

اصل حذف کی کوئی واپسی نہیں۔ [حذف سے پہلے پری ویو](./preview-first.md) صفائی سے پہلے اپنانے والی ترتیب بتاتا ہے۔
