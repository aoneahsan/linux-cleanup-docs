# ایپ کے مسائل کا حل

ایپ کی **مدد › خرابیاں اور آف لائن** اسکرین یہی صورتیں ہر ایک کے بٹن کے ساتھ سنبھالتی ہے۔ یہ صفحہ اس کا تفصیلی روپ ہے۔

## AppImage نہیں کھلتی {#the-appimage-does-not-open}

- **ڈبل کلک پر کچھ نہیں ہوتا۔** فائل قابل عمل ہونی چاہیے: `chmod +x linux-cleanup_*_amd64.AppImage`۔
- **خرابی میں FUSE کا ذکر ہے۔** AppImage خود کو FUSE 2 سے ماؤنٹ کرتی ہے۔ Ubuntu 22.04 اور بعد کے ورژن اسے ڈیفالٹ طور پر انسٹال نہیں کرتے: `sudo apt install libfuse2` (Ubuntu 24.04 پر `libfuse2t64`)۔ اس کے بغیر AppImage کو `./linux-cleanup_*_amd64.AppImage --appimage-extract-and-run` سے بھی چلایا جا سکتا ہے۔
- **خرابی میں WebKitGTK یا `libwebkit2gtk-4.1` کا ذکر ہے۔** ونڈو کو آپ کی ڈسٹری بیوشن کا WebKitGTK 4.1 چاہیے۔ Debian اور Ubuntu پر `.deb` اسے ساتھ لے آتا ہے؛ AppImage کے ساتھ `libwebkit2gtk-4.1-0` انسٹال کریں۔

## ایپ کہتی ہے کہ شامل CLI غائب ہے {#the-app-says-the-bundled-cli-is-missing}

ایپ شروع ہونے پر `cleanup.sh` کی اپنی کاپی جانچتی ہے۔ اگر یہ جانچ ناکام ہو تو انسٹالیشن خراب ہے: ریلیز [ڈاؤن لوڈ صفحے](https://linux-cleanup.aoneahsan.com/download) سے دوبارہ ڈاؤن لوڈ کریں۔ دوبارہ انسٹال کرنے سے آپ کی رسیدیں، رپورٹس اور لاگز نہیں چھوئے جاتے۔

## سائن اِن مکمل نہیں ہوتا {#sign-in-does-not-finish}

سائن اِن آپ کے براؤزر میں ہوتا ہے اور `127.0.0.1` کے ذریعے ایپ پر لوٹتا ہے۔ اگر براؤزر نتیجہ دکھائے مگر ایپ آگے نہ بڑھے تو شاید کوئی فائر وال یا براؤزر ایکسٹینشن مقامی پتوں کو روک رہی ہے۔ ناکام سائن اِن سے کچھ نہیں بدلتا؛ **Google سے سائن اِن کریں** دوبارہ دبایا جا سکتا ہے۔

## اکاؤنٹ سرور جواب نہیں دیتا {#the-account-server-does-not-answer}

آزمائشی رن، اصل رن، رسیدوں اور شیڈول کو کبھی انٹرنیٹ نہیں چاہیے۔ آف لائن ہونے پر ایپ اصل رن اس کمپیوٹر کے ماہانہ حصے میں گنتی رہتی ہے اور سرور کے دوبارہ جواب دینے پر سنک کرتی ہے۔ صرف پلان کی تبدیلیاں اور سنک ہونے والی ہسٹری انتظار کرتی ہیں۔

## کوئی شیڈول نہیں چلا {#a-schedule-did-not-run}

```bash
systemctl --user list-timers 'linux-cleanup-schedule-*'
journalctl --user -u 'linux-cleanup-schedule-*' --since today
```

ٹائمر صرف تب چلتا ہے جب آپ لاگ اِن ہوں؛ کمپیوٹر بند رہتے چھوٹا ہوا رن اگلے لاگ اِن پر چلتا ہے۔ ہر شروع ہوا رن اپنا سلسلہ `~/.linux-cleanup/schedule-runs/` میں چھوڑتا ہے، اور اگلی بار کھولنے پر ایپ اسے رسید میں بدل دیتی ہے۔
