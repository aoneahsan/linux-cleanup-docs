# انسٹال اور اپ ڈیٹ

موجودہ ریلیز [ڈاؤن لوڈ صفحے](https://linux-cleanup.aoneahsan.com/download) سے ڈاؤن لوڈ کریں؛ ہر ریلیز `desktop-v<version>` ٹیگ کے تحت [GitHub Releases](https://github.com/aoneahsan/linux-cleanup/releases) پر بھی موجود ہے۔ ہر ریلیز میں دو انسٹالرز ہوتے ہیں:

| فائل | کس کے لیے |
|---|---|
| `linux-cleanup_<version>_amd64.AppImage` | ڈیسک ٹاپ سیشن والی کوئی بھی ڈسٹری بیوشن۔ اسے قابل عمل بنائیں، پھر چلائیں |
| `linux-cleanup_<version>_amd64.deb` | Debian، Ubuntu اور ان سے بنی ڈسٹروز (`sudo apt install ./linux-cleanup_<version>_amd64.deb`) |

```bash
chmod +x linux-cleanup_*_amd64.AppImage
./linux-cleanup_*_amd64.AppImage
```

ورژن 1.0.4 سے AppImage پہلی بار چلنے پر خود کو آپ کے ایپلیکیشن مینو میں شامل کرتی ہے: یہ `~/.local/share/applications/linux-cleanup-desktop.desktop` اور `~/.local/share/icons/hicolor/` کے تحت اپنا آئیکن لکھتی ہے، اور اندراج کو وہیں کی طرف رکھتی ہے جہاں فائل ہو۔ اگر آپ AppImage کہیں اور منتقل کریں تو نئی جگہ سے ایک بار چلائیں، اندراج ساتھ آ جائے گا۔ `.deb` اپنا مینو اندراج خود انسٹال کرتا ہے۔

ڈیسک ٹاپ ایپ کو WebKitGTK 4.1 اور GTK 3 چاہیے، جو موجودہ ڈیسک ٹاپ ڈسٹری بیوشنز میں آتے ہیں۔ `.deb` انہیں انحصار کے طور پر ظاہر کرتا ہے۔

## یہ کیسے اپ ڈیٹ ہوتی ہے {#how-it-updates}

ایپ خود کو اپ ڈیٹ کرتی ہے۔ یہ شروع ہونے پر، ونڈو دوبارہ نظر آنے پر، اور نئی ریلیز شائع ہوتے ہی دستخط شدہ اپ ڈیٹ جانچتی ہے۔ **اپ ڈیٹس خود بخود انسٹال کریں** آن ہو (ڈیفالٹ) تو یہ اپ ڈیٹ ڈاؤن لوڈ کرتی ہے، اس کا دستخط جانچتی ہے، اور کسی پرسکون لمحے میں دوبارہ شروع ہوتی ہے: کبھی رن کے دوران نہیں۔

**AppImage** اپنی جگہ بدل دی جاتی ہے۔ **`.deb`** انسٹال `dpkg` کے ذریعے اپ ڈیٹ ہوتا ہے، اس لیے آپ کا ڈیسک ٹاپ پہلے ایڈمنسٹریٹر پاس ورڈ مانگتا ہے (معمول کی گرافیکل ونڈو)؛ اسے منسوخ کرنے پر موجودہ ورژن چلتا رہتا ہے۔

کسی ریلیز کو **لازمی** بھی قرار دیا جا سکتا ہے:

- **فوری** ریلیز ایپ کو فوراً روکتی ہے، وجہ بتاتی ہے، اور ایک **اپ ڈیٹ** بٹن دیتی ہے؛
- **عام** ریلیز بتاتی ہے کہ نیا ورژن آیا ہے، اور اگلے آغاز سے وہ لازمی ہو جاتا ہے۔

اگر جانچ کے وقت ایپ آف لائن ہو تو وہ چلتی رہتی ہے؛ ناکام جانچ کبھی کسی رن کو نہیں روکتی۔
