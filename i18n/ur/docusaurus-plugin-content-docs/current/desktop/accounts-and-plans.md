# اکاؤنٹس اور پلانز

|---|---|---|---|

قیمتیں اور حدود ان پلان ریکارڈز میں طے ہیں جنہیں ایپ اور ویب سائٹ دونوں پڑھتی ہیں؛ [قیمتوں کا صفحہ](https://linux-cleanup.aoneahsan.com/pricing) موجودہ اعداد دکھاتا ہے۔
