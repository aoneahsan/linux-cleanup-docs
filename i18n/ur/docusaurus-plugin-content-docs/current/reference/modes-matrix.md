## وہ موڈز جو کبھی کچھ حذف نہیں کرتے {#modes-that-never-delete-anything}

یہ کمانڈز صفائی کے اہداف حذف نہیں کرتیں۔ کچھ مقامی لاگز، رپورٹس، ایکسپورٹس یا تشخیصی بنڈلز لکھتی ہیں:

`--scan` · `--audit` · `--globals` · `--list-targets` · `--self-test` · `--version` · `--export` ·
`--feedback` · `--debug-bundle`

`--doctor` بھی یہیں آتا ہے، ایک شرط کے ساتھ: یہ آپ کی شیل کنفیگریشن بدلتا ہے، مگر صرف تصدیق کے بعد **شامل کر کے**۔ یہ کسی موجودہ لائن کو کبھی حذف نہیں کرتا یا دوبارہ نہیں لکھتا۔

## وہ موڈز جن پر `--yes` اثر کرتا ہے {#modes---yes-affects}

صرف ایک: [`--all-safe`](../modes/all-safe.md)۔

ذاتی ڈیٹا والے انٹرایکٹو موڈز — `--stale`، `--partials`، `--node-modules` — اپنی الگ تصدیق مانگتے ہیں۔ دیکھیں [رکاوٹ 3](../safety/guards.md#guard-3--personal-data-is-interactive-only)۔

## وہ موڈز جن پر غیر فعالیت کی رکاوٹ لاگو ہوتی ہے {#modes-the-staleness-gate-applies-to}

| لاگو | لاگو نہیں |
|---|---|
| واک تھرو، مینو، TUI اور مکمل محفوظ میں کیش کی چھانٹی | `--system` (اپنا مقرر 7 دن کا `/tmp` اصول استعمال کرتا ہے) |
| `--editor-ext` میں پرانے ورژن ہٹانا | `--partials` (عمر معیار نہیں) |
| `--node-modules` | صرف پڑھنے والے موڈز (کچھ حذف نہیں ہوتا) |
| `--stale` |  |
| ڈیولپر ٹول ڈیٹا (AVD، flatpak، pub-cache) |  |

جہاں رکاوٹ ویسے لاگو ہوتی، وہاں `--purge-all` اسے بند کر دیتا ہے۔

## کن موڈز کو اختیاری انحصار چاہیے {#which-modes-need-optional-dependencies}

| موڈ | چاہیے | نہ ہو تو |
|---|---|---|
| `--tui` | `whiptail` یا `dialog` | انسٹال کی ہدایت کے ساتھ `--menu` پر لوٹتا ہے |
| `--export`، `--reports` تبدیلی | `jq` | JSON پھر بھی لکھا جاتا ہے؛ تبدیلی دستیاب نہیں |
| `--install-cron` | `crontab` | نہیں چل سکتا |
| `--system` کا snap مرحلہ | `snap` | مرحلہ صاف طور پر چھوڑ دیا جاتا ہے |
| `--system` کے apt مراحل | `apt`، `dpkg` | **ناکام** — [صرف Debian/Ubuntu](../distro-support.md) |
