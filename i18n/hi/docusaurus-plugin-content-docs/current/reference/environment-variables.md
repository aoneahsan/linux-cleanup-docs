# एनवायरनमेंट वेरिएबल

**linux-cleanup जो भी एनवायरनमेंट वेरिएबल पढ़ता है।** सब वैकल्पिक हैं।

| वेरिएबल | डिफ़ॉल्ट | असर |
|---|---|---|
| `NO_COLOR` | सेट नहीं | कोई भी ख़ाली न होने वाला मान ANSI रंग बंद करता है। [no-color.org](https://no-color.org) का सभी टूल वाला मानक। `--no-color` जैसा ही |
| `CLEANUP_NO_COLOR` | `0` | linux-cleanup का अपना रंग स्विच। केवल यहाँ रंग बंद करने के लिए `1` करें |
| `LINUX_CLEANUP_LOG_DIR` | `~/.linux-cleanup/logs/` (npx / npm) या `<repo>/logs/` (क्लोन) | सत्र लॉग कहाँ जाते हैं। न हो तो बनता है |
| `LINUX_CLEANUP_REPORTS_DIR` | `~/.linux-cleanup/reports/` या `<repo>/reports/` | JSON सत्र रिकॉर्ड कहाँ जाते हैं। न हो तो बनता है |
| `LINUX_CLEANUP_DATA_HOME` | सेट नहीं — लॉग फ़ोल्डर के ऊपर वाले फ़ोल्डर पर लौटता है | `logs/`, `reports/` और `feedback/` तीनों का ऊपर वाला फ़ोल्डर |
| `LINUX_CLEANUP_NPX` | सेट नहीं | **भीतरी।** Node लॉन्चर इसे `1` करता है। खुद सेट न करें |
| `LINUX_CLEANUP_LAUNCHER` | सेट नहीं | **भीतरी।** Node लॉन्चर `node` सेट करता है; डेस्कटॉप ऐप `desktop` सेट करता है, जिससे CLI की अपनी अपडेट जाँच छूट जाती है क्योंकि ऐप अपनी जाँच करता है (2.1.0 से)। खुद सेट न करें |
| `XDG_CONFIG_HOME` | `~/.config` | `personal-roots.txt` और `project-roots.txt` कहाँ खोजे जाते हैं |

## सारा आउटपुट कहीं और भेजना

`LINUX_CLEANUP_DATA_HOME` वह अकेला लीवर है जो सब कुछ हटाता है — लॉग, रिकॉर्ड और फ़ीडबैक बंडल:

```bash
export LINUX_CLEANUP_DATA_HOME="/mnt/secure/linux-cleanup"
linux-cleanup --scan
```

:::caution फ़ोल्डर बनता है, माउंट नहीं
टूल आपके दिए पथ के नीचे `logs/`, `reports/` और `feedback/` बनाता है। यह नीचे वाला माउंट पॉइंट **नहीं** बनाता और न उसकी जाँच करता है। किसी अनमाउंटेड पथ पर इशारा करें तो आउटपुट चुपचाप नीचे वाले फ़ाइल सिस्टम पर पहुँच जाता है।

इस पर भरोसा करने से पहले जाँचें कि लक्ष्य माउंटेड और लिखने योग्य है।
:::

बारीक नियंत्रण के लिए `LINUX_CLEANUP_LOG_DIR` और `LINUX_CLEANUP_REPORTS_DIR` अलग-अलग बदलते हैं और डेटा होम से ऊपर माने जाते हैं।

## रंग नियंत्रण

```bash
export NO_COLOR=1          # इस मशीन पर सब कुछ, सभी टूल
export CLEANUP_NO_COLOR=1  # केवल linux-cleanup
linux-cleanup --no-color   # केवल यह एक बार
```

`CLEANUP_NO_COLOR` उस हालत के लिए है जब आप बाकी हर टूल से रंग चाहते हैं और इससे सादा आउटपुट — आम तौर पर तब, जब इसका आउटपुट किसी ऐसी जगह पाइप होता है जो एस्केप क्रम बिगाड़ देती है।

## स्कैन होने वाले रूट तय करना

`$XDG_CONFIG_HOME` (डिफ़ॉल्ट `~/.config`) के नीचे दो फ़ाइलें तय करती हैं कि निजी और प्रोजेक्ट स्कैनर किन फ़ोल्डरों में जाते हैं:

| फ़ाइल | किसके लिए | डिफ़ॉल्ट रूट |
|---|---|---|
| `personal-roots.txt` | [`--stale`](../modes/personal-stale-files.md) | `~/Downloads`; `~/Desktop` जैसे संरक्षित रूट अनदेखे होते हैं |
| `project-roots.txt` | [`--node-modules`](../modes/node-modules-finder.md) | आपके प्रोजेक्ट फ़ोल्डर |

हर पंक्ति में एक पथ। यह [XDG Base Directory विनिर्देश](https://specifications.freedesktop.org/basedir-spec/) मानता है, इसलिए `XDG_CONFIG_HOME` सेट करने से दोनों की जगह बदलती है।

:::danger `personal-roots.txt` में रूट जोड़ने से हटाए जा सकने वाला दायरा बढ़ता है
निजी स्कैनर [केवल इंटरैक्टिव](../safety/guards.md#guard-3--personal-data-is-interactive-only) है, इसलिए हर फ़ाइल की आपकी पुष्टि के बिना कुछ नहीं हटता — पर आपका जोड़ा रूट ऐसा फ़ोल्डर है जिसकी सामग्री उम्मीदवार सूचियों में दिखने लगेगी।

[पथ अनुमति सूची](./protected-paths.md) फिर भी लागू है और जीतती है: यहाँ `~/Documents` जोड़ने से वह हटाने योग्य नहीं बनता।
:::

## CI और स्क्रिप्ट के लिए

```bash
NO_COLOR=1 linux-cleanup --scan > /tmp/scan.log
```

अलग से चलने वाला स्कैन वॉकथ्रू की JSON सत्र रिपोर्ट नहीं बनाता। स्क्रिप्ट में [एग्ज़िट कोड](./exit-codes.md) देखें, या ढाँचेदार आउटपुट के लिए [`--json-events`](./json-events.md) इस्तेमाल करें।

## यह क्या नहीं पढ़ता

- `PATH`, सिवाय यह जानने के कि कौन-से वैकल्पिक टूल इंस्टॉल हैं
- `USER` और `LOGNAME`, सिवाय लॉग के शीर्ष पर लिखने के
- आपका शेल इतिहास, एलियास या कॉन्फ़िगरेशन — [`--doctor`](../modes/doctor.md) अकेला मोड है जो शेल की शुरुआती फ़ाइलें पढ़ता है, और केवल यह देखने के लिए कि कोई रनटाइम जुड़ा है या नहीं
- कोई भी रिमोट या नेटवर्क से मिलने वाली कॉन्फ़िगरेशन। ऐसी कोई नहीं है

अगर `$HOME` सेट नहीं है तो स्क्रिप्ट अंदाज़ा लगाने के बजाय तुरंत रुक जाती है। देखें [समस्या निवारण](../troubleshooting.md#home-is-not-set)।
