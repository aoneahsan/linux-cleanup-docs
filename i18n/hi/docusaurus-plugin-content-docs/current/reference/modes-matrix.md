## वे मोड जो कभी कुछ नहीं हटाते {#modes-that-never-delete-anything}

ये कमांड सफ़ाई के लक्ष्य नहीं हटाते। कुछ स्थानीय लॉग, रिपोर्ट, एक्सपोर्ट या डायग्नॉस्टिक बंडल लिखते हैं:

`--scan` · `--audit` · `--globals` · `--list-targets` · `--self-test` · `--version` · `--export` ·
`--feedback` · `--debug-bundle`

`--doctor` भी यहीं आता है, एक शर्त के साथ: यह आपकी शेल कॉन्फ़िगरेशन बदलता है, पर केवल पुष्टि के बाद **जोड़कर**। यह किसी मौजूदा पंक्ति को कभी हटाता या दोबारा नहीं लिखता।

## वे मोड जिन पर `--yes` असर करता है {#modes---yes-affects}

सिर्फ़ एक: [`--all-safe`](../modes/all-safe.md)।

निजी डेटा वाले इंटरैक्टिव मोड — `--stale`, `--partials`, `--node-modules` — अपनी अलग पुष्टि माँगते हैं। देखें [रोक 3](../safety/guards.md#guard-3--personal-data-is-interactive-only)।

## वे मोड जिन पर निष्क्रियता की रोक लागू होती है {#modes-the-staleness-gate-applies-to}

| लागू | लागू नहीं |
|---|---|
| वॉकथ्रू, मेन्यू, TUI, पूरी तरह सुरक्षित में कैश छँटाई | `--system` (अपना तय 7 दिन का `/tmp` नियम इस्तेमाल करता है) |
| `--editor-ext` में पुराने संस्करण हटाना | `--partials` (उम्र कसौटी नहीं है) |
| `--node-modules` | केवल-पढ़ने वाले मोड (कुछ नहीं हटता) |
| `--stale` |  |
| डेवलपर टूल डेटा (AVD, flatpak, pub-cache) |  |

जहाँ रोक वैसे लागू होती, वहाँ `--purge-all` उसे बंद कर देता है।

## किन मोड को वैकल्पिक निर्भरताएँ चाहिए {#which-modes-need-optional-dependencies}

| मोड | चाहिए | न हो तो |
|---|---|---|
| `--tui` | `whiptail` या `dialog` | इंस्टॉल संकेत के साथ `--menu` पर लौटता है |
| `--export`, `--reports` रूपांतरण | `jq` | JSON फिर भी लिखा जाता है; रूपांतरण नहीं होता |
| `--install-cron` | `crontab` | नहीं चल सकता |
| `--system` का snap चरण | `snap` | चरण साफ़ तरीके से छोड़ा जाता है |
| `--system` के apt चरण | `apt`, `dpkg` | **विफल** — [केवल Debian/Ubuntu](../distro-support.md) |
