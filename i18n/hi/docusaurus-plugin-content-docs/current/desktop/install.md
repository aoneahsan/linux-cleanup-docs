# इंस्टॉल और अपडेट

मौजूदा रिलीज़ [डाउनलोड पेज](https://linux-cleanup.aoneahsan.com/download) से डाउनलोड करें; हर रिलीज़ `desktop-v<version>` टैग के तहत [GitHub Releases](https://github.com/aoneahsan/linux-cleanup/releases) पर भी है। हर रिलीज़ में दो इंस्टॉलर होते हैं:

| फ़ाइल | किसके लिए |
|---|---|
| `linux-cleanup_<version>_amd64.AppImage` | डेस्कटॉप सत्र वाला कोई भी डिस्ट्रीब्यूशन। इसे चलने लायक बनाएँ, फिर चलाएँ |
| `linux-cleanup_<version>_amd64.deb` | Debian, Ubuntu और उनसे बने डिस्ट्रो (`sudo apt install ./linux-cleanup_<version>_amd64.deb`) |

```bash
chmod +x linux-cleanup_*_amd64.AppImage
./linux-cleanup_*_amd64.AppImage
```

संस्करण 1.0.4 से AppImage पहली बार चलने पर ख़ुद को आपके ऐप्लिकेशन मेन्यू में जोड़ता है: यह `~/.local/share/applications/linux-cleanup-desktop.desktop` और `~/.local/share/icons/hicolor/` के नीचे अपना आइकन लिखता है, और प्रविष्टि को फ़ाइल जहाँ भी हो वहीं की ओर रखता है। अगर आप AppImage को कहीं और ले जाएँ, तो नई जगह से एक बार चलाएँ और प्रविष्टि साथ आ जाएगी। `.deb` अपनी मेन्यू प्रविष्टि ख़ुद इंस्टॉल करता है।

डेस्कटॉप ऐप को WebKitGTK 4.1 और GTK 3 चाहिए, जो मौजूदा डेस्कटॉप डिस्ट्रीब्यूशन में आते हैं। `.deb` इन्हें निर्भरता के रूप में बताता है।

## यह कैसे अपडेट होता है {#how-it-updates}

ऐप ख़ुद को अपडेट करता है। यह शुरू होने पर, विंडो फिर दिखने पर, और नई रिलीज़ प्रकाशित होते ही हस्ताक्षरित अपडेट जाँचता है। **अपडेट अपने आप इंस्टॉल करें** चालू हो (डिफ़ॉल्ट) तो यह अपडेट डाउनलोड करता है, उसका हस्ताक्षर जाँचता है, और किसी शांत पल में फिर शुरू होता है: रन चलते समय कभी नहीं।

**AppImage** अपनी जगह बदल दिया जाता है। **`.deb`** इंस्टॉल `dpkg` के ज़रिए अपडेट होता है, इसलिए आपका डेस्कटॉप पहले एडमिनिस्ट्रेटर पासवर्ड माँगता है (सामान्य ग्राफ़िकल प्रॉम्प्ट); इसे रद्द करने पर मौजूदा संस्करण चलता रहता है।

किसी रिलीज़ को **ज़रूरी** भी बताया जा सकता है:

- **तत्काल** रिलीज़ ऐप को तुरंत रोकती है, कारण बताती है, और एक **अपडेट** बटन देती है;
- **सामान्य** रिलीज़ बताती है कि नया संस्करण आया है, और अगली शुरुआत से वह ज़रूरी हो जाता है।

अगर जाँच के समय ऐप ऑफ़लाइन हो, तो वह चलता रहता है; विफल जाँच कभी किसी रन को नहीं रोकती।
