# Linux क्लीनर की तुलना

हर टूल का वर्णन उसकी अपनी वेबसाइट या रिपॉज़िटरी से किया गया है, जाँच की तारीख़ के साथ। जो बात उनके पेजों पर नहीं लिखी, उसे “जाँचे गए पेजों पर नहीं बताया गया” लिखा जाता है, कभी “नहीं” नहीं।
