# मेन्यू

**`--menu` हर श्रेणी की नंबर वाली सूची छापता है और आपकी चुनी हुई चलाता है।** इसे तब इस्तेमाल करें जब आपको पता हो कि क्या चाहिए और दस चरणों के दौरे की ज़रूरत न हो।

```bash
linux-cleanup --menu     # या: -m, -i, --interactive
```

## यह वॉकथ्रू से कैसे अलग है {#how-it-differs-from-the-walkthrough}

| | मेन्यू | [वॉकथ्रू](./walkthrough.md) |
|---|---|---|
| क्रम | आप चुनते हैं | तय, दस चरण |
| दायरा | हर चुनाव में एक श्रेणी | सब कुछ, क्रम से |
| दोहराव | बाद में मेन्यू पर लौटता है | अंत तक चलता है |
| रिपोर्ट | हर कार्रवाई की | पूरे सत्र की एक |
| किसके लिए बेहतर | निशाना लगाकर सफ़ाई | पहले रन, पूरी सफ़ाई |

सुरक्षा मॉडल बिल्कुल वही है। हर श्रेणी ठीक वैसे ही बर्ताव करती है जैसे वॉकथ्रू में — [अनुमति-सूची](../safety/guards.md#guard-1--the-path-allowlist), [निष्क्रियता जाँच](../safety/guards.md#guard-2--the-staleness-gate) और हर लक्ष्य की पुष्टि, सब लागू रहते हैं। मेन्यू से निजी डेटा वाली श्रेणी चुनने पर भी हर प्रविष्टि के लिए पूछा जाता है, और `--yes` का उस पर अब भी कोई असर नहीं।

## विकल्प फिर भी लागू होते हैं {#options-still-apply}

```bash
linux-cleanup --menu -d 30        # जो भी चुनें उसके लिए 30 दिन की सीमा
linux-cleanup --menu --purge-all  # निष्क्रियता जाँच बंद
linux-cleanup --menu --no-color   # सादा आउटपुट
```

## TUI कब इस्तेमाल करें {#when-to-use-the-tui-instead}

[`--tui`](./tui.md) वही मेन्यू है, whiptail या dialog बॉक्स के रूप में। उसके लिए इनमें से एक इंस्टॉल होना चाहिए; `--menu` को bash के अलावा कुछ नहीं चाहिए और यह किसी भी कनेक्शन पर चलता है, सादे टर्मिनल या ऐसे `ssh -T` सत्र में भी जहाँ फ़ुल-स्क्रीन डायलॉग गड़बड़ करे।
