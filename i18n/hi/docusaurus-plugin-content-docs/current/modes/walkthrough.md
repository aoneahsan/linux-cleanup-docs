# वॉकथ्रू (डिफ़ॉल्ट)

**बिना फ़्लैग `linux-cleanup` चलाने पर गाइडेड वॉकथ्रू शुरू होता है: हर सफ़ाई श्रेणी से गुज़रते दस चरण, हर एक कुछ करने से पहले पूछता है।** टूल को इंटरैक्टिव रूप से इस्तेमाल करने का यही सुझाया तरीका है।

```bash
linux-cleanup          # या: linux-cleanup -w / --walkthrough
```

## दस चरण {#the-ten-steps}

| # | चरण | हटाता है | टिप्पणी |
|---|---|---|---|
| 1 | पैकेज मैनेजर कैश | दोबारा बन सकने वाला | yarn, npm, npx, pnpm, pip, composer, bun, deno |
| 2 | ऐप्लिकेशन कैश | दोबारा बन सकने वाला | ब्राउज़र, Gradle, Cypress, Playwright, Zoom, एडिटर VSIX |
| 3 | डेवलपर टूल का डेटा | केवल पुराना | Android AVD, pub-cache, Dart analysis, flatpak |
| 4 | एडिटर के पुराने एक्सटेंशन | पुराना + नए से बदला | VS Code / Cursor |
| 5 | पुराने `node_modules` | **इंटरैक्टिव** | सीमा से ज़्यादा निष्क्रिय प्रोजेक्ट |
| 6 | अधूरे / अनाथ डाउनलोड | **इंटरैक्टिव** | `.crdownload`, `.part`, `.fdmdownload` |
| 7 | पुरानी निजी फ़ाइलें | **इंटरैक्टिव** | `~/Downloads` और आपके तय किए निजी रूट में बड़ी निष्क्रिय फ़ाइलें |
| 8 | सिस्टम सफ़ाई (sudo) | सिस्टम | apt, जर्नल, snap, `/tmp`, पेज कैश |
| 9 | आख़िरी आकार जाँच | कुछ नहीं | केवल-पढ़ने वाला सार |
| 10 | पढ़ने लायक रिपोर्ट बनाना | कुछ नहीं | Markdown / HTML एक्सपोर्ट — `jq` चाहिए |

चरण 5, 6 और 7 [केवल इंटरैक्टिव](../safety/guards.md#guard-3--personal-data-is-interactive-only) हैं। इनकी अपने आप पुष्टि नहीं हो सकती, और पूरे टूल में चरण 7 अकेला ऐसा है जो सच में अपूरणीय चीज़ हटा सकता है।

## प्रॉम्प्ट कैसे काम करते हैं {#how-the-prompts-work}

पुष्टि के दो स्तर।

**हर चरण पर**, आप तय करते हैं कि पूरी श्रेणी का क्या करना है:

| कुंजी | असर |
|---|---|
| `a` | यह चरण चलाएँ। यही डिफ़ॉल्ट है — Enter इसे चुनता है |
| `s` | यह चरण पूरी तरह छोड़ें |
| `q` | अब तक की प्रगति रखते हुए वॉकथ्रू अभी बंद करें |

**हर लक्ष्य पर**, जिस चरण को आपने चलाना चुना उसके भीतर हर चीज़ की अपनी `[Y/n]` या `[y/N]` पुष्टि होती है। बड़ा अक्षर डिफ़ॉल्ट है।

यानी चरण के स्तर पर `a` का मतलब यह नहीं कि आपने उसमें सब कुछ हटाने की हामी भर दी — आप फिर भी हर लक्ष्य देखते और उसका जवाब देते हैं।

## चलते हुए कुल {#running-totals}

हर चले चरण के बाद टूल उसका मापा गया बदलाव और अब तक का सत्र कुल छापता है।

आख़िरी सार पहले और बाद की ख़ाली डिस्क जगह बताता है। यह आँकड़ा `df` से मापा जाता है, इसलिए मशीन पर होने वाली हर चीज़ इसमें झलकती है — अगर आपके सत्र के दौरान कोई बिल्ड चला, तो बताई गई बचत चरणों के जोड़ से कम, या नकारात्मक भी, हो सकती है। यह बग नहीं है; देखें [समस्या निवारण](../troubleshooting.md#disk-usage-grew-during-the-session)।

## जल्दी रुकना {#quitting-early}

किसी भी चरण के प्रॉम्प्ट पर `q`, या कभी भी `Ctrl-C`, सत्र को साफ़ तरीके से ख़त्म करता है:

- पहले हुए हटाने स्थायी रहते हैं; रुकने से पहले आज़माए गए चरण लॉग में देखें
- `Ctrl-C` कोड `130` के साथ निकलता है, जिसे [क्रैश ट्रैप जानबूझकर अनदेखा करता है](../reference/exit-codes.md#how-the-crash-trap-decides), इसलिए कोई क्रैश बंडल नहीं लिखा जाता
- जिन चरणों तक नहीं पहुँचे, वे रिपोर्ट में छोड़े गए दर्ज होते हैं

## सत्र रिपोर्ट {#the-session-report}

वॉकथ्रू JSON रिपोर्ट `~/.linux-cleanup/reports/report-<timestamp>.json` में लिखता है, जब तक `--no-report` या `--dry-run` न लगा हो। इसमें हर चरण की स्थिति और ख़ाली हुए बाइट, पहले/बाद की डिस्क और मेमोरी, और सत्र के कुल होते हैं। पूरी फ़ील्ड सूची: [रिपोर्ट स्कीमा](../reference/report-schema.md)।

चरण 10 वैकल्पिक रूप से इसे Markdown और HTML में बदलता है। उस चरण को `jq` चाहिए; इसके बिना वह चरण `skipped (jq missing)` दर्ज होता है और JSON फिर भी लिखा जाता है।

```bash
linux-cleanup --no-report    # JSON बनाना छोड़ें; लॉग फिर भी लिखे जाते हैं
```

## साथ लगाने लायक विकल्प {#options-worth-combining}

```bash
linux-cleanup -d 30          # 100 के बजाय 30 दिन की निष्क्रियता सीमा
linux-cleanup --purge-all    # निष्क्रियता जाँच पूरी तरह बंद
linux-cleanup --no-color     # सादा आउटपुट
linux-cleanup --cleanup-logs # अंत में इस रन का लॉग हटाएँ
```

:::danger `--purge-all` बदल देता है कि चरण 1–4 क्या हटाते हैं
[निष्क्रियता जाँच](../safety/guards.md#guard-2--the-staleness-gate) बंद होने पर कैश वाले चरण निष्क्रिय फ़ाइलें छाँटने के बजाय अपने लक्ष्य पूरे मिटा देते हैं। इसमें Gradle wrapper वितरण, Playwright ब्राउज़र और Cypress बाइनरी भी आती हैं जो शायद आपको अब भी चाहिए हों। रन से पहले का बैनर बताता है कि कौन-सी रणनीति चालू है।
:::
