# TUI (विज़ुअल मेन्यू)

**`--tui` श्रेणी मेन्यू को फ़ुल-स्क्रीन whiptail या dialog बॉक्स में दिखाता है।** [1.3.0](../changelog.md#130--2026-05-10) में जोड़ा गया। व्यवहार [`--menu`](./menu.md) जैसा ही, बस दिखावट अलग।

```bash
linux-cleanup --tui      # या: -t, -g, --gui
```

## यह कैसे काम करता है {#how-it-behaves}

कोई प्रविष्टि चुनने पर डायलॉग से बाहर आकर वह श्रेणी सामान्य CLI आउटपुट और प्रॉम्प्ट के साथ चलती है, फिर मेन्यू पर लौटती है। यानी डायलॉग बस शुरू करने का ज़रिया है — असली पुष्टियाँ अब भी सामान्य टेक्स्ट प्रॉम्प्ट हैं, और हर सुरक्षा जाँच वैसी ही है।

TUI में एक **About** डायलॉग भी है जो संस्करण, संपर्क विवरण, लाइसेंस और निजता की गारंटी दिखाता है।

## ज़रूरतें और विकल्प {#requirements-and-fallback}

`whiptail` या `dialog` चाहिए। दोनों न हों तो टूल हर डिस्ट्रो के लिए इंस्टॉल का सुझाव छापता है और सामान्य CLI मेन्यू पर लौट जाता है — विफल नहीं होता।

```bash
sudo apt install whiptail     # Debian / Ubuntu
sudo dnf install newt         # Fedora / RHEL
sudo pacman -S libnewt        # Arch
```

RPM और Arch सिस्टम पर `whiptail` `newt` / `libnewt` पैकेज के भीतर आता है, इसलिए पैकेज का नाम कमांड के नाम से मेल नहीं खाता।

:::note सिर्फ़ यहीं टूल आपका डिस्ट्रो पहचानता है
ऊपर का इंस्टॉल सुझाव डिस्ट्रो के हिसाब से है। linux-cleanup में और कुछ नहीं — ख़ासकर [`--system` Debian/Ubuntu मानकर चलता है](../distro-support.md)।
:::

## सादा मेन्यू कब इस्तेमाल करें {#when-to-use-the-plain-menu}

`--tui` को ऐसा टर्मिनल चाहिए जो फ़ुल-स्क्रीन डायलॉग दिखा सके। सीमित कनेक्शन पर, CI लॉग के भीतर, या बिना TTY वाले `ssh -T` सत्र में [`--menu`](./menu.md) इस्तेमाल करें — इसे bash के अलावा कुछ नहीं चाहिए।
