# स्पीड जाँच

**`--speed` बताता है कि मशीन अपना समय कहाँ लगा रही है।** यह तापमान काउंटर, CPU, मेमोरी और I/O दबाव, भारी प्रक्रियाएँ और बूट जानकारी पढ़ता है। यह अपने आप शुरू होने वाले कंटेनर, सर्विस और लॉगिन ऐप भी ढूँढ सकता है।

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

ड्राई रन वे बदलाव बताता है जिनके बारे में वह पूछता, पर लागू नहीं करता। सामान्य रन हर प्रस्तावित बदलाव से पहले अलग से पूछता है; डिफ़ॉल्ट जवाब नहीं है। `--yes` इन सुधारों की अनुमति नहीं देता।

कुछ स्वीकार किए गए सुधार किसी कंटेनर को रोकते हैं, सर्विस बंद करते हैं या उपयोगकर्ता की लॉगिन सेटिंग बदलते हैं। ये कैश फ़ाइलें नहीं हटाते, पर अगली बार क्या शुरू होगा, इस पर असर डालते हैं। बदलाव लागू होने के बाद CLI एक अनडू कमांड छापता है। सिस्टम सर्विस के बदलाव पर sudo प्रॉम्प्ट आ सकता है।

कोई खोज एक माप या स्थिति है, इस बात का सबूत नहीं कि कोई ख़ास ऐप ख़राब है। बदलाव स्वीकार करने से पहले बताई गई प्रक्रिया या सर्विस पढ़ें और तय करें कि आपको उसकी ज़रूरत है या नहीं।

शेल की शुरुआत में ग़ायब रनटाइम कमांड के लिए अलग [डॉक्टर](./doctor.md) मोड इस्तेमाल करें। डिस्क जगह के लिए [स्कैन](./scan.md) से शुरू करें।
