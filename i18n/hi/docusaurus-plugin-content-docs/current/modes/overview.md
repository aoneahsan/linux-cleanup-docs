# मोड का सार

**linux-cleanup का एक ही प्रवेश है और मोड एक फ़्लैग से चुना जाता है।** बिना फ़्लैग चलाने पर [गाइडेड वॉकथ्रू](./walkthrough.md) मिलता है।

मोड एक-दूसरे को छोड़ते हैं — एक ही दें। `--days` और `--yes` जैसे विकल्प उनके साथ जुड़ते हैं।

## केवल पढ़ना — कभी कुछ नहीं हटाता {#read-only--never-deletes-anything}

ये मोड सफ़ाई लक्ष्य नहीं हटाते। ये फिर भी स्थानीय लॉग लिख सकते हैं, और ऑनलाइन होने पर रिलीज़ जाँच एक सार्वजनिक रिकॉर्ड पढ़ सकती है।

| मोड | फ़्लैग | दिखाता है |
|---|---|---|
| [स्कैन](./scan.md) | `-s` `--scan` | हर कैश श्रेणी, मौजूदा आकार के साथ |
| [होम जाँच](./home-audit.md) | `--audit` | `$HOME` की 20 सबसे बड़ी चीज़ें |
| [ग्लोबल पैकेज जाँच](./globals-audit.md) | `--globals` | npm/pnpm/yarn/bun/deno के ग्लोबल पैकेज |
| लक्ष्य सूची | `--list-targets` | हर पथ जिसे टूल छू सकता है, और संरक्षित सूची |
| स्व-परीक्षण | `--self-test` | निर्भरता, सिंटैक्स और सुरक्षा जाँच |
| संस्करण | `-V` `--version` | संस्करण और लेखक |

## सफ़ाई — दोबारा बन सकने वाला डेटा {#cleanup--regenerable-data}

ये मोड सफ़ाई लक्ष्य हटा सकते हैं। `--yes` केवल `--all-safe` में बैच पुष्टि छोड़ता है; दूसरे मोड अपने प्रॉम्प्ट रखते हैं।

| मोड | फ़्लैग | व्यवहार |
|---|---|---|
| [वॉकथ्रू](./walkthrough.md) | _(डिफ़ॉल्ट)_ `-w` | दस गाइडेड चरण, हर एक से पहले पूछता है |
| [मेन्यू](./menu.md) | `-m` `--menu` | नंबर वाला मेन्यू — एक श्रेणी चुनें |
| [TUI](./tui.md) | `-t` `--tui` | वही, whiptail/dialog डायलॉग के रूप में |
| [पूरी तरह सुरक्षित](./all-safe.md) | `-a` `--all-safe` | हर दोबारा बन सकने वाला कैश एक बार में |
| [एडिटर एक्सटेंशन](./editor-extensions.md) | `--editor-ext` | VS Code / Cursor के पुराने पड़े संस्करण |
| [सिस्टम सफ़ाई](./system-cleanup.md) | `--system` | apt, जर्नल, snap, `/tmp`, पेज कैश — `sudo` चाहिए |

## सफ़ाई — केवल इंटरैक्टिव {#cleanup--interactive-only}

निजी या प्रोजेक्ट डेटा। ये **`--yes` को अनदेखा करते हैं** और हर प्रविष्टि की पुष्टि माँगते हैं। देखें [जाँच 3](../safety/guards.md#guard-3--personal-data-is-interactive-only)।

| मोड | फ़्लैग | ढूँढता है |
|---|---|---|
| [पुरानी निजी फ़ाइलें](./personal-stale-files.md) | `-p` `--stale` | `~/Downloads` और कॉन्फ़िगर की गई असंरक्षित जड़ों में बड़ी निष्क्रिय फ़ाइलें |
| [अधूरे डाउनलोड](./partial-downloads.md) | `--partials` | `.fdmdownload`, `.crdownload`, `.part` |
| [node_modules खोज](./node-modules-finder.md) | `--node-modules` | N+ दिन निष्क्रिय प्रोजेक्ट निर्भरता फ़ोल्डर |

## आउटपुट, सुधार और सेटअप {#output-repair-and-setup}

| मोड | फ़्लैग | उद्देश्य |
|---|---|---|
| [रिपोर्ट](./reports.md) | `--reports` | पिछली सत्र रिपोर्ट सूचीबद्ध करें, बदलें, देखें |
| [एक्सपोर्ट](./reports.md#exporting) | `--export FMT ID` | बिना पूछे बदलाव |
| [डॉक्टर](./doctor.md) | `--doctor` | nvm, pnpm, bun, deno, cargo के टूटे शेल-इनिट ठीक करें |
| [स्पीड जाँच](./speed.md) | `--speed` | दबाव और शुरुआती काम नापें; वैकल्पिक सुधार अलग से पूछते हैं |
| फ़ीडबैक | `--feedback` | बग रिपोर्ट के निर्देश, वैकल्पिक mailto ड्राफ़्ट |
| डीबग बंडल | `--debug-bundle` | नया लॉग + रिपोर्ट एक tar.gz में पैक करें |
| एलियास इंस्टॉल | `--install-alias` | शेल एलियास `cleanup` जोड़ें |
| cron इंस्टॉल | `--install-cron` | हर रविवार 03:00 `--all-safe -y` |
| एलियास / cron अनइंस्टॉल | `--uninstall-alias` `--uninstall-cron` | दोनों में से किसी को हटाएँ |

## मोड चुनना {#choosing-a-mode}

| लक्ष्य | मोड |
|---|---|
| टूल का पहली बार उपयोग | `--self-test`, `--scan`, `--all-safe --dry-run` |
| अभी जगह चाहिए, नियंत्रण के साथ | _(डिफ़ॉल्ट वॉकथ्रू)_ |
| अभी जगह चाहिए, बिना प्रॉम्प्ट | `--all-safe -y` |
| कोई एक ख़ास श्रेणी | `--menu` / `--tui` |
| हर हफ़्ते बिना देखरेख रखरखाव | `--all-safe -y` + `--install-cron` |
| सिस्टम दोबारा इंस्टॉल करने से पहले अधिकतम जगह | `--all-safe -y --purge-all` |
| पता करें डिस्क कौन खा रहा है | `--audit`, `--scan` |
| पुराने साइड प्रोजेक्ट जमा हो रहे हैं | `--node-modules` |
| इंस्टॉल के बाद `command not found` | `--doctor` |

## मोड के साथ जुड़ने वाले विकल्प {#options-that-combine-with-modes}

| विकल्प | डिफ़ॉल्ट | असर |
|---|---|---|
| `-d N` `--days N` | 100 | निष्क्रियता सीमा। कम का मतलब ज़्यादा आक्रामक |
| `--purge-all` | बंद | निष्क्रियता जाँच बंद — पूरा मिटाना |
| `-y` `--yes` | बंद | दोबारा बन सकने वाले कैश की अपने आप पुष्टि। केवल `--all-safe` के साथ |
| `--no-report` | बंद | JSON रिपोर्ट छोड़ें। लॉग फिर भी लिखे जाते हैं |
| `--cleanup-logs` | बंद | अंत में इस रन का लॉग हटाएँ। रिपोर्ट हमेशा रखी जाती हैं |
| `--no-color` | बंद | ANSI रंग बंद करें। `NO_COLOR` भी माना जाता है |
| `-n` `--dry-run` | बंद | चुनी गई सफ़ाई से बिना हटाए गुज़रें; स्थानीय लॉग और अपडेट-जाँच स्थिति फिर भी लिखी जा सकती है |
| `--json-events` | बंद | `--scan` या गैर-इंटरैक्टिव `--all-safe --yes` के लिए NDJSON |

पूरा विवरण: [CLI फ़्लैग](../reference/cli-flags.md) और [मोड तालिका](../reference/modes-matrix.md)।
