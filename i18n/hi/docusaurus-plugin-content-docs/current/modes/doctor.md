# डॉक्टर

**`--doctor` उन रनटाइम को ढूँढता है जो डिस्क पर हैं पर आपकी शेल कॉन्फ़िगरेशन से जुड़े नहीं, और ग़ायब इनिट ब्लॉक जोड़ने का विकल्प देता है।** [1.1.0](../changelog.md#110--2026-05-10) में जोड़ा गया।

```bash
linux-cleanup --doctor
```

यह वह मोड है जब आप अच्छी तरह जानते हैं कि pnpm इंस्टॉल किया था, फिर भी `pnpm: command not found` दिखता है।

## केवल जोड़ता है {#additive-only}

:::note Doctor कभी मौजूदा पंक्ति नहीं हटाता या बदलता
यह केवल एक मानक इनिट ब्लॉक **जोड़ता** है, और वह भी आपकी पुष्टि के बाद। यह आपकी शेल कॉन्फ़िगरेशन में पहले से मौजूद कुछ भी बदलता, आगे-पीछे करता या हटाता नहीं।

शेल-इनिट फ़ाइलें हटाने के स्तर पर भी अलग से संरक्षित हैं: `safe_rm` किसी भी ऐसे पथ को मना करता है जिसका फ़ाइल नाम `.bashrc`, `.zshrc`, `.profile`, `.bash_aliases` या ऐसा ही हो, चाहे वह कहीं भी हो। देखें [संरक्षित पथ](../reference/protected-paths.md#protected-basenames)।
:::

## यह क्या जाँचता है {#what-it-checks}

| रनटाइम | पहचान | क्या जोड़ता है |
|---|---|---|
| `nvm` | `~/.nvm` मौजूद, `NVM_DIR` इनिट नहीं | nvm का मानक लोडर ब्लॉक |
| `pnpm` | `~/.local/share/pnpm` मौजूद, `PATH` पर नहीं | `PNPM_HOME` एक्सपोर्ट और `PATH` में जोड़ |
| `bun` | `~/.bun` मौजूद, `PATH` पर नहीं | Bun का इनिट ब्लॉक |
| `deno` | `~/.deno` मौजूद, `PATH` पर नहीं | Deno का `PATH` में जोड़ |
| `cargo` | `~/.cargo` मौजूद, `PATH` पर नहीं | `. "$HOME/.cargo/env"` |

## यह आम तौर पर कैसे होता है {#how-this-usually-happens}

कोई इंस्टॉलर अपना इनिट ब्लॉक ऐसी फ़ाइल में लिखता है जिसे आपका शेल नहीं पढ़ता। `~/.profile` केवल लॉगिन शेल पढ़ते हैं; `~/.bash_profile` मौजूद हो तो उसे ढक देता है; `~/.bashrc` का बदलाव कभी `zsh` सत्र तक नहीं पहुँचता। रनटाइम ठीक से इंस्टॉल होता है और फिर ग़ायब हुआ लगता है।

यह मशीनों के बीच dotfiles रिपॉज़िटरी ले जाने के बाद, या लॉगिन शेल बदलने के बाद भी होता है।

## उसके बाद {#afterwards}

अपना शेल फिर लोड करें, वरना बदलाव काम करता नहीं लगेगा:

```bash
source ~/.bashrc     # या ~/.zshrc
```

फिर पुष्टि करें:

```bash
command -v pnpm && pnpm --version
```

## ग्लोबल पैकेज जाँच से इसका संबंध {#its-relationship-to-the-globals-audit}

[`--globals`](./globals-audit.md) तब भी काम करता है जब कोई पैकेज मैनेजर `PATH` पर न हो, क्योंकि यह फ़ाइल सिस्टम देखने पर लौट आता है। इसलिए अगर जाँच pnpm के ग्लोबल पैकेज दिखाए पर `pnpm` ख़ुद न मिले, तो `--doctor` ही हल है।
