# होम जाँच

**`--audit` `$HOME` की 20 सबसे बड़ी चीज़ें आकार के क्रम में दिखाता है।** यह कुछ नहीं हटाता, और इसे फ़र्क नहीं पड़ता कि टूल जो मिला उसे साफ़ कर सकता है या नहीं।

```bash
linux-cleanup --audit
```

## यह `--scan` से कैसे अलग है {#why-this-is-different-from---scan}

[`--scan`](./scan.md) उन श्रेणियों को नापता है जिन्हें linux-cleanup साफ़ करना जानता है। `--audit` आपका होम फ़ोल्डर नापता है, बस।

यही अंतर असली बात है। अगर आपकी डिस्क असल में 60 GB की VM इमेज, डाउनलोड किए डेटासेट या Steam लाइब्रेरी से भरी है, तो `--scan` उसका ज़िक्र कभी नहीं करेगा और `--audit` उसे सूची में सबसे ऊपर रखेगा।

| | `--audit` | `--scan` |
|---|---|---|
| दायरा | `$HOME` में सब कुछ | केवल साफ़ होने लायक श्रेणियाँ |
| जवाब देता है | मेरी डिस्क किसने भरी? | यह टूल क्या वापस दिला सकता है? |
| JSON सत्र रिपोर्ट लिखता है | नहीं | नहीं |
| हटाता है | कभी नहीं | कभी नहीं |

## आम तरीका {#the-usual-workflow}

```bash
linux-cleanup --audit    # बड़ा क्या है?
linux-cleanup --scan     # यह टूल क्या वापस दिला सकता है?
```

अगर जाँच की सबसे ऊपर की चीज़ें स्कैन में दिखें, तो टूल मदद कर सकता है। अगर नहीं, तो आपने कुछ ज़्यादा काम का सीखा — जगह ऐसी जगह है जहाँ यह टूल नहीं जाता, और आप उसे सीधे सँभाल सकते हैं।

आम बड़ी चीज़ें जिन्हें linux-cleanup साफ़ **नहीं** करेगा:

- VM इमेज और कंटेनर स्टोरेज (`~/.local/share/libvirt`, `~/.local/share/docker`)
- गेम लाइब्रेरी (Steam, Lutris)
- डेटासेट, मॉडल वेट, मीडिया लाइब्रेरी
- `~/Documents`, `~/Pictures`, `~/Music`, `~/Videos` में कुछ भी — सब [संरक्षित](../reference/protected-paths.md)

## किसी खोज के पीछे जाना {#following-up-on-a-finding}

```bash
du -sh ~/.local/share/*      | sort -rh | head -20
du -sh ~/*                   | sort -rh | head -20
```

`--audit` तेज़ पहली नज़र है; कहाँ देखना है पता चलने पर `du` दायरा छोटा करता है।
