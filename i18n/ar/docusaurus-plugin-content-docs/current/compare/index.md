# مقارنة منظّفات Linux

وُصفت كل أداة من موقعها أو مستودعها، مع تاريخ تحقّقنا. وما لم تذكره صفحاتها يُكتب «غير مذكور في الصفحات التي راجعناها»، ولا يُكتب «لا» أبدًا.

تُفتح الروابط إلى المشاريع الأخرى في علامة تبويب جديدة وتحمل `nofollow`.

*آخر تحقّق 2026-11-22.*
