# TUI (القائمة المرئية)

**يعرض `--tui` قائمة الفئات في مربع whiptail أو dialog يملأ الشاشة.** أُضيف في [1.3.0](../changelog.md#130--2026-05-10). السلوك نفسه الذي في [`--menu`](./menu.md)، بعرض مختلف.

```bash
linux-cleanup --tui      # أو: -t, -g, --gui
```

## كيف يعمل {#how-it-behaves}

اختيار مدخل يُخرج من المربع، ويشغّل تلك الفئة بمخرجات سطر الأوامر وأسئلته المعتادة، ثم يعود إلى القائمة. فالمربع مجرد مشغّل؛ والتأكيدات الفعلية ما تزال الأسئلة النصية المعتادة، وكل الضمانات كما هي.

تحتوي TUI أيضًا على مربع **حول** يعرض الإصدار وبيانات التواصل والترخيص والتزام الخصوصية.

## المتطلبات والبديل {#requirements-and-fallback}

يحتاج إلى `whiptail` أو `dialog`. وإن لم يوجد أيهما تطبع الأداة تلميح تثبيت بحسب التوزيعة وتعود إلى قائمة سطر الأوامر العادية، دون أن تفشل.

```bash
sudo apt install whiptail     # Debian / Ubuntu
sudo dnf install newt         # Fedora / RHEL
sudo pacman -S libnewt        # Arch
```

يأتي `whiptail` ضمن حزمتي `newt` / `libnewt` على أنظمة RPM وArch، ولهذا لا يطابق اسم الحزمة اسم الأمر.

:::note هذا الموضع الوحيد الذي تكتشف فيه الأداة التوزيعة
تلميح التثبيت أعلاه يراعي التوزيعة، ولا شيء غيره في linux-cleanup يفعل ذلك — وأبرز مثال أن [`--system` يفترض Debian/Ubuntu](../distro-support.md).
:::

## متى تُستخدم القائمة النصية {#when-to-use-the-plain-menu}

يحتاج `--tui` إلى طرفية قادرة على عرض مربع يملأ الشاشة. وعبر اتصال محدود، أو داخل سجل CI، أو في جلسة `ssh -T` بلا TTY، يُستخدم [`--menu`](./menu.md) بدلًا منه — فهو لا يحتاج إلى غير bash.
