# الجولة الموجّهة (الافتراضية)

**تشغيل `linux-cleanup` دون خيارات يبدأ الجولة الموجّهة: عشر خطوات عبر كل فئات التنظيف، تسأل كل منها قبل أن تفعل أي شيء.** وهي الطريقة الموصى بها لاستخدام الأداة تفاعليًا.

```bash
linux-cleanup          # أو: linux-cleanup -w / --walkthrough
```

## الخطوات العشر {#the-ten-steps}

| # | الخطوة | تحذف | ملاحظات |
|---|---|---|---|
| 1 | ذاكرة مديري الحزم | قابلة لإعادة الإنشاء | yarn وnpm وnpx وpnpm وpip وcomposer وbun وdeno |
| 2 | ذاكرة التطبيقات | قابلة لإعادة الإنشاء | المتصفحات وGradle وCypress وPlaywright وZoom وملفات VSIX للمحررات |
| 3 | بيانات أدوات المطورين | المهمل فقط | أجهزة Android الافتراضية وpub-cache وتحليل Dart وflatpak |
| 4 | إضافات المحررات القديمة | مهمل + مستبدل | VS Code / Cursor |
| 5 | مجلدات `node_modules` المهملة | **تفاعلي** | مشاريع خاملة أكثر من الحد |
| 6 | التنزيلات غير المكتملة أو المتروكة | **تفاعلي** | `.crdownload` و`.part` و`.fdmdownload` |
| 7 | الملفات الشخصية المهملة | **تفاعلي** | ملفات كبيرة خاملة في `~/Downloads` والجذور الشخصية المضبوطة |
| 8 | تنظيف النظام (sudo) | النظام | apt وسجل النظام وsnap و`/tmp` وذاكرة الصفحات |
| 9 | فحص الحجم النهائي | لا شيء | ملخص للقراءة فقط |
| 10 | إنشاء تقرير مقروء | لا شيء | تصدير Markdown / HTML — يتطلب `jq` |

الخطوات 5 و6 و7 هي [التفاعلية فقط](../safety/guards.md#guard-3--personal-data-is-interactive-only). لا يمكن تأكيدها تلقائيًا، والخطوة 7 هي الوحيدة في الأداة كلها التي قد تحذف شيئًا لا يُعوَّض حقًا.

## كيف تعمل الأسئلة {#how-the-prompts-work}

للتأكيد مستويان.

**لكل خطوة**، يُختار ما يُفعل بالفئة كلها:

| المفتاح | الأثر |
|---|---|
| `a` | تشغيل هذه الخطوة. وهو الافتراضي — الضغط على Enter يختاره |
| `s` | تخطي هذه الخطوة كليًا |
| `q` | إنهاء الجولة الآن مع الاحتفاظ بالتقدم حتى اللحظة |

**لكل هدف**، داخل الخطوة المختارة، لكل عنصر تأكيد `[Y/n]` أو `[y/N]` خاص به. والحرف الكبير هو الافتراضي.

فاختيار `a` على مستوى الخطوة لا يُلزم بحذف كل ما فيها؛ إذ يظهر كل هدف ويُجاب عنه.

## المجاميع المتراكمة {#running-totals}

بعد كل خطوة نُفذت، تطبع الأداة التغيّر المقيس ومجموع الجلسة حتى تلك اللحظة.

يذكر الملخص النهائي المساحة الحرة قبل وبعد. ويُقاس هذا الرقم بـ `df`، فيعكس كل ما يجري على الجهاز؛ فإن شُغّل بناء أثناء الجلسة، قد تكون الاستعادة المذكورة أقل من مجموع الخطوات، بل سالبة. وهذا ليس خللًا؛ انظر [استكشاف الأخطاء](../troubleshooting.md#disk-usage-grew-during-the-session).

## الخروج مبكرًا {#quitting-early}

`q` عند سؤال أي خطوة، أو `Ctrl-C` في أي لحظة، ينهي الجلسة بسلاسة:

- يبقى الحذف السابق دائمًا؛ ويُراجَع السجل لمعرفة الخطوات التي جُرّبت قبل المقاطعة
- يخرج `Ctrl-C` بالرمز `130`، الذي [يتجاهله فخ الانهيار عن قصد](../reference/exit-codes.md#how-the-crash-trap-decides)، فلا تُكتب حزمة انهيار
- تُسجَّل الخطوات التي لم يُوصل إليها بوصفها متخطاة في التقرير

## تقرير الجلسة {#the-session-report}

تكتب الجولة تقرير JSON في `~/.linux-cleanup/reports/report-<timestamp>.json` ما لم يُضبط `--no-report` أو `--dry-run`. ويحتوي على حالة كل خطوة والبايتات المحررة، والقرص والذاكرة قبل وبعد، ومجاميع الجلسة. قائمة الحقول كاملة: [بنية التقرير](../reference/report-schema.md).

تحوّله الخطوة 10 اختياريًا إلى Markdown وHTML. وتحتاج هذه الخطوة إلى `jq`؛ ودونه تُسجَّل `skipped (jq missing)` ويُكتب JSON مع ذلك.

```bash
linux-cleanup --no-report    # تخطي إنشاء JSON؛ وتُكتب السجلات مع ذلك
```

## خيارات تستحق الجمع {#options-worth-combining}

```bash
linux-cleanup -d 30          # حد خمول 30 يومًا بدلًا من 100
linux-cleanup --purge-all    # تعطيل بوابة الخمول كليًا
linux-cleanup --no-color     # مخرجات بلا ألوان
linux-cleanup --cleanup-logs # حذف سجل هذا التشغيل في النهاية
```

:::danger يغيّر `--purge-all` ما تحذفه الخطوات 1–4
مع تعطيل [بوابة الخمول](../safety/guards.md#guard-2--the-staleness-gate) تمسح خطوات ذاكرة التخزين المؤقت أهدافها بالكامل بدلًا من تقليم الملفات الخاملة. ويشمل ذلك توزيعات Gradle wrapper ومتصفحات Playwright وملفات Cypress التنفيذية التي قد تكون ما تزال مطلوبة. وتذكر لافتة ما قبل التشغيل الإستراتيجية المفعّلة.
:::
