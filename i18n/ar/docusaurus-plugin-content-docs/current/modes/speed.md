# تشخيص السرعة

**يبيّن `--speed` أين يقضي الجهاز وقته.** يقرأ عدادات الحرارة، وضغط المعالج والذاكرة والإدخال والإخراج، والعمليات الثقيلة، ومعلومات الإقلاع. ويمكنه أيضًا العثور على الحاويات والخدمات وتطبيقات تسجيل الدخول التي تبدأ من تلقاء نفسها.

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

يعرض التشغيل التجريبي التغييرات التي كان سيسأل عنها دون تطبيقها. ويسأل التشغيل العادي على حدة قبل كل تغيير مقترح، والإجابة الافتراضية لا. ولا يخوّل `--yes` هذه الإصلاحات.

بعض الإصلاحات المقبولة يوقف حاوية أو يعطّل خدمة أو يغيّر إعداد تسجيل دخول للمستخدم. ولا تحذف ملفات ذاكرة تخزين مؤقت، لكنها تؤثر فيما يبدأ في المرة التالية. ويطبع سطر الأوامر أمر تراجع بعد تطبيق التغيير. وقد يظهر طلب sudo عند تغيير خدمة نظام.

النتيجة قياس أو حالة، لا دليل على أن تطبيقًا بعينه معطوب. يُقرأ اسم العملية أو الخدمة ويُقرَّر إن كانت مطلوبة قبل قبول التغيير.

للأوامر المفقودة في بدء تشغيل الصدفة يُستخدم وضع [الطبيب](./doctor.md) المنفصل. ولمساحة القرص يُبدأ بـ[فحص](./scan.md).
