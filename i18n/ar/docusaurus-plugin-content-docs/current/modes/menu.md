# القائمة

**يطبع `--menu` قائمة مرقّمة بكل الفئات ويشغّل الفئة المختارة.** يُستخدم حين يكون المطلوب واضحًا ولا حاجة إلى جولة الخطوات العشر.

```bash
linux-cleanup --menu     # أو: -m, -i, --interactive
```

## كيف تختلف عن الجولة الموجّهة {#how-it-differs-from-the-walkthrough}

| | القائمة | [الجولة الموجّهة](./walkthrough.md) |
|---|---|---|
| الترتيب | باختيار المستخدم | ثابت، عشر خطوات |
| النطاق | فئة واحدة لكل اختيار | كل شيء بالتسلسل |
| التكرار | تعود إلى القائمة بعد ذلك | تعمل حتى النهاية |
| التقرير | لكل إجراء | تقرير جلسة واحد |
| الأنسب لـ | تنظيف موجّه | أول تشغيل، تنظيف شامل |

نموذج الأمان مطابق. تتصرف كل فئة تمامًا كما في الجولة الموجّهة — تنطبق [قائمة المسارات المسموحة](../safety/guards.md#guard-1--the-path-allowlist) و[بوابة الخمول](../safety/guards.md#guard-2--the-staleness-gate) والتأكيد لكل هدف. واختيار فئة بيانات شخصية من القائمة يعطي أسئلة لكل مدخل كذلك، ولا يزال `--yes` بلا أثر عليها.

## الخيارات تبقى سارية {#options-still-apply}

```bash
linux-cleanup --menu -d 30        # حد 30 يومًا لما يُختار
linux-cleanup --menu --purge-all  # بوابة الخمول معطّلة
linux-cleanup --menu --no-color   # مخرجات بلا ألوان
```

## متى تُستخدم TUI بدلًا منها {#when-to-use-the-tui-instead}

[`--tui`](./tui.md) هي القائمة نفسها معروضة في مربع whiptail أو dialog، وتحتاج إلى تثبيت أحدهما. أما `--menu` فلا يحتاج إلى غير bash، ويعمل عبر أي اتصال، بما في ذلك طرفية بسيطة أو جلسة `ssh -T` قد يضطرب فيها مربع ملء الشاشة.
