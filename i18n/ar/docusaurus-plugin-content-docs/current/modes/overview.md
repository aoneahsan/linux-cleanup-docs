# نظرة على الأوضاع

**لـ linux-cleanup نقطة دخول واحدة، ويُختار الوضع بخيار واحد.** والتشغيل دون خيارات يبدأ [الجولة الموجّهة](./walkthrough.md).

الأوضاع متنافية؛ يُمرَّر واحد منها فقط. وتُضاف إليها خيارات مثل `--days` و`--yes`.

## للقراءة فقط — لا يحذف شيئًا أبدًا {#read-only--never-deletes-anything}

لا تحذف هذه الأوضاع أهداف التنظيف. وقد تكتب مع ذلك سجلًا محليًا، وقد يقرأ فحص الإصدارات سجلًا عامًا عند الاتصال.

| الوضع | الخيار | يعرض |
|---|---|---|
| [الفحص](./scan.md) | `-s` `--scan` | كل فئات ذاكرة التخزين المؤقت مع أحجامها الحالية |
| [فحص المجلد الرئيسي](./home-audit.md) | `--audit` | أكبر 20 مدخلًا في `$HOME` |
| [فحص الحزم العامة](./globals-audit.md) | `--globals` | حزم npm/pnpm/yarn/bun/deno العامة |
| سرد الأهداف | `--list-targets` | كل مسار يمكن للأداة لمسه، مع القائمة المحمية |
| الاختبار الذاتي | `--self-test` | فحص الاعتماديات والصياغة والضمانات |
| الإصدار | `-V` `--version` | الإصدار والمؤلف |

## التنظيف — بيانات قابلة لإعادة الإنشاء {#cleanup--regenerable-data}

يمكن لهذه الأوضاع حذف أهداف التنظيف. ولا يتخطى `--yes` تأكيد الدفعة إلا في `--all-safe`، وتحتفظ الأوضاع الأخرى بأسئلتها.

| الوضع | الخيار | السلوك |
|---|---|---|
| [الجولة الموجّهة](./walkthrough.md) | _(افتراضي)_ `-w` | عشر خطوات موجّهة، مع سؤال قبل كل منها |
| [القائمة](./menu.md) | `-m` `--menu` | قائمة مرقّمة — تُختار فئة واحدة |
| [TUI](./tui.md) | `-t` `--tui` | الشيء نفسه في مربع whiptail/dialog |
| [الآمن بالكامل](./all-safe.md) | `-a` `--all-safe` | كل ذاكرة قابلة لإعادة الإنشاء في مرور واحد |
| [إضافات المحررات](./editor-extensions.md) | `--editor-ext` | إصدارات VS Code / Cursor القديمة |
| [تنظيف النظام](./system-cleanup.md) | `--system` | apt وسجل النظام وsnap و`/tmp` وذاكرة الصفحات — يتطلب `sudo` |

## التنظيف — تفاعلي فقط {#cleanup--interactive-only}

بيانات شخصية أو بيانات مشاريع. هذه الأوضاع **تتجاهل `--yes`** وتتطلب تأكيدًا لكل مدخل. انظر [البوابة 3](../safety/guards.md#guard-3--personal-data-is-interactive-only).

| الوضع | الخيار | يعثر على |
|---|---|---|
| [الملفات الشخصية المهملة](./personal-stale-files.md) | `-p` `--stale` | ملفات كبيرة خاملة في `~/Downloads` والجذور غير المحمية المضبوطة |
| [التنزيلات غير المكتملة](./partial-downloads.md) | `--partials` | `.fdmdownload` و`.crdownload` و`.part` |
| [باحث node_modules](./node-modules-finder.md) | `--node-modules` | مجلدات اعتماديات مشاريع خاملة منذ N يومًا فأكثر |

## المخرجات والإصلاح والإعداد {#output-repair-and-setup}

| الوضع | الخيار | الغرض |
|---|---|---|
| [التقارير](./reports.md) | `--reports` | سرد تقارير الجلسات السابقة وتحويلها وعرضها |
| [التصدير](./reports.md#exporting) | `--export FMT ID` | تحويل غير تفاعلي |
| [الطبيب](./doctor.md) | `--doctor` | إصلاح تهيئة الصدفة المعطوبة لـ nvm وpnpm وbun وdeno وcargo |
| [تشخيص السرعة](./speed.md) | `--speed` | قياس الضغط وما يبدأ مع النظام؛ والإصلاحات الاختيارية تسأل على حدة |
| الملاحظات | `--feedback` | تعليمات تقرير الخلل، ومسودة mailto اختيارية |
| حزمة التصحيح | `--debug-bundle` | حزم أحدث سجل وتقرير في ملف tar.gz |
| تثبيت الاسم المستعار | `--install-alias` | إضافة اسم مستعار للصدفة `cleanup` |
| تثبيت cron | `--install-cron` | `--all-safe -y` أسبوعيًا، الأحد الساعة 03:00 |
| إلغاء الاسم المستعار / cron | `--uninstall-alias` `--uninstall-cron` | إزالة أي منهما |

## اختيار وضع {#choosing-a-mode}

| الهدف | الوضع |
|---|---|
| أول استخدام للأداة | `--self-test`, `--scan`, `--all-safe --dry-run` |
| تحرير مساحة الآن مع التحكم | _(الجولة الموجّهة الافتراضية)_ |
| تحرير مساحة الآن دون أسئلة | `--all-safe -y` |
| فئة واحدة بعينها | `--menu` / `--tui` |
| صيانة أسبوعية دون إشراف | `--all-safe -y` + `--install-cron` |
| أقصى استعادة قبل إعادة تثبيت النظام | `--all-safe -y --purge-all` |
| معرفة ما يلتهم القرص | `--audit`, `--scan` |
| تراكم مشاريع جانبية قديمة | `--node-modules` |
| `command not found` بعد التثبيت | `--doctor` |

## خيارات تُضاف إلى الأوضاع {#options-that-combine-with-modes}

| الخيار | الافتراضي | الأثر |
|---|---|---|
| `-d N` `--days N` | 100 | حد الخمول. كلما قلّ ازدادت الحدة |
| `--purge-all` | معطّل | يعطّل بوابة الخمول — مسح كامل |
| `-y` `--yes` | معطّل | يؤكد ذاكرة التخزين المؤقت القابلة لإعادة الإنشاء تلقائيًا. مع `--all-safe` فقط |
| `--no-report` | معطّل | يتخطى تقرير JSON. وتُكتب السجلات مع ذلك |
| `--cleanup-logs` | معطّل | يحذف سجل هذا التشغيل في النهاية. وتُحفظ التقارير دائمًا |
| `--no-color` | معطّل | يعطّل ألوان ANSI. ويُحترم `NO_COLOR` أيضًا |
| `-n` `--dry-run` | معطّل | يمر بالتنظيف المختار دون حذف؛ وقد يكتب مع ذلك سجلًا محليًا وحالة فحص التحديثات |
| `--json-events` | معطّل | NDJSON لـ `--scan` أو `--all-safe --yes` غير التفاعلي |

التفاصيل الكاملة: [خيارات سطر الأوامر](../reference/cli-flags.md) و[مصفوفة الأوضاع](../reference/modes-matrix.md).
