# فحص المجلد الرئيسي

**يسرد `--audit` أكبر 20 مدخلًا في `$HOME` مرتبة حسب الحجم.** لا يحذف شيئًا، ولا يهمه إن كانت الأداة قادرة على تنظيف ما يجده.

```bash
linux-cleanup --audit
```

## كيف يختلف عن `--scan` {#why-this-is-different-from---scan}

يقيس [`--scan`](./scan.md) الفئات التي يعرف linux-cleanup كيف ينظفها. أما `--audit` فيقيس المجلد الرئيسي، لا أكثر.

وهذا الفرق هو المقصود. فإن كان ما ملأ القرص فعلًا صورة آلة افتراضية بحجم 60 GB أو مجموعة بيانات منزّلة أو مكتبة Steam، فلن يذكرها `--scan` أبدًا، وسيضعها `--audit` في أعلى القائمة.

| | `--audit` | `--scan` |
|---|---|---|
| النطاق | كل ما في `$HOME` | الفئات القابلة للتنظيف فقط |
| يجيب عن | ما الذي يشغل قرصي؟ | ما الذي تستطيع هذه الأداة استعادته؟ |
| يكتب تقرير جلسة JSON | لا | لا |
| يحذف | أبدًا | أبدًا |

## سير العمل المعتاد {#the-usual-workflow}

```bash
linux-cleanup --audit    # ما الكبير؟
linux-cleanup --scan     # ما الذي تستطيع هذه الأداة استعادته؟
```

إن ظهرت أكبر مدخلات الفحص في نتائج `--scan`، فالأداة قادرة على المساعدة. وإن لم تظهر، فقد اتضح شيء أنفع: المساحة في مكان لا تصل إليه هذه الأداة، ويمكن التعامل معه مباشرة.

أشياء كبيرة شائعة **لن** ينظفها linux-cleanup:

- صور الآلات الافتراضية وتخزين الحاويات (`~/.local/share/libvirt` و`~/.local/share/docker`)
- مكتبات الألعاب (Steam وLutris)
- مجموعات البيانات وأوزان النماذج ومكتبات الوسائط
- أي شيء في `~/Documents` و`~/Pictures` و`~/Music` و`~/Videos` — وكلها [محمية](../reference/protected-paths.md)

## متابعة نتيجة ما {#following-up-on-a-finding}

```bash
du -sh ~/.local/share/*      | sort -rh | head -20
du -sh ~/*                   | sort -rh | head -20
```

`--audit` هو المرور الأول السريع، و`du` يضيّق النطاق بعد معرفة أين يُنظر.
