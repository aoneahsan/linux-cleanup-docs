# استعادة المساحة بتأنٍّ

**القياس أولًا. ثم اختيار أصغر نطاق تنظيف يعالج المسارات التي ظهرت.** فحجم جذر ذاكرة التخزين المؤقت المذكور لا يعني أن التنظيف يستطيع حذفه كله أو ينبغي له.

## 1. العثور على المسارات الكبيرة {#1-find-the-large-paths}

```bash
linux-cleanup --audit
linux-cleanup --scan
```

يسرد `--audit` المدخلات الكبيرة في `$HOME`، بما فيها ما لا تستطيع هذه الأداة تنظيفه. ويسرد `--scan` جذور ذاكرة التخزين المؤقت المضبوطة وسائر المرشحات دون حذف. وإن كان معظم القرص صورة آلة افتراضية أو مجموعة بيانات أو مكتبة ألعاب، تُفحص مباشرة بدلًا من تشغيل أوضاع تنظيف لا علاقة لها.

## 2. معاينة ذاكرة التخزين المؤقت المعتادة {#2-preview-routine-caches}

```bash
linux-cleanup --all-safe --dry-run
```

يقلّم الوضع الآمن بالكامل الافتراضي ذاكرة التخزين المؤقت القابلة لإعادة الإنشاء المؤهلة بعد حد خمول 100 يوم. وتمر المعاينة بتلك القواعد دون حذف، وقد تكتب مع ذلك سجلًا محليًا وحالة فحص التحديثات.

وإن كان كل مسار مقترح مما يمكن إعادة بنائه أو تنزيله، يُشغَّل `linux-cleanup --all-safe` وتُراجَع رسالة تأكيده. أما `--yes` فلتشغيل دون إشراف بعد فحص هذا الجهاز مسبقًا.

## 3. مراجعة اعتماديات المشاريع على حدة {#3-review-project-dependencies-separately}

```bash
linux-cleanup --node-modules --dry-run
```

وضع اعتماديات المشاريع تفاعلي. ويُفحص مسار المشروع وملف القفل قبل الحذف الفعلي. والتعديل المحلي داخل `node_modules` لا يعود بإعادة تثبيت الاعتماديات.

## 4. مراجعة تخزين النظام على حدة {#4-review-system-storage-separately}

```bash
linux-cleanup --system --dry-run
```

يستخدم وضع النظام الكامل apt وdpkg، فهو لـ Debian وUbuntu. ويطلب sudo، ويشمل تنظيف سجل النظام والملفات القديمة في `/tmp` وخطوة اختيارية لذاكرة الصفحات. وتؤثر خطوة ذاكرة الصفحات في الذاكرة RAM لا في القرص. انظر [تنظيف النظام](../modes/system-cleanup.md).

## 5. تغيير حد العمر بعد معاينة أخرى فقط {#5-change-the-age-threshold-only-after-another-preview}

يغيّر `--days N` أي الملفات الخاملة أو وحدات ذاكرة التخزين المؤقت الكاملة تصبح مؤهلة. وخفضه من 100 إلى 30 قد يحذف ما استُخدم مؤخرًا، لذا يُراجَع أولًا تشغيل تجريبي بالقيمة المختارة. ويعطّل `--purge-all` حماية العمر، وقد يحذف توزيعة Gradle أو متصفح اختبار يلزم تنزيله مجددًا.

## 6. إبقاء الملفات الشخصية قرارًا منفصلًا {#6-keep-personal-files-as-a-separate-decision}

يعرض `--stale` الملفات الشخصية الكبيرة الخاملة المرشحة، ويسأل عن كل حذف. وقد يكون تنزيل قديم النسخة الوحيدة الموجودة. ولا يوافق `--yes` على هذا الوضع. انظر [الملفات الشخصية المهملة](../modes/personal-stale-files.md) و[الحذف دائم](../safety/irreversibility.md).

تختلف المساحة المستعادة حسب الجهاز وحسب العمليات الأخرى التي تكتب أثناء التشغيل. ويُراجَع السجل النهائي والمسارات المحتفظ بها قبل تقرير الحاجة إلى وضع آخر.
