# أحداث تقرؤها الآلة

يكتب `--json-events` بيانات JSON مفصولة بأسطر جديدة إلى stdout. ويذهب النص المقروء والأسئلة إلى stderr، مع نسخة محلية في سجل الجلسة. ويبقى البث على هذا الجهاز، وقد يحتوي على مسارات محلية كاملة. ولا ينبغي للمستهلك رفع تلك المسارات ضمن بيانات الحساب أو التحليلات.

يدعم الخيار `--scan` و`--all-safe --yes`. ويحتاج التشغيل الآمن بالكامل إلى `--yes` حتى لا يتوقف عميل آلي عند سؤال. ويُضاف `--dry-run` لمعاينة الإجراء الآمن بالكامل دون حذف ملفات، وقد يُكتب مع ذلك سجل محلي وحالة فحص التحديثات. وتعيد الأوضاع الأخرى رمز الخروج 2.

```bash
linux-cleanup --scan --json-events > scan.ndjson
linux-cleanup --all-safe --yes --dry-run --json-events > preview.ndjson
```

لكل حدث مكتمل `v: 1` و`type` و`ts` (أجزاء الألف من الثانية بتوقيت Unix). وينبغي للمستهلك رفض `v` أعلى، وتجاهل الحقول غير المعروفة في الإصدار 1. ومعرّف الوضع نص: `scan` أو `allsafe`.

| الحدث | الحقول | المعنى |
|---|---|---|
| `plan` | `version`, `dry_run`, `profile`, `sections[]` | الحدث الأول؛ قسم واحد للوضع المختار. وللقسم `id` و`title` و`stamp` و`sudo` و`deep`. |
| `disk` | `phase`, `total_kb`, `free_kb`, `purgeable_kb`, `snapshots`, `snapshot_note` | عيّنة القرص قبل الوضع وبعده. والتقديرات غير المدعومة `null`. |
| `section_start` | `id`, `title`, `stamp` | بدأ الوضع المختار. |
| `item` | `id`, `path`, `kb`, `action`, `unique`, `age_days`, `reason` | نتيجة فحص للقراءة فقط أو مسار اختاره مساعد تنظيف. `report` للقراءة فقط، و`delete` إجراء مقترح في التشغيل التجريبي وإجراء مساعد مكتمل في التشغيل الفعلي، و`skip` رفض. ويُقتطع `kb` إلى عدد صحيح من KiB. |
| `progress` | `id`, `done`, `total` | الوضع المختار الوحيد عند 0/1 أو 1/1. وهو حد للوضع، لا نسبة مئوية لكل ملف. |
| `error` | `id`, `message` | إخفاق أو رفض أبلغ عنه سطر الأوامر. |
| `section_result` | `id`, `status`, `freed_kb`, `items`, `reason` | الحالة `completed` أو `failed`. وتبقى مجاميع البايتات والعناصر `null` إلى أن يميّز سطر الأوامر كتاباته عن نشاط القرص الآخر. |
| `summary` | `attempted`, `completed`, `skipped`, `failed`, `freed_kb`, `disk_free_before_kb`, `disk_free_after_kb`, `elapsed_s`, `reports`, `log`, `dry_run` | آخر حدث بعد اكتمال الوضع. وعيّنتا المساحة الحرة ملاحظتان، لا ادعاء بالبايتات التي استعادتها هذه العملية. |

في التشغيل المكتمل يبدأ البث بـ `plan` وينتهي بـ `summary`. وقد لا تترك عملية مقطوعة أو متطلب تحديث غير مستوفى أي summary؛ فيُعامل ذلك على أنه تشغيل غير مكتمل، ويُعتمد على رمز الخروج وstderr. وقد يُصدر وسيط مرفوض حدث `error` ويخرج بالرمز 2 قبل plan. ودون الخيار تبقى المخرجات النصية ورموز الخروج كما هي.

يكمّل بث الأحداث تقرير جلسة JSON المحلي. ولا يكتب التشغيل التجريبي تقرير جلسة. ويمكن للمستهلك استخدام `item.path` لتفسير قرار محلي ثم التخلي عنه بدلًا من مزامنته مع خادم. وحين يحذف `--cleanup-logs` سجل الجلسة يكون `summary.log` مساويًا لـ `null`.
