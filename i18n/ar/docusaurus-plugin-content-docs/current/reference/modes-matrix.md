## الأوضاع التي لا تحذف شيئًا أبدًا {#modes-that-never-delete-anything}

لا تحذف هذه الأوامر أهداف التنظيف. وبعضها يكتب سجلات محلية أو تقارير أو ملفات تصدير أو حزم تشخيص:

`--scan` · `--audit` · `--globals` · `--list-targets` · `--self-test` · `--version` · `--export` ·
`--feedback` · `--debug-bundle`

ويندرج `--doctor` هنا أيضًا مع تحفّظ: فهو يعدّل إعدادات الصدفة، لكن **بالإضافة فقط** بعد التأكيد. ولا يحذف سطرًا موجودًا ولا يعيد كتابته أبدًا.

## الأوضاع التي يؤثر فيها `--yes` {#modes---yes-affects}

وضع واحد فقط: [`--all-safe`](../modes/all-safe.md).

تتطلب أوضاع البيانات الشخصية التفاعلية — `--stale` و`--partials` و`--node-modules` — تأكيداتها الخاصة. انظر [الحاجز 3](../safety/guards.md#guard-3--personal-data-is-interactive-only).

## الأوضاع التي يسري عليها حاجز الخمول {#modes-the-staleness-gate-applies-to}

| يسري | لا يسري |
|---|---|
| تقليم ذاكرة التخزين المؤقت في الجولة الموجّهة والقائمة وTUI والآمن بالكامل | `--system` (يستخدم قاعدته الثابتة لـ `/tmp` بمدة 7 أيام) |
| استبدال الإصدارات في `--editor-ext` | `--partials` (العمر ليس المعيار) |
| `--node-modules` | أوضاع القراءة فقط (لا يُحذف شيء) |
| `--stale` |  |
| بيانات أدوات المطورين (AVD وflatpak وpub-cache) |  |

يعطّل `--purge-all` الحاجز حيثما كان سيسري.

## الأوضاع التي تحتاج إلى اعتماديات اختيارية {#which-modes-need-optional-dependencies}

| الوضع | يحتاج إلى | دونها |
|---|---|---|
| `--tui` | `whiptail` أو `dialog` | يعود إلى `--menu` مع تلميح للتثبيت |
| تحويل `--export` و`--reports` | `jq` | يُكتب JSON مع ذلك؛ والتحويل غير متاح |
| `--install-cron` | `crontab` | لا يمكن تشغيله |
| خطوة snap في `--system` | `snap` | تُتخطّى الخطوة بسلاسة |
| خطوات apt في `--system` | `apt` و`dpkg` | **يخفق** — [Debian/Ubuntu فقط](../distro-support.md) |
