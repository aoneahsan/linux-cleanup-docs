# ما الذي يحذفه

**يحذف linux-cleanup ذاكرة التخزين المؤقت والبقايا المختارة حذفًا دائمًا.** يتوقف الهدف على الوضع. يسرد الفحص المسارات وأحجامها الحالية، ويمر التشغيل التجريبي بالتنظيف المختار ويعرض الإجراءات المقترحة. ولا أحد منهما نسخة احتياطية.

```bash
linux-cleanup --list-targets
linux-cleanup --scan
linux-cleanup --all-safe --dry-run
```

ترفض [حماية المسارات المحمية](../reference/protected-paths.md) المواقع الشخصية ومواقع النظام المضبوطة بعد حلّ الروابط الرمزية. يُقرأ كل مسار مقترح قبل التشغيل الفعلي.

## ذاكرة مديري الحزم {#package-manager-caches}

يمكن للتنظيف الآمن بالكامل المعتاد تقليم جذور ذاكرة التخزين المؤقت هذه. وقد تحتاج إعادة تثبيت حزمة بعدها إلى تنزيل من الشبكة.

| ذاكرة التخزين المؤقت | الجذر المستهدف |
|---|---|
| Yarn Berry | `~/.yarn/berry/cache` |
| npm | `~/.npm/_cacache` |
| npx | `~/.npm/_npx` |
| pnpm store | `~/.local/share/pnpm/store` |
| pnpm cache | `~/.cache/pnpm` |
| bun | `~/.bun/install/cache` |
| deno | `~/.cache/deno` |
| Composer | `~/.cache/composer` |
| pip | `~/.cache/pip` |

تُقلَّم حزم Yarn v1 المستخرجة كمدخلات كاملة في `~/.cache/yarn`. أما الحزم المثبتة عالميًا وجذور تثبيت مديري الحزم فمنفصلة عن هذه الذاكرة.

## ذاكرة المتصفحات والتطبيقات {#browser-and-application-caches}

تشمل الأهداف المعتادة ذاكرة المتصفحات المضبوطة، ووحدات إصدارات Gradle، وملفات Cypress وPlaywright التنفيذية، وذاكرة مراقب TypeScript. وقد يحتاج المتصفح أو أداة البناء إلى إعادة إنشاء ما حُذف أو تنزيله في الاستخدام التالي. يُحتفظ بتوزيعة Gradle الحالية وإصدار Android Studio الحالي وفق قواعدهما الخاصة، وتُحذف الوحدة القديمة المؤهلة كاملة حتى لا يبقى تثبيت محذوف نصفه.

يتحقق الوضع من آخر وصول وآخر تعديل قبل التقليم على مستوى الملفات. ونظام الملفات الذي لا يُعتمد على أوقات الوصول فيه يمنع التقليم حسب العمر. ويُزيل `--purge-all` بوابة العمر هذه ويتطلب قرارًا منفصلًا.

## بيانات أدوات المطورين {#developer-tool-data}

قد يعرض الفحص أجهزة Android الافتراضية وذاكرة pub في Flutter وبيانات مستخدم Flatpak وجذورًا كبيرة أخرى. **ظهور مسار في الفحص لا يعني أن `--all-safe` سيحذفه.** تُقرأ صفحة الوضع ومخرجات التشغيل التجريبي لمعرفة ما يستهدفه الوضع المختار فعلًا. محاكيات Android وتطبيقات Flatpak المثبتة ليست ذاكرة تخزين مؤقت معتادة.

## إضافات المحررات {#editor-extensions}

يتناول `--editor-ext` إصدارات إضافات VS Code وCursor التي حلّ محلها إصدار أحدث. ويشترط وجود إصدار أحدث وإصدار قديم خامل، ويُحتفظ بالإصدار الحالي. انظر [إضافات المحررات](../modes/editor-extensions.md).

## ملفات المشاريع والملفات الشخصية — تفاعليًا فقط {#project-and-personal-files--interactive-only}

لمجلدات `node_modules` في المشاريع المهملة، والتنزيلات غير المكتملة، والملفات الشخصية الكبيرة المهملة المرشحة أوضاع تفاعلية منفصلة. ولا يوافق `--yes` على هذه الأوضاع. قد يكون تنزيل غير مكتمل أو ملف في `~/Downloads` النسخة الوحيدة الموجودة. يُقرأ كل مسار وعاقبته قبل التأكيد.

## تنظيف النظام (يتطلب sudo) {#system-cleanup-requires-sudo}

يسأل `--system` قبل خطوات apt وسجل النظام وSnap و`/tmp` وذاكرة الصفحات. تستخدم أوامر الحزم فيه `apt` و`dpkg`، ولا تتكيف مع Fedora أو Arch أو openSUSE. تسرد خطوة النواة الإصدارات المثبتة ولا تحذف أيًّا منها مباشرة. يستهدف تنظيف السجل 100 MB، ويُستخدم عمر 7 أيام لـ `/tmp` أيًّا كانت قيمة `--days`. وتفريغ ذاكرة الصفحات يؤثر في الذاكرة RAM لا في مساحة القرص. انظر [تنظيف النظام](../modes/system-cleanup.md) و[دعم التوزيعات](../distro-support.md).

## ما يرفض حذفه {#what-it-refuses-to-delete}

ترفض الحماية الجذر والمسارات المحمية في المجلد الرئيسي مثل `~/Documents` و`~/Pictures` و`~/.ssh` و`~/.config` و`~/.claude`. القائمة الدقيقة واستثناءاتها في [المسارات المحمية](../reference/protected-paths.md). ويفحص `--self-test` حالات رفض مختارة في النسخة المثبتة.

لا تراجع عن الحذف الفعلي. تشرح [المعاينة قبل الحذف](./preview-first.md) الترتيب المتبع قبل أي تنظيف.
