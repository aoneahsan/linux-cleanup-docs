# Linux のクリーナーを比較

各ツールは、公式サイトやリポジトリの記載をもとに、確認日とともに紹介しています。ページに書かれていないことは「確認したページには記載なし」とし、「なし」とは書きません。

ほかのプロジェクトへのリンクは新しいタブで開き、`nofollow` を付けています。

*最終確認：2026-11-22.*

| ツール | 概要 | 確認日 |
|---|---|---|
| [BleachBit](./bleachbit.md) | ディスク容量とプライバシーのためのオープンソースのクリーナー。グラフィカルなプレビューと CLI を備えています。 | 2026-11-22 |
| [Stacer](./stacer.md) | システムクリーナーを備えた Linux のシステムモニター兼最適化ツール。 | 2026-11-22 |
| [Sweeper](./sweeper.md) | Cookie、キャッシュ、そのほかの利用の痕跡を消す KDE のユーティリティ。 | 2026-11-22 |
| [Cross Cleaner](./cross-cleaner.md) | ウィンドウ版、ターミナル版、コマンドライン版があるクロスプラットフォームのクリーナー。 | 2026-11-22 |
| [CleanMate](./cleanmate.md) | デスクトップアプリ、ターミナルアプリ、削除前の確認フローを備えた macOS と Ubuntu 向けのクリーナー。 | 2026-11-22 |
| [TuxCleaner](./tuxcleaner.md) | 掃除、アプリのアンインストール、ディスク分析、状態確認のための Linux CLI。 | 2026-11-22 |
| [Ubuntu Cleaner](./ubuntu-cleaner.md) | パッケージと開発用キャッシュの保守を行う、Ubuntu、Debian、Linux Mint 向けの Bash クリーナー。 | 2026-11-22 |
| [Disk Cleaner](./disk-cleaner.md) | ディスクの可視化と掃除の提案を備えた Linux の GTK クリーナー。 | 2026-11-22 |
| [Czkawka](./czkawka.md) | 重複ファイル、空のフォルダー、似たメディアなどを見つけるユーティリティ。 | 2026-11-22 |
| [Safe Disk Cleaner](./safe-disk-cleaner.md) | ディスクのカテゴリを説明し、削除の前に確認する GTK 4 アプリ。 | 2026-11-22 |
