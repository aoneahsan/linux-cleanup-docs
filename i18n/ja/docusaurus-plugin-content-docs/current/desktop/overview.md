# デスクトップアプリ

デスクトップアプリは、ウィンドウで動く linux-cleanup です。このサイトで説明している CLI をそのまま同梱し、それを通じて 1 つのモードを実行します。[完全安全のクリーンアップ](../modes/all-safe.md)を、まずドライランで、確定すると本番で実行します。何を削除し何を拒否するかのルールはすべて CLI のもので、アプリはその判断を表示するだけで、変えることはありません。

## CLI の実行のしかた {#how-it-runs-the-cli}

アプリは、同梱の `cleanup.sh` を 2 通りの引数のどちらかだけで起動し、その [`--json-events`](../reference/json-events.md) の出力を読み取ります。

| 押すボタン | アプリが実行するもの |
|---|---|
| **ドライランを開始** | `--all-safe --yes --dry-run --json-events` |
| **今すぐクリーンアップを実行** | `--all-safe --yes --json-events` |

レポートとログは `~/.linux-cleanup/reports/` と `~/.linux-cleanup/logs/` に保存されます。`npx linux-cleanup` で実行したときと同じフォルダーなので、アプリとターミナルで履歴を共有します。

同梱のコピーは CLI 自身の更新チェックを行いません（`LINUX_CLEANUP_LAUNCHER=desktop`）。代わりにアプリが自分の更新を確認します。[インストールと更新](./install.md)を参照。

## コンピューターの外に出るもの {#what-leaves-your-computer}

| データ | 外に出るか |
|---|---|
| ファイルやフォルダーのパス、ファイル名 | 出ません |
| 手順の結果、サイズ、実行前後の空き容量、ディストリビューション名 | サインインしているときだけ、数値として |
| 開いた画面と実行した操作 | Amplitude で集計。パス、名前、メールアドレスは含みません |

サインインは任意です。サインインしなくても、ドライラン、本番実行、レシート、スケジュールはこのコンピューターで使えます。毎月の本番実行の回数はコンピューターごとに数えます。

## 削除は元に戻せない {#removal-is-permanent}

本番実行は CLI と同じようにファイルを削除します。完全に削除し、コピーは残しません。アプリは本番実行の前に最近のドライランを求め、何かを実行する前に確定画面でそのことをはっきり伝えます。
