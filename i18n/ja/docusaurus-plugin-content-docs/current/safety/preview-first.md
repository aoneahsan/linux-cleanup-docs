# 削除前のプレビュー

**まず `--scan` を実行し、次にクリーンアップモードを `--dry-run` 付きで実行してください。** スキャンは削除せずにパスとサイズを表示します。ドライランは選んだクリーンアップをたどって実行予定の操作を表示しますが、ファイルの削除や設定の変更は行いません。どちらもローカルのセッションログは作成します。

```bash
linux-cleanup --self-test
linux-cleanup --scan
linux-cleanup --all-safe --dry-run
```

`--self-test` は依存関係、Bash の構文、保護パスの安全装置を確認します。失敗した場合はそこで止めてください。

## スキャンで何がわかりますか？ {#what-does-the-scan-show}

`--scan` は、キャッシュのルート、途中で止まったダウンロード、重複していそうなダウンロード、大きく長期間使われていない個人ファイルの候補、システムに関する所見を一覧にします。キャッシュのルートについて表示されるサイズは**現在そこにあるすべて**であり、後のクリーンアップで削除される量ではありません。既定の 100 日のアイドルしきい値、現在の使用状況、各モードのルールによって、その大部分が残ることもあります。

スキャンは JSON のセッションレポートを作成しません。機械で読める形式が必要な場合は `linux-cleanup --scan --json-events` を使ってください。イベントにはローカルの完全なパスが含まれることがあるため、マシンの外に出さないでください。

## ドライランで何がわかりますか？ {#what-does-a-dry-run-show}

`--dry-run` は選んだクリーンアップをたどり、予定している操作を表示します。例：

```bash
linux-cleanup --all-safe --dry-run
linux-cleanup --all-safe --yes --dry-run --json-events > preview.ndjson
```

1 つ目のコマンドは、本番実行と同じように確認を求めます。2 つ目は非対話で、バージョン付きの JSON イベントを stdout に、人が読むテキストを stderr に出力します。どちらもファイルを削除しません。ドライランは JSON のセッションレポートを書き出しません。

プレビューは現時点のマシンのスナップショットであり、後の実行結果を約束するものではありません。プレビューから確定までのあいだに、ファイルが使われたり、変更されたり、削除されたりすることがあります。このツールには元に戻す機能もバックアップもありません。

## 本番実行の前に範囲を確認する {#check-the-boundary-before-a-real-run}

`--list-targets` は、ディスクを計測せずに、設定された対象ルートと保護パスを表示します。あるディレクトリが対象に入るかどうかを確かめるのに役立ちます。拒否のルールは[保護パスのリファレンス](../reference/protected-paths.md)にあります。

個人ファイル向けのモードとプロジェクト関連のモードは、通常のキャッシュクリーンアップとは別です。候補は 1 件ずつ確認してください。`--yes` は `--all-safe` にのみ適用され、個人ファイルの削除を承認するものではありません。

プレビューが意図どおりなら、使うモードを選び、その確認メッセージを読んでください。本番の削除は元に戻せません。
