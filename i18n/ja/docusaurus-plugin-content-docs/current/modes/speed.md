# 速度の診断

**`--speed` は、マシンが何に時間を使っているかを報告します。** 温度のカウンター、CPU・メモリ・I/O の負荷、重いプロセス、起動の情報を読み取ります。自動で起動するコンテナー、サービス、ログイン時のアプリも見つけられます。

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

ドライランは、確認するはずの変更を適用せずに報告します。通常の実行では、提案する変更ごとに個別に確認し、既定の答えは「いいえ」です。`--yes` ではこれらの修正は承認されません。

承認した修正の中には、コンテナーの停止、サービスの無効化、ユーザーのログイン設定の変更を行うものがあります。キャッシュファイルは削除しませんが、次回に起動するものが変わります。変更を適用すると、CLI が元に戻すためのコマンドを表示します。システムサービスを変更するときは sudo の確認が出ることがあります。

診断結果は測定値や状態であって、特定のアプリに問題があるという証拠ではありません。変更を承認する前に、示されたプロセスやサービスを確かめ、必要かどうかを判断してください。

シェルの起動時に見つからない実行環境のコマンドについては、別の [Doctor](./doctor.md) モードを使ってください。ディスク容量については、まず[スキャン](./scan.md)から。
