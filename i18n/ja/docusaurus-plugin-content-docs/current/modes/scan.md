# スキャン（読み取り専用）

**`--scan` は、ファイルを削除せずにパスと現在のサイズを一覧にします。** マシンを最初に見渡すためのものです。予定の操作を確かめるには、選んだクリーンアップモードのドライランを使ってください。

```bash
linux-cleanup --scan
```

## 何を調べますか？ {#what-does-it-inspect}

スキャンは、キャッシュやビルドツールのルートを表にして表示します。パッケージマネージャー、ブラウザー、Gradle、テストランナー、Android のツール、そのほか設定された場所です。途中のダウンロード、重複していそうなダウンロード、大きく長期間使われていない個人ファイルの候補、いくつかのシステムの所見も一覧にします。パッケージマネージャーの掃除は実行せず、`sudo` も求めません。

一覧にあるキャッシュのルートのサイズは、そこにいまあるすべてです。ツールが削除する量では**ありません**。何が残るかは、選んだモード、アイドルしきい値、現在の使用状況、拒否のルールで決まります。

スキャンはローカルのセッションログを書き出しますが、ガイド付きの手順の [JSON セッションレポート](../reference/report-schema.md)は書き出しません。

## モードを選ぶ前にパスを読む {#read-the-paths-before-choosing-a-mode}

見覚えのないパスは確認してください。シンボリックリンクは、見た目の名前とは別の場所を指していることがあります。クリーンアップの前に `realpath` で確かめてください。保護パスの安全装置も、削除の前にシンボリックリンクを解決します。

個人ファイルの候補は確認のために表示されるだけです。通常の `--all-safe` のクリーンアップでは選ばれません。キャッシュのクリーンアップをプレビューするには：

```bash
linux-cleanup --all-safe --dry-run
```

ドライランは削除せずにそのモードをたどります。それでもローカルのログと更新チェックの状態は書き込むことがあります。本番の削除は元に戻せません。

## 機械で読めるスキャン {#machine-readable-scan}

```bash
linux-cleanup --scan --json-events > scan.ndjson
```

[バージョン 1 のイベント](../reference/json-events.md)は stdout に、人が読むテキストは stderr に出力されます。ローカルの完全なパスが含まれることがあるので、このマシンの外に出さないでください。最後まで実行できたのか途中で切れたのかは、終了コードで判断してください。

## ほかの読み取り専用の表示 {#other-read-only-views}

| コマンド | 答える問い |
|---|---|
| `--list-targets` | モードが対象にできる、または拒否する設定済みのパスはどれか |
| `--audit` | クリーンアップモードの対象かどうかに関係なく、`$HOME` で大きい項目はどれか |
| `--globals` | インストールされているグローバルな実行環境のパッケージは何か |
| `--self-test` | 必須コマンド、構文、安全装置の確認がすべて通るか |

手順の順番は[削除前のプレビュー](../safety/preview-first.md)、モードのオプションは [CLI フラグ](../reference/cli-flags.md)を参照してください。
