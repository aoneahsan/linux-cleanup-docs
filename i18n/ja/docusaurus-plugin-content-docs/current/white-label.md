# ホワイトラベルとライセンス

**ホワイトラベルライセンス**を使うと、linux-cleanup をあなたの製品名、ロゴ、色で利用者に提供できます。ビルドと署名、あなたのリリースチャネルやサイトへの公開、更新は私たちが行います。コマンドラインは MIT ライセンスのオープンソースです。デスクトップアプリとそのバックエンドは私たちのもので、製品を買い取らない限り非公開のままです。

価格はここには載せていません。[ホワイトラベルの料金ページ](https://linux-cleanup.aoneahsan.com/ja/white-label/pricing)は開くたびにライセンスサービスへ価格を問い合わせるので、常に最新の金額が表示されます。

## 2 つの方法 {#two-ways-to-have-it}

| | ライセンス | 買い取り |
|---|---|---|
| 得られるもの | あなたの名前のビルド。運用は私たち | デスクトップアプリのソースとバックエンドを引き渡し |
| ソースコード | 含まない | デスクトップアプリをビルドするすべてのリポジトリ |
| 独占 | なし：ほかの会社にもライセンスすることがあります | あり：linux-cleanup の販売をやめます |
| 更新 | 6 か月分を含み、その後は延長 | 私たちから 6 か月、その後はあなたが保守 |
| 継続的な費用 | 更新がほしい場合は延長 | 製品の総売上の 7% のロイヤリティ |

## それぞれの内容 {#what-each-part-delivers}

| 項目 | ライセンスの場合 |
|---|---|
| デスクトップアプリ | あなたの名前の AppImage と .deb。署名済みで、あなたのリリースチャネルに公開し、自動で更新 |
| コマンドライン | あなたの名前の CLI。好きな場所に公開（例：あなた自身の npm のスコープ） |

## 始め方 {#how-it-starts}

1. [料金ページ](https://linux-cleanup.aoneahsan.com/ja/white-label/pricing)で項目を選ぶか、[買い取りのページ](https://linux-cleanup.aoneahsan.com/ja/white-label/buyout)を開いてください。
2. 支払いページに進んでください。私たちの Wise の情報が表示されるので、そこで送金し、送金の参照番号を送ってください。
3. 送金を確認すると、ライセンスまたは買い取りを発行し、メールでお届けします。
4. 製品名、ロゴ、色、ドメインまたはリリースチャネルをお送りください。ビルド、署名、公開を行い、各段階をメールでお知らせします。

製品がまだ対応していないことが必要ですか。[内容を書いて](https://linux-cleanup.aoneahsan.com/ja/white-label/custom-work)いただければ、書面で見積もりをお返しします。

## 更新と延長 {#updates-and-renewals}

各ライセンスには、支払いを確認した日から 6 か月分の更新が含まれます。あなたの名前でビルドし直した新しいリリースや、変化したディストリビューションやパッケージマネージャーへの修正です。その後も、ビルドは最後に受け取ったバージョンで動き続けます。[更新のページ](https://linux-cleanup.aoneahsan.com/ja/white-label/updates)で、ライセンスキーとライセンスに登録したメールアドレスを使って 3、6、12 か月延長できます。

## ライセンスの確認 {#verify-a-licence}

各ライセンスには公開のキーがあります。だれでも[ライセンスの確認](https://linux-cleanup.aoneahsan.com/ja/verify-license)で、キーや、ビルドが動いているドメインを確認できます。ライセンスを受けたビルドは、自分のドメインの `/.well-known/linuxcleanup-white-label-license.json` にライセンスファイルを公開します。

## よくある質問 {#questions}

**コマンドラインを自分でビルドしてもよいですか。** はい。MIT ライセンスです。ライセンスは、あなたの名前でのビルド、署名、公開、更新を私たちに任せたい場合のものです。

**ライセンスでデスクトップアプリのソースも受け取れますか。** いいえ。ソースを引き渡すのは買い取りの場合だけです。

契約の全文は、わかりやすい言葉で[ライセンス条件のページ](https://linux-cleanup.aoneahsan.com/ja/white-label/license-terms)に載せています。
