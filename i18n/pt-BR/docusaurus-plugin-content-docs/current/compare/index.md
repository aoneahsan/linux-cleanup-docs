# Comparar limpadores para Linux

Cada ferramenta é descrita a partir do próprio site ou repositório, com a data em que verificamos. O que as páginas dela não dizem aparece como “Não informado nas páginas que verificamos”, nunca como um não.

Os links para outros projetos abrem numa nova aba e levam `nofollow`.
