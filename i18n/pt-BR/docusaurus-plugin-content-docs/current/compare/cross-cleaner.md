# linux-cleanup e Cross Cleaner

*Conferido em 2026-11-22 com a <a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">página oficial do Cross Cleaner</a>.*

**O que é:** Um limpador multiplataforma com edições em janela, terminal e linha de comando.

**Preço lá:** Grátis (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">fonte</a>, verificado em 2026-11-22). **Preço aqui:** A linha de comando é gratuita sob a licença MIT. Os planos do aplicativo para desktop estão na [página de preços](https://linux-cleanup.aoneahsan.com/pt-BR/pricing).

| | linux-cleanup | Cross Cleaner |
|---|---|---|
| Interface de linha de comando | Sim | Sim (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">fonte</a>) |
| Prévia antes de apagar | Sim | Não informado nas páginas que verificamos |
| Simulação | Sim | Sim (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">fonte</a>) |
| Limpeza de cache | Sim | Sim (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">fonte</a>) |
| Busca de arquivos duplicados | Em parte | Não informado nas páginas que verificamos |

## Para quem o Cross Cleaner serve melhor {#who-is-better-served-by-cross-cleaner}

Escolha o Cross Cleaner se você precisa de um só limpador para Linux, Windows, macOS e Android.

## Onde o linux-cleanup está à frente {#where-linux-cleanup-is-ahead}

Escolha o linux-cleanup para uma ferramenta só para Linux cuja lista protegida recusa pelo nome ~/Documents, ~/.ssh e ~/.config, diga o que disser uma regra de cache.

## Por onde começar aqui {#where-to-start-here}

Não existe importação de uma ferramenta para a outra: cada uma mantém as próprias regras. Para ver o que o linux-cleanup faria no seu computador, comece por [Visualizar antes de apagar](../safety/preview-first.md) e rode `npx -y linux-cleanup --all-safe --yes --dry-run`, que não apaga nada.
