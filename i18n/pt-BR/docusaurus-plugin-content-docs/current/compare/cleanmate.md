# linux-cleanup e CleanMate

*Conferido em 2026-11-22 com a <a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">página oficial do CleanMate</a>.*

**O que é:** Um limpador para macOS e Ubuntu com app para desktop, app de terminal e um fluxo de revisão antes de remover.

**Preço lá:** Grátis (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fonte</a>, verificado em 2026-11-22). **Preço aqui:** A linha de comando é gratuita sob a licença MIT. Os planos do aplicativo para desktop estão na [página de preços](https://linux-cleanup.aoneahsan.com/pt-BR/pricing).

## Para quem o CleanMate serve melhor {#who-is-better-served-by-cleanmate}

Escolha o CleanMate se você quer o app de desktop para Ubuntu, o Space Lens ou o fluxo de Lixeira e desfazer para arquivos pessoais.

## Onde o linux-cleanup está à frente {#where-linux-cleanup-is-ahead}

Escolha o linux-cleanup se você quer uma linha de comando programável com fluxo de eventos JSON, e cada execução real gravada em um relatório JSON local.

## Por onde começar aqui {#where-to-start-here}

Não existe importação de uma ferramenta para a outra: cada uma mantém as próprias regras. Para ver o que o linux-cleanup faria no seu computador, comece por [Visualizar antes de apagar](../safety/preview-first.md) e rode `npx -y linux-cleanup --all-safe --yes --dry-run`, que não apaga nada.
