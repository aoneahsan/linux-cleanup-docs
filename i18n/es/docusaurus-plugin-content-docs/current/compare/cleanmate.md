# linux-cleanup y CleanMate

*Revisado el 2026-11-22 con la <a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">página propia de CleanMate</a>.*

**Qué es:** Un limpiador para macOS y Ubuntu con aplicación de escritorio, aplicación de terminal y un flujo de revisión antes de eliminar.

**Precio allí:** Gratis (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>, revisado el 2026-11-22). **Precio aquí:** La línea de comandos es gratuita bajo la licencia MIT. Los planes de la aplicación de escritorio están en la [página de precios](https://linux-cleanup.aoneahsan.com/es/pricing).

| | linux-cleanup | CleanMate |
|---|---|---|
| Interfaz de línea de comandos | Sí | Sí (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>) |
| Vista previa antes de eliminar | Sí | Sí (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>) |
| Simulación | Sí | No se indica en las páginas que revisamos |
| Limpieza de caché | Sí | Sí (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>) |
| Búsqueda de archivos duplicados | En parte | Sí (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>) |

## A quién le sirve más CleanMate {#who-is-better-served-by-cleanmate}

Elija CleanMate si quiere su aplicación de escritorio para Ubuntu, Space Lens o su flujo de Papelera y deshacer para archivos personales.

## Dónde linux-cleanup va por delante {#where-linux-cleanup-is-ahead}

Elija linux-cleanup si quiere una línea de comandos programable con un flujo de eventos JSON, y cada ejecución real escrita en un informe JSON local.

## Por dónde empezar aquí {#where-to-start-here}

No hay importación de una herramienta a otra: cada una mantiene sus propias reglas. Para ver lo que haría linux-cleanup en su equipo, empiece por [Revisar antes de eliminar](../safety/preview-first.md) y ejecute `npx -y linux-cleanup --all-safe --yes --dry-run`, que no elimina nada.
