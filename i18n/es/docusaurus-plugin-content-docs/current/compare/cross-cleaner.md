# linux-cleanup y Cross Cleaner

*Revisado el 2026-11-22 con la <a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">página propia de Cross Cleaner</a>.*

**Qué es:** Un limpiador multiplataforma con ediciones de ventana, terminal y línea de comandos.

**Precio allí:** Gratis (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">fuente</a>, revisado el 2026-11-22). **Precio aquí:** La línea de comandos es gratuita bajo la licencia MIT. ## A quién le sirve más Cross Cleaner {#who-is-better-served-by-cross-cleaner}

Elija Cross Cleaner si necesita un mismo limpiador para Linux, Windows, macOS y Android.

## Dónde linux-cleanup va por delante {#where-linux-cleanup-is-ahead}

Elija linux-cleanup para una herramienta solo para Linux cuya lista protegida rechaza por nombre ~/Documents, ~/.ssh y ~/.config, diga lo que diga una regla de caché.

## Por dónde empezar aquí {#where-to-start-here}

No hay importación de una herramienta a otra: cada una mantiene sus propias reglas. Para ver lo que haría linux-cleanup en su equipo, empiece por [Revisar antes de eliminar](../safety/preview-first.md) y ejecute `npx -y linux-cleanup --all-safe --yes --dry-run`, que no elimina nada.
