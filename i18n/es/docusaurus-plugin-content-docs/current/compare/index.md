# Comparar limpiadores de Linux

Cada herramienta se describe a partir de su propio sitio o repositorio, con la fecha en que lo revisamos. Lo que sus páginas no indican se escribe como “No se indica en las páginas que revisamos”, nunca como un no.

Los enlaces a otros proyectos se abren en una pestaña nueva y llevan `nofollow`.

*Revisado por última vez el 2026-11-22.*

| Herramienta | Qué es | Revisado |
|---|---|---|
| [BleachBit](./bleachbit.md) | Un limpiador de código abierto para espacio en disco y privacidad, con vista previa gráfica y CLI. | 2026-11-22 |
| [Stacer](./stacer.md) | Un monitor y optimizador de sistema para Linux con limpiador incluido. | 2026-11-22 |
| [Sweeper](./sweeper.md) | Una utilidad de KDE para borrar cookies, cachés y otros rastros de uso. | 2026-11-22 |
| [Cross Cleaner](./cross-cleaner.md) | Un limpiador multiplataforma con ediciones de ventana, terminal y línea de comandos. | 2026-11-22 |
| [CleanMate](./cleanmate.md) | Un limpiador para macOS y Ubuntu con aplicación de escritorio, aplicación de terminal y un flujo de revisión antes de eliminar. | 2026-11-22 |
| [TuxCleaner](./tuxcleaner.md) | Una CLI para Linux de limpieza, desinstalación de aplicaciones, análisis de disco y estado. | 2026-11-22 |
| [Ubuntu Cleaner](./ubuntu-cleaner.md) | Un limpiador en Bash para Ubuntu, Debian y Linux Mint con mantenimiento de paquetes y cachés de desarrollo. | 2026-11-22 |
| [Disk Cleaner](./disk-cleaner.md) | Un limpiador GTK para Linux con visualizaciones del disco y tareas de limpieza sugeridas. | 2026-11-22 |
| [Czkawka](./czkawka.md) | Una utilidad para encontrar duplicados, carpetas vacías, medios similares y otro desorden. | 2026-11-22 |
| [Safe Disk Cleaner](./safe-disk-cleaner.md) | Una aplicación GTK 4 que explica las categorías del disco y pregunta antes de eliminar. | 2026-11-22 |
