# Comparer les nettoyeurs Linux

Chaque outil est décrit à partir de son propre site ou dépôt, avec la date de notre vérification. Ce que leurs pages n’indiquent pas est noté « Non indiqué sur les pages consultées », jamais comme un non.

Les liens vers d’autres projets s’ouvrent dans un nouvel onglet et portent `nofollow`.

*Dernière vérification le 2026-11-22.*

| Outil | Ce que c’est | Vérifié |
|---|---|---|
| [BleachBit](./bleachbit.md) | Un nettoyeur open source pour l’espace disque et la vie privée, avec aperçu graphique et CLI. | 2026-11-22 |
| [Stacer](./stacer.md) | Un moniteur et optimiseur système pour Linux, avec un nettoyeur. | 2026-11-22 |
| [Sweeper](./sweeper.md) | Un utilitaire KDE pour effacer les cookies, les caches et les autres traces d’utilisation. | 2026-11-22 |
| [Cross Cleaner](./cross-cleaner.md) | Un nettoyeur multiplateforme avec des éditions fenêtrée, terminal et ligne de commande. | 2026-11-22 |
| [CleanMate](./cleanmate.md) | Un nettoyeur pour macOS et Ubuntu avec application de bureau, application terminal et un parcours de vérification avant suppression. | 2026-11-22 |
| [TuxCleaner](./tuxcleaner.md) | Une CLI Linux pour le nettoyage, la désinstallation d’applications, l’analyse du disque et l’état du système. | 2026-11-22 |
| [Ubuntu Cleaner](./ubuntu-cleaner.md) | Un nettoyeur Bash pour Ubuntu, Debian et Linux Mint, avec maintenance des paquets et des caches de développement. | 2026-11-22 |
| [Disk Cleaner](./disk-cleaner.md) | Un nettoyeur GTK pour Linux avec des visualisations du disque et des tâches de nettoyage suggérées. | 2026-11-22 |
| [Czkawka](./czkawka.md) | Un utilitaire de recherche de doublons, dossiers vides, médias similaires et autres encombrements. | 2026-11-22 |
| [Safe Disk Cleaner](./safe-disk-cleaner.md) | Une application GTK 4 qui explique les catégories du disque et demande avant de supprimer. | 2026-11-22 |
