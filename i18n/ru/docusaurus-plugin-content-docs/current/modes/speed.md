# Диагностика скорости

**`--speed` показывает, на что машина тратит время.** Он читает датчики температуры, нагрузку на процессор, память и ввод-вывод, тяжёлые процессы и сведения о загрузке. Он также находит контейнеры, службы и приложения входа, которые запускаются сами.

```bash
linux-cleanup --speed --dry-run
linux-cleanup --speed
```

Пробный запуск показывает изменения, о которых он спросил бы, не применяя их. Обычный запуск спрашивает отдельно перед каждым предложенным изменением; ответ по умолчанию — «Нет». `--yes` эти исправления не разрешает.

Некоторые принятые исправления останавливают контейнер, отключают службу или меняют настройку входа пользователя. Они не удаляют файлы кэша, но влияют на то, что запустится в следующий раз. После применения изменения CLI печатает команду для отмены. При изменении системной службы может появиться запрос sudo.

Находка — это измерение или состояние, а не доказательство того, что конкретное приложение неисправно. Прежде чем принять изменение, прочитайте, о каком процессе или службе речь, и решите, нужен ли он вам.

Для отсутствующих команд при запуске оболочки используйте отдельный режим [Doctor](./doctor.md). Для места на диске начните со [сканирования](./scan.md).
