# Сканирование (только чтение)

**`--scan` перечисляет пути и их текущий размер, ничего не удаляя.** Это первый взгляд на машину. Чтобы увидеть предлагаемые действия, выполните пробный запуск выбранного режима очистки.

```bash
linux-cleanup --scan
```

## Что он просматривает? {#what-does-it-inspect}

Сканирование печатает таблицу корней кэша и инструментов сборки: менеджеры пакетов, браузеры, Gradle, средства запуска тестов, инструменты Android и другие настроенные места. Оно также перечисляет недокачанные загрузки, вероятные дубликаты загрузок, крупные давно не используемые личные файлы-кандидаты и несколько наблюдений о системе. Оно не запускает очистку менеджеров пакетов и не просит `sudo`.

Размер перечисленного корня кэша — это всё, что в нём сейчас есть. Это **не** объём, который удалит инструмент. Что останется, определяют выбранный режим, порог простоя, текущее использование и правила отказа.

Сканирование пишет локальный журнал сеанса. Оно не пишет [JSON-отчёт о сеансе](../reference/report-schema.md) пошагового сценария.

## Прочитайте пути, прежде чем выбрать режим {#read-the-paths-before-choosing-a-mode}

Проверьте пути, которые вам незнакомы. Символическая ссылка может вести не туда, куда намекает её имя; перед очисткой посмотрите её через `realpath`. Защита путей тоже разрешает ссылки перед удалением.

Личные файлы-кандидаты показываются только для просмотра. Обычная очистка `--all-safe` их не выбирает. Чтобы просмотреть очистку кэша:

```bash
linux-cleanup --all-safe --dry-run
```

Пробный запуск проходит этот режим без удаления. Он всё равно может записать локальный журнал и состояние проверки обновлений. Реальное удаление нельзя отменить.

## Машиночитаемое сканирование {#machine-readable-scan}

```bash
linux-cleanup --scan --json-events > scan.ndjson
```

[Поток событий версии 1](../reference/json-events.md) идёт в stdout, текст для людей — в stderr. Он может содержать полные локальные пути. Держите его на этой машине и по коду выхода отличайте полный запуск от прерванного потока.

## Другие представления только для чтения {#other-read-only-views}

| Команда | На какой вопрос отвечает |
|---|---|
| `--list-targets` | Какие настроенные пути режим может затронуть или отклонить? |
| `--audit` | Какие элементы в `$HOME` самые крупные, независимо от того, охватывает ли их режим очистки? |
| `--globals` | Какие глобальные пакеты сред выполнения установлены? |
| `--self-test` | Проходят ли проверки обязательных команд, синтаксиса и защит? |

Порядок действий — в разделе [Предпросмотр перед удалением](../safety/preview-first.md), параметры режимов — в разделе [Флаги CLI](../reference/cli-flags.md).
