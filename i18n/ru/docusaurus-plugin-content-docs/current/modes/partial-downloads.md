# Недокачанные и брошенные загрузки

**`--partials` находит брошенные файлы недокачанных загрузок и предлагает их удалить.** Это временные файлы, которые браузер или менеджер загрузок пишет во время передачи и забывает убрать, если она прервалась.

```bash
linux-cleanup --partials
```

## Что он ищет {#what-it-looks-for}

| Расширение | Кто пишет |
|---|---|
| `.crdownload` | Chrome, Chromium, Brave, Edge, Vivaldi |
| `.part` | Firefox, wget, aria2 |
| `.fdmdownload` | Free Download Manager |

Недокачанный файл содержит столько байтов, сколько успело прийти до обрыва: иногда несколько килобайт, иногда почти весь многогигабайтный ISO.

## Только интерактивно {#interactive-only}

Подтверждение по каждому файлу, `--yes` игнорируется, в [`--all-safe`](./all-safe.md) не входит. См. [барьер 3](../safety/guards.md#guard-3--personal-data-is-interactive-only).

## Чего стоит удаление {#what-deleting-one-costs-you}

:::caution Недокачанный файл, возможно, ещё можно докачать — но обычно нет
Для продолжения нужен исходный сеанс загрузки: запись в менеджере загрузок браузера, исходный URL и сервер, поддерживающий запросы диапазонов. Если браузер перезапускался или запись о загрузке удалена, файл докачать нельзя и он просто занимает место.

Сам по себе файл бесполезен — наполовину скачанный архив не откроется. Так что вопрос лишь в том, собираетесь ли вы его докачивать.
:::

Прежде чем согласиться на удаление крупного файла:

- Откройте страницу загрузок браузера и найдите приостановленную или неудачную загрузку с тем же именем файла
- Если она есть, продолжите её там, а не удаляйте файл
- Если нет, файл брошен, и его можно спокойно удалить

## Здесь появится и идущая загрузка {#an-active-download-will-show-up-here}

У загрузки, которая идёт *прямо сейчас*, тоже есть файл `.crdownload` или `.part`. Инструмент не может отличить идущую передачу от брошенной. Удаление активного файла прервёт загрузку — поэтому при сомнении проверьте страницу загрузок или запускайте этот режим, когда ничего не скачивается.
