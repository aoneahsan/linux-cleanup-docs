# Меню

**`--menu` печатает нумерованный список всех категорий и запускает выбранную.** Пользуйтесь им, когда знаете, что нужно, и десятишаговый обход не требуется.

```bash
linux-cleanup --menu     # или: -m, -i, --interactive
```

## Чем оно отличается от пошагового сценария {#how-it-differs-from-the-walkthrough}

| | Меню | [Пошаговый сценарий](./walkthrough.md) |
|---|---|---|
| Порядок | Выбираете вы | Фиксированный, десять шагов |
| Охват | Одна категория за выбор | Всё по очереди |
| Повтор | Затем возвращается в меню | Идёт до конца |
| Отчёт | По каждому действию | Один отчёт за сеанс |
| Лучше всего для | Точечной очистки | Первых запусков, полной очистки |

Модель безопасности та же. Каждая категория ведёт себя ровно так же, как в пошаговом сценарии: действуют [список разрешённых путей](../safety/guards.md#guard-1--the-path-allowlist), [порог простоя](../safety/guards.md#guard-2--the-staleness-gate) и подтверждение по каждой цели. Если выбрать в меню категорию личных данных, вопросы по каждому пункту всё равно будут, и `--yes` на неё по-прежнему не действует.

## Параметры по-прежнему работают {#options-still-apply}

```bash
linux-cleanup --menu -d 30        # порог 30 дней для выбранного
linux-cleanup --menu --purge-all  # порог простоя отключён
linux-cleanup --menu --no-color   # вывод без цвета
```

## Когда лучше TUI {#when-to-use-the-tui-instead}

[`--tui`](./tui.md) — то же меню в окне whiptail или dialog. Для него нужен один из них; `--menu` не требует ничего, кроме bash, и работает при любом подключении, в том числе в простом терминале или в сеансе `ssh -T`, где полноэкранное окно сработает плохо.
