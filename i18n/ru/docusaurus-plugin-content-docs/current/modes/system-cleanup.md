# Очистка системы (sudo)

**`--system` запрашивает sudo перед началом, а затем спрашивает о каждом системном шаге.** Для работы с пакетами он напрямую использует `apt` и `dpkg`, поэтому полный режим — для Debian и Ubuntu. В других дистрибутивах могут сработать части с журналом или `/tmp`, но команды пакетов завершатся ошибкой; см. [Поддержка дистрибутивов](../distro-support.md).

```bash
linux-cleanup --system --dry-run
linux-cleanup --system
```

Пробный запуск печатает предлагаемые команды, не удаляя цели очистки и не меняя настройки. Он всё равно может записать локальный журнал и состояние проверки обновлений. Просмотрите его перед реальным запуском, который нельзя отменить.

## Шесть шагов {#the-six-steps}

| Шаг | Что выполняет код после подтверждения | По умолчанию |
|---|---|---|
| apt | `sudo apt autoremove --purge -y`, `sudo apt clean` | Да |
| Журнал | `sudo journalctl --vacuum-size=100M` | Да |
| Snap | Подходящие отключённые ревизии через `sudo snap remove` | Да |
| Ядра | Список установленных пакетов `linux-image-*` через `dpkg` | Ничего не удаляет |
| `/tmp` | `sudo find /tmp -mindepth 1 -atime +7 -delete` | Да |
| Кэш страниц | `sudo sync`, `sudo sysctl -q -w vm.drop_caches=3` | Нет |

Цель для журнала — 100 MB, возраст для `/tmp` — 7 дней; ни то ни другое не зависит от `--days`. Шаг Snap сохраняет отключённую ревизию для отката, пока её замена не достигнет настроенного порога возраста, если не указан `--purge-all`. Список ядер носит справочный характер; apt может удалить вытесненные пакеты ядра на своём предыдущем шаге.

Шаг `/tmp` опирается на время доступа. Если файловая система не записывает его надёжно, инструмент пропускает удаление по возрасту. Сброс кэша страниц освобождает RAM, а не диск, и может замедлить последующее чтение, пока кэш снова заполняется.

## Границы {#boundaries}

Пока режим работает, он кэширует учётные данные sudo, чтобы выполнять свои отдельные команды. Не начинайте очистку системы, если не готовы просмотреть эти команды. У `--speed` есть свои необязательные исправления, которые тоже могут запросить sudo; системный режим — не единственный путь в CLI, использующий sudo.

Сколько места освободится, зависит от машины. Изменение места на диске, измеренное после запуска, может включать и записи других процессов. Какие команды пытался выполнить инструмент, смотрите в журнале.
