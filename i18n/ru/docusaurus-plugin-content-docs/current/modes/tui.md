# TUI (визуальное меню)

**`--tui` показывает меню категорий в полноэкранном окне whiptail или dialog.** Появилось в [1.3.0](../changelog.md#130--2026-05-10). Поведение как у [`--menu`](./menu.md), другое оформление.

```bash
linux-cleanup --tui      # или: -t, -g, --gui
```

## Как оно работает {#how-it-behaves}

При выборе пункта окно закрывается, категория выполняется с обычным выводом и вопросами CLI, затем снова открывается меню. То есть окно лишь запускает действия — настоящие подтверждения остаются обычными текстовыми вопросами, и все защиты на месте.

В TUI есть также окно **О программе** с версией, контактами, лицензией и обязательством о конфиденциальности.

## Требования и запасной вариант {#requirements-and-fallback}

Нужен `whiptail` или `dialog`. Если нет ни того ни другого, инструмент печатает подсказку по установке для вашего дистрибутива и переходит в обычное меню CLI — без ошибки.

```bash
sudo apt install whiptail     # Debian / Ubuntu
sudo dnf install newt         # Fedora / RHEL
sudo pacman -S libnewt        # Arch
```

В системах RPM и Arch `whiptail` входит в пакеты `newt` / `libnewt`, поэтому имя пакета не совпадает с именем команды.

:::note Только здесь инструмент определяет ваш дистрибутив
Подсказка по установке выше учитывает дистрибутив. Больше нигде в linux-cleanup этого нет — в частности, [`--system` рассчитан на Debian/Ubuntu](../distro-support.md).
:::

## Когда пользоваться простым меню {#when-to-use-the-plain-menu}

`--tui` нужен терминал, способный показать полноэкранное окно. При ограниченном подключении, в журнале CI или в сеансе `ssh -T` без TTY используйте [`--menu`](./menu.md) — ему нужен только bash.
