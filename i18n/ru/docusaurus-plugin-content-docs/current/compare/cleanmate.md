# linux-cleanup и CleanMate

*Проверено 2026-11-22 по <a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">странице CleanMate</a>.*

**Что это:** Очиститель для macOS и Ubuntu с настольным приложением, терминальным приложением и проверкой перед удалением.

**Цена у них:** Бесплатно (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">источник</a>, проверено 2026-11-22). **Цена здесь:** Командная строка бесплатна по лицензии MIT. Тарифы настольного приложения — на [странице цен](https://linux-cleanup.aoneahsan.com/ru/pricing).

| | linux-cleanup | CleanMate |
|---|---|---|
| Интерфейс командной строки | Да | Да (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Предпросмотр перед удалением | Да | Да (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Пробный запуск | Да | На проверенных страницах не указано |
| Очистка кэша | Да | Да (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Поиск дубликатов | Частично | Да (<a href="https://cleanmate.homielab.com/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |

## Кому лучше подходит CleanMate {#who-is-better-served-by-cleanmate}

Выбирайте CleanMate, если нужны его приложение для Ubuntu, Space Lens или корзина с отменой для личных файлов.

## В чём впереди linux-cleanup {#where-linux-cleanup-is-ahead}

Выбирайте linux-cleanup, если нужна командная строка для скриптов с потоком JSON-событий и запись каждого реального запуска в локальный JSON-отчёт.

## С чего начать здесь {#where-to-start-here}

Импорта из одного инструмента в другой нет: у каждого свои правила. Чтобы увидеть, что linux-cleanup сделает на вашем компьютере, начните с раздела [Предпросмотр перед удалением](../safety/preview-first.md) и выполните `npx -y linux-cleanup --all-safe --yes --dry-run` — эта команда ничего не удаляет.
