# linux-cleanup и Cross Cleaner

*Проверено 2026-11-22 по <a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">странице Cross Cleaner</a>.*

**Что это:** Кроссплатформенный очиститель с оконной, терминальной и консольной версиями.

**Цена у них:** Бесплатно (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">источник</a>, проверено 2026-11-22). **Цена здесь:** Командная строка бесплатна по лицензии MIT. Тарифы настольного приложения — на [странице цен](https://linux-cleanup.aoneahsan.com/ru/pricing).

| | linux-cleanup | Cross Cleaner |
|---|---|---|
| Интерфейс командной строки | Да | Да (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Предпросмотр перед удалением | Да | На проверенных страницах не указано |
| Пробный запуск | Да | Да (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Очистка кэша | Да | Да (<a href="https://cross-cleaner.github.io/" target="_blank" rel="noopener noreferrer nofollow">источник</a>) |
| Поиск дубликатов | Частично | На проверенных страницах не указано |

## Кому лучше подходит Cross Cleaner {#who-is-better-served-by-cross-cleaner}

Выбирайте Cross Cleaner, если нужен один очиститель для Linux, Windows, macOS и Android.

## В чём впереди linux-cleanup {#where-linux-cleanup-is-ahead}

Выбирайте linux-cleanup — инструмент только для Linux, чей защищённый список по имени отклоняет ~/Documents, ~/.ssh и ~/.config, что бы ни говорило правило кэша.

## С чего начать здесь {#where-to-start-here}

Импорта из одного инструмента в другой нет: у каждого свои правила. Чтобы увидеть, что linux-cleanup сделает на вашем компьютере, начните с раздела [Предпросмотр перед удалением](../safety/preview-first.md) и выполните `npx -y linux-cleanup --all-safe --yes --dry-run` — эта команда ничего не удаляет.
