# Предпросмотр перед удалением

**Начните с `--scan`, затем запустите режим очистки с `--dry-run`.** Сканирование показывает пути и размеры без удаления. Пробный запуск проходит выбранную очистку и печатает действия, которые он выполнил бы, не удаляя файлы и не меняя настройки. Оба всё равно создают локальный журнал сеанса.

```bash
linux-cleanup --self-test
linux-cleanup --scan
linux-cleanup --all-safe --dry-run
```

`--self-test` проверяет зависимости, синтаксис Bash и защиту путей. Если он не проходит, остановитесь.

## Что показывает сканирование? {#what-does-the-scan-show}

`--scan` перечисляет корни кэша, недокачанные загрузки, вероятные дубликаты загрузок, крупные давно не используемые личные файлы-кандидаты и наблюдения о системе. Размер корня кэша — это **всё, что там сейчас лежит**, а не то, что удалит последующая очистка. Порог простоя по умолчанию в 100 дней, текущее использование и правила режима могут сохранить большую часть.

Сканирование не создаёт JSON-отчёт о сеансе. Для машиночитаемого сканирования используйте `linux-cleanup --scan --json-events`. Поток событий может содержать полные локальные пути — держите его на своей машине.

## Что показывает пробный запуск? {#what-does-a-dry-run-show}

`--dry-run` проходит выбранную очистку и печатает предлагаемые действия. Например:

```bash
linux-cleanup --all-safe --dry-run
linux-cleanup --all-safe --yes --dry-run --json-events > preview.ndjson
```

Первая команда, как и реальный запуск, спрашивает подтверждение. Вторая неинтерактивна и пишет версионированные JSON-события в stdout; текст для людей уходит в stderr. Ни одна не удаляет файлы. Пробный запуск не пишет JSON-отчёт о сеансе.

Предпросмотр — снимок машины в текущий момент, а не обещание о последующем запуске. Между предпросмотром и подтверждением файлы могут использоваться, меняться или удаляться. У инструмента нет ни отмены, ни резервной копии.

## Проверьте границы перед реальным запуском {#check-the-boundary-before-a-real-run}

`--list-targets` печатает настроенные целевые корни и защищённые пути, не измеряя диск. Это помогает понять, входит ли каталог в область действия. [Справочник защищённых путей](../reference/protected-paths.md) описывает правила отказа.

Режимы для личных файлов и для проектов отделены от обычной очистки кэша. Просматривайте их кандидатов по одному. `--yes` действует только для `--all-safe` и не разрешает удаление личных файлов.

Когда предпросмотр совпадает с вашим намерением, выберите режим и прочитайте его подтверждение. Реальное удаление безвозвратно.
