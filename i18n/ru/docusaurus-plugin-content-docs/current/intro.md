# linux-cleanup

**linux-cleanup показывает пути, прежде чем удалить в Linux кэш, который можно создать заново.** Он охватывает кэш менеджеров пакетов, браузеров и инструментов сборки, а для системной работы и личных файлов-кандидатов есть отдельные режимы. Начните со сканирования только для чтения или пробного запуска, а потом выбирайте реальную очистку.

Скачать linux-cleanup: [в npm](https://www.npmjs.com/package/linux-cleanup) · [сайт](https://linux-cleanup.aoneahsan.com) · [все варианты](/apps)

Это **инструмент, который удаляет**. Каждое удаление безвозвратно, отменить его нельзя. Его безопасность в том, что он с самого начала отказывается трогать не то, а не в том, что умеет вернуть удалённое.

:::danger Этот инструмент безвозвратно удаляет файлы
Нет отмены, корзины или резервной копии. Реальная очистка навсегда удаляет выбранные файлы. Перед подтверждением просмотрите выбранный режим с `--dry-run`.

Прежде чем позволить ему что-либо удалить, прочитайте **[Что удаляется](./safety/what-it-deletes.md)** и запустите **[предпросмотр только для чтения](./safety/preview-first.md)**.
:::

## Что он умеет хорошо {#what-it-is-good-at}

- **Показывать кандидатов.** Сканирование называет корни кэша и их текущий размер. Пробный запуск проходит выбранную очистку и называет предлагаемые действия.
- **Не удалять лишнее.** [Список разрешённых путей](./reference/protected-paths.md) после разрешения символических ссылок жёстко отклоняет `~/Documents`, `~/.ssh`, `~/.config`, `/etc` и подобные.
- **Не трогать недавно использованные файлы.** С версии 1.2.0 по умолчанию выполняется *прореживание*, а не полная очистка: в кэше удаляются только файлы, которых не касались 100+ дней. См. [порог простоя](./safety/guards.md#guard-2--the-staleness-gate).
- **Записывать запуск.** CLI ведёт локальный журнал. Пошаговые сценарии пишут [JSON-отчёт о сеансе](./reference/report-schema.md), если его не отключили; пробные запуски — нет.
- **Проверять обновления.** При запуске CLI, если может, читает публичную запись о выпусках по HTTPS.

## Чем он не является {#what-it-is-not}

Ясность в границах полезнее списка возможностей.

- **Не инструмент резервного копирования.** Он удаляет и никогда не архивирует. Удалённое им нельзя восстановить средствами самого инструмента.
- **Не инструмент отмены.** [`--scan`](./modes/scan.md) только читает; `--dry-run` показывает выбранную очистку; ни один не вернёт файлы после реального запуска.
- **Не сканер безопасности.** Он не ищет секреты, вредоносные программы или уязвимости.
- **Не кроссплатформенный.** Только Linux. Пакет npm объявляет `"os": ["linux"]`.
- **Не во всех дистрибутивах одинаково.** Очистка кэша внутри `$HOME` работает везде, но [режим `--system` — только для Debian/Ubuntu](./distro-support.md): он напрямую вызывает `apt` и `dpkg`.
- **Не замена вашему суждению.** Прочитайте, что он предлагает, прежде чем подтвердить.

## Версия на 30 секунд {#the-30-second-version}

```bash
# 1. Посмотреть, сколько можно освободить. Ничего не удаляет.
npx linux-cleanup --scan

# 2. Просмотреть выбранную очистку без удаления.
npx linux-cleanup --all-safe --dry-run

# 3. Запустить пошаговый сценарий. Проверять каждый выбор перед удалением.
npx linux-cleanup
```

Шаг 3 — режим по умолчанию. Он проходит десять категорий, спрашивает перед каждой, показывает нарастающий итог освобождённых байтов и в конце пишет отчёт. См. [Пошаговый сценарий](./modes/walkthrough.md).
