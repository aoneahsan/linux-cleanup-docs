# Расписания

Расписания входят в тарифы Pro и Team. Расписание — это пара **пользовательских юнитов systemd** в `~/.config/systemd/user/` с именами `linux-cleanup-schedule-<id>.timer` и `.service`. Оно запускает пробный запуск или полностью безопасную очистку ежедневно, еженедельно или в определённый день месяца (с 1 по 28).

Таймер использует `Persistent=true`: если в назначенное время компьютер был выключен, запуск произойдёт при следующем входе. Каждый запуск по расписанию пишет поток событий в `~/.linux-cleanup/schedule-runs/`, а приложение при следующем открытии превращает его в отчёт.

Поскольку файлы AppImage исчезают после закрытия приложения, расписание запускает копию встроенного CLI в `~/.linux-cleanup/desktop-engine/`. Приложение обновляет эту копию при каждом запуске, так что таймер всегда выполняет ту версию, которая поставляется с приложением.

Чтобы посмотреть или остановить таймер из терминала:

```bash
systemctl --user list-timers 'linux-cleanup-schedule-*'
systemctl --user disable --now linux-cleanup-schedule-<id>.timer
```
