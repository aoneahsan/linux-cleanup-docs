# Неполадки приложения

Экран **Справка › Ошибки и офлайн** в приложении описывает те же случаи, с кнопкой для каждого. Эта страница — подробная версия.

## AppImage не открывается {#the-appimage-does-not-open}

- **Двойной щелчок ничего не делает.** Файл должен быть исполняемым: `chmod +x linux-cleanup_*_amd64.AppImage`.
- **Ошибка упоминает FUSE.** AppImage монтирует себя через FUSE 2. В Ubuntu 22.04 и новее он не устанавливается по умолчанию: `sudo apt install libfuse2` (в Ubuntu 24.04 — `libfuse2t64`). Без него AppImage можно запустить и так: `./linux-cleanup_*_amd64.AppImage --appimage-extract-and-run`.
- **Ошибка упоминает WebKitGTK или `libwebkit2gtk-4.1`.** Окну нужен WebKitGTK 4.1 из вашего дистрибутива. В Debian и Ubuntu `.deb` подтягивает его сам; для AppImage установите `libwebkit2gtk-4.1-0`.

## Приложение сообщает, что встроенного CLI нет {#the-app-says-the-bundled-cli-is-missing}

При запуске приложение проверяет свою копию `cleanup.sh`. Если проверка не проходит, установка повреждена: скачайте выпуск заново со [страницы загрузки](https://linux-cleanup.aoneahsan.com/download). Переустановка не затрагивает ваши отчёты и журналы.

## Вход не завершается {#sign-in-does-not-finish}

Вход выполняется в браузере и возвращается в приложение через `127.0.0.1`. Если браузер показывает результат, а приложение не продолжает, возможно, локальные адреса блокирует брандмауэр или расширение браузера. Неудачный вход ничего не меняет; кнопку **Войти через Google** можно нажать снова.

## Сервер учётных записей не отвечает {#the-account-server-does-not-answer}

Пробным и реальным запускам, отчётам и расписаниям интернет не нужен никогда. Без сети приложение продолжает считать реальные запуски по месячному лимиту этого компьютера и синхронизируется, когда сервер снова ответит. Ждут только изменения тарифа и синхронизация истории.

## Расписание не сработало {#a-schedule-did-not-run}

```bash
systemctl --user list-timers 'linux-cleanup-schedule-*'
journalctl --user -u 'linux-cleanup-schedule-*' --since today
```

Таймер срабатывает только пока вы вошли в систему; пропущенный при выключенном компьютере запуск выполнится при следующем входе. Каждый запуск, который всё-таки начался, оставляет поток в `~/.linux-cleanup/schedule-runs/`, а приложение при следующем открытии превращает его в отчёт.
