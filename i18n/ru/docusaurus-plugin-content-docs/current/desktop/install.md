# Установка и обновление

Скачайте текущий выпуск со [страницы загрузки](https://linux-cleanup.aoneahsan.com/download); каждый выпуск есть и на [GitHub Releases](https://github.com/aoneahsan/linux-cleanup/releases) с тегом `desktop-v<version>`. В каждом выпуске два установщика:

| Файл | Для чего |
|---|---|
| `linux-cleanup_<version>_amd64.AppImage` | Любой дистрибутив с рабочим столом. Сделайте файл исполняемым и запустите |
| `linux-cleanup_<version>_amd64.deb` | Debian, Ubuntu и производные (`sudo apt install ./linux-cleanup_<version>_amd64.deb`) |

```bash
chmod +x linux-cleanup_*_amd64.AppImage
./linux-cleanup_*_amd64.AppImage
```

Начиная с версии 1.0.4, AppImage при первом запуске добавляет себя в меню приложений: записывает `~/.local/share/applications/linux-cleanup-desktop.desktop` и значок в `~/.local/share/icons/hicolor/` и направляет пункт меню туда, где лежит файл. Если вы переместите AppImage, запустите его один раз с нового места, и пункт меню последует за ним. `.deb` устанавливает собственный пункт меню.

Настольному приложению нужны WebKitGTK 4.1 и GTK 3, которые есть в современных дистрибутивах с рабочим столом. `.deb` объявляет их зависимостями.

## Как оно обновляется {#how-it-updates}

Приложение обновляется само. Оно ищет подписанное обновление при запуске, когда окно снова появляется на экране, и в момент публикации нового выпуска. При включённом параметре **Устанавливать обновления автоматически** (по умолчанию) оно скачивает обновление, проверяет подпись и перезапускается в спокойный момент — никогда во время запуска очистки.

**AppImage** заменяется на месте. Установка из **`.deb`** обновляется через `dpkg`, поэтому рабочий стол сначала запрашивает пароль администратора (обычное графическое окно); если отменить, продолжит работать текущая версия.

Выпуск может быть помечен как **обязательный**:

- **срочный** выпуск сразу останавливает приложение, объясняет причину и предлагает одну кнопку **Обновить**;
- **обычный** выпуск сообщает, что вышла новая версия, и со следующего запуска становится обязательным.

Если при проверке нет сети, приложение продолжает работать; неудачная проверка никогда не блокирует запуск.
