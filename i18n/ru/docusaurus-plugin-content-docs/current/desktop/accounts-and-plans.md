# Учётные записи и тарифы

В каждом тарифе есть полная полностью безопасная очистка, неограниченные пробные запуски и тот же защищённый список. Меняется число реальных запусков и дополнения вокруг них.

| | Бесплатный | Pro | Team |
|---|---|---|---|
| Реальные запуски | 15 в месяц на компьютер и ещё 15 после входа | Без месячного лимита | Без месячного лимита, для каждого места |
| Синхронизированные отчёты (только числа) | Нет | До 5 компьютеров | До 5 компьютеров на место |
| Расписания | Нет | Да | Да |
| Экспорт | Нет | Да | Да |
| Командный отчёт | Нет | Нет | Да |

Цены и лимиты заданы в записях тарифов, которые читают и приложение, и сайт; актуальные значения — на [странице цен](https://linux-cleanup.aoneahsan.com/pricing).

Вход только через Google. Вход добавляет реальные запуски, сохраняет отчёты на всех ваших компьютерах и хранит ваш тариф. Удаление учётной записи в разделе **Учётная запись** удаляет её и синхронизированные числа с наших серверов; отчёты, журналы и файлы на вашем компьютере остаются на месте.
