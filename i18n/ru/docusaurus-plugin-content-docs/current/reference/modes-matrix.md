## Режимы, которые никогда ничего не удаляют {#modes-that-never-delete-anything}

Эти команды не удаляют цели очистки. Некоторые пишут локальные журналы, отчёты, экспорт или диагностические пакеты:

`--scan` · `--audit` · `--globals` · `--list-targets` · `--self-test` · `--version` · `--export` ·
`--feedback` · `--debug-bundle`

Сюда же относится `--doctor` — с оговоркой: он меняет настройки оболочки, но только **дописывает** строки после подтверждения. Существующую строку он никогда не удаляет и не переписывает.

## Режимы, на которые действует `--yes` {#modes---yes-affects}

Ровно один: [`--all-safe`](../modes/all-safe.md).

Интерактивные режимы для личных данных — `--stale`, `--partials`, `--node-modules` — требуют собственных подтверждений. См. [барьер 3](../safety/guards.md#guard-3--personal-data-is-interactive-only).

## Режимы, к которым применяется порог простоя {#modes-the-staleness-gate-applies-to}

| Применяется | Не применяется |
|---|---|
| Очистка кэшей в пошаговом сценарии, меню, TUI и полностью безопасной очистке | `--system` (своё жёсткое правило 7 дней для `/tmp`) |
| Замена версий в `--editor-ext` | `--partials` (возраст — не критерий) |
| `--node-modules` | Режимы только для чтения (ничего не удаляется) |
| `--stale` |  |
| Данные инструментов разработчика (AVD, flatpak, pub-cache) |  |

`--purge-all` отключает порог везде, где он иначе применялся бы.

## Каким режимам нужны необязательные зависимости {#which-modes-need-optional-dependencies}

| Режим | Нужно | Без этого |
|---|---|---|
| `--tui` | `whiptail` или `dialog` | Переходит на `--menu` с подсказкой по установке |
| Преобразование в `--export`, `--reports` | `jq` | JSON всё равно пишется; преобразование недоступно |
| `--install-cron` | `crontab` | Не может запуститься |
| Шаг snap в `--system` | `snap` | Шаг аккуратно пропускается |
| Шаги apt в `--system` | `apt`, `dpkg` | **Сбой** — [только Debian/Ubuntu](../distro-support.md) |
