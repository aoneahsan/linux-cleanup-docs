# Флаги CLI

**Все флаги, которые принимает linux-cleanup.** Режимы взаимоисключающие — передайте один. Параметры сочетаются с любым режимом.

```bash
linux-cleanup --help    # тот же список с реальными путями вашей машины
```

Нераспознанный флаг печатает справку и завершает работу с кодом `2`.

## Режимы {#modes}

Передайте не больше одного. Без режима запускается [пошаговый сценарий](../modes/walkthrough.md).

## Параметры {#options}

| Флаг | По умолчанию | Действие |
|---|---|---|
| `-d N` `--days N` | `100` | Порог простоя. Файл подходит, только если **и** `atime`, **и** `mtime` его превышают. Чем меньше значение, тем агрессивнее |
| `--purge-all` | выкл. | **Отключает порог простоя.** Кэши-цели очищаются полностью — как до 1.2.0 |
| `-y` `--yes` | выкл. | Автоподтверждение восстанавливаемых кэшей. Действует только с `--all-safe`. **Режимы для личных данных его игнорируют** |
| `--no-report` | выкл. | Не создаёт JSON. Журналы всё равно пишутся |
| `--cleanup-logs` | выкл. | Удаляет журнал этого запуска в конце. **Записи сохраняются всегда** |
| `-n` `--dry-run` | выкл. | Проходит выбранный режим, не удаляя файлов и не меняя настроек. Остаётся локальный журнал; JSON-отчёт о сеансе не пишется |
| `--json-events` | выкл. | [Машиночитаемые события](./json-events.md) в stdout для `--scan` или `--all-safe --yes`; текст для людей идёт в stderr |
| `--no-color` | выкл. | Отключает цвет ANSI. `NO_COLOR` тоже учитывается |
| `-h` `--help` | — | Печатает справку и выходит |

:::danger `--purge-all` снимает защитный барьер
Он отключает [порог простоя](../safety/guards.md#guard-2--the-staleness-gate), и кэши очищаются целиком независимо от того, когда ими пользовались. Вместе с ними уходят дорогие ресурсы — дистрибутивы Gradle wrapper, браузеры Playwright, бинарные файлы Cypress. Баннер перед запуском показывает, какая стратегия включена.
:::

:::note Сканирование и пробный запуск отвечают на разные вопросы
[`--scan`](../modes/scan.md) читает текущие пути и размеры. `--dry-run` проходит выбранную очистку и показывает предлагаемые действия без удаления. См. [Предпросмотр перед удалением](../safety/preview-first.md).
:::

## Готовые команды {#recipes}

| Цель | Команда |
|---|---|
| Проверить установку | `linux-cleanup --self-test` |
| Узнать, сколько можно освободить | `linux-cleanup --scan` |
| Предпросмотр выбранной очистки кэшей | `linux-cleanup --all-safe --dry-run` |
| Выдать сканирование только для чтения как поток JSON-событий | `linux-cleanup --scan --json-events` |
| Увидеть все пути, которых он может коснуться | `linux-cleanup --list-targets` |
| Пошаговая очистка | `linux-cleanup` |
| Один пакетный проход без вопросов | `linux-cleanup --all-safe -y` |
| Агрессивная чистка | `linux-cleanup --all-safe -y -d 30` |
| Максимум места перед переустановкой | `linux-cleanup --all-safe -y --purge-all` |
| Визуальное меню | `linux-cleanup --tui` |
| Каталоги зависимостей старых проектов | `linux-cleanup --node-modules -d 90` |
| Обслуживание системы | `linux-cleanup --system` |
| Еженедельная автоматизация | `linux-cleanup --install-cron` |
| Преобразовать последнюю запись в HTML | `linux-cleanup --export html latest` |
| Сообщить об ошибке | `linux-cleanup --debug-bundle && linux-cleanup --feedback` |

## Переменные окружения {#environment-variables}

Самые используемые; [полный список](./environment-variables.md) — отдельно:

| Переменная | Действие |
|---|---|
| `NO_COLOR` | Любое непустое значение отключает цвет |
| `LINUX_CLEANUP_LOG_DIR` | Переопределяет каталог журналов |
| `LINUX_CLEANUP_REPORTS_DIR` | Переопределяет каталог записей сеансов |
| `LINUX_CLEANUP_DATA_HOME` | Родитель для журналов, записей и пакетов обратной связи |

## Коды выхода {#exit-codes}

| Код | Значение |
|---|---|
| `0` | Чистый запуск |
| `2` | Ошибка разбора аргументов или режим, не поддерживаемый потоком событий |
| `3` | Старая версия, заблокированная записью о выпусках |
| `130` | Прервано через `Ctrl-C` |
| `143` | Завершён сигналом `SIGTERM` |
| другой | Неожиданно — пишется пакет сбоя |

Полная таблица и логика обработчика сбоев: [Коды выхода](./exit-codes.md).
