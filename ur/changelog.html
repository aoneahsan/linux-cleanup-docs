1.3.0 — 2026-05-10​

آخری نکھار والی ریلیز: ایک بصری مینو اور کریش کا خودکار ریکارڈ۔ کوئی نئی صفائی منطق نہیں؛ موجودہ حفاظتی اور غیر فعالیت کی رکاوٹیں ویسی ہی۔

شامل ہوا​

  • TUI موڈ (-t / --tui / -g / --gui) — whiptail یا dialog سے چلنے والا مینو۔ ہر انتخاب رن کے لیے عام CLI آؤٹ پٹ پر لوٹتا ہے، پھر مینو پر۔ دونوں ٹولز نہ ہوں تو ڈسٹرو کے مطابق انسٹال کی ہدایت کے ساتھ آرام سے CLI مینو پر لوٹتا ہے۔

  • کریش بنڈل کا خودکار ریکارڈ — ایک EXIT ٹریپ جو غیر متوقع غیر صفر ایگزٹ پر ~/.linux-cleanup/feedback/ میں ایک مکمل crash-<stamp>.tar.gz لکھتا ہے، جس میں سیشن لاگ، حالیہ ترین ریکارڈ اور سسٹم مینی فیسٹ ہوتا ہے، پھر ایک لائن دکھاتا ہے جو آپ ای میل کر سکتے ہیں۔

    صاف ایگزٹ، Ctrl-C (130)، SIGTERM (143) اور آرگیومنٹ کی خرابی کے ایگزٹ (2) پر نہیں بنتا۔ کوئی نیٹ ورک کال نہیں — بنڈل تب تک آپ کی مشین پر رہتا ہے جب تک آپ شیئر کرنا نہ چنیں۔

  • TUI کا About ڈائیلاگ، جس میں ورژن، رابطہ، لائسنس اور رازداری کا وعدہ ہے۔

تبدیل ہوا​

  • بینر اور سیشن خلاصہ اب tui موڈ میں بھی دبائے جاتے ہیں، تاکہ ڈائیلاگ اور لاگ آؤٹ پٹ آپس میں نہ ٹکرائیں۔

1.2.1 — 2026-05-10​

1.2.0 کی غیر فعالیت کی رکاوٹ کو ہر اس چیز تک بڑھاتا ہے جو دوبارہ بن سکنے والا کیش نہیں بلکہ ٹول ہے۔ ایسی چیزیں حذف کرنے کے لیے اب دونوں ضروری ہیں: کوئی فعال سافٹ ویئر اس پر منحصر نہ ہو، اور آپ نے اسے --days دنوں میں نہ چھوا ہو۔

تبدیل ہوا​

  • Android AVD — پہلے تصدیق پر ~/.android/avd پورا صاف ہوتا تھا۔ اب ہر *.avd فولڈر ایک اکائی کے طور پر جانچا جاتا ہے، اپنی ساتھ والی *.ini کے ساتھ، اور تبھی چھانٹا جاتا ہے جب پروفائل کی ہر فائل حد سے زیادہ غیر فعال ہو۔ حال میں استعمال ہونے والے ایمولیٹر پروفائلز پورے بچے رہتے ہیں۔
  • VS Code / Cursor کی پرانی پڑ چکی ایکسٹینشنز — "نیا ورژن موجود ہے" کی جانچ پہلی شرط پوری کرتی تھی؛ اب پرانے پڑ چکے فولڈر کو حد سے زیادہ غیر فعال بھی ہونا چاہیے۔ حال میں لوڈ ہونے والے پرانے ورژنز دکھائے جاتے ہیں مگر رکھے جاتے ہیں، ہر ورژن کے غیر فعال دنوں کے ساتھ۔
  • Flatpak صارف ڈیٹا — ~/.local/share/flatpak میں صارف کی سطح پر انسٹال ایپس ہوتی ہیں، صرف کیش نہیں۔ اب ماڈیول کسی بھی صارف سطح کی ایپ کے انسٹال ہونے پر اس درخت کو چھونے سے انکار کرتا ہے، اور پورے درخت کا حد سے زیادہ غیر فعال ہونا بھی مانگتا ہے۔ محفوظ راستے کے لیے flatpak uninstall --user --unused بتاتا ہے۔

شامل ہوا​

  • newest_access_age_days <path> — کسی پاتھ کے نیچے کہیں بھی سب سے تازہ atime/mtime کے بعد کے دن لوٹاتا ہے۔
  • prune_stale_units <root> <days> [glob] — ہر اوپری حصے کو ناقابلِ تقسیم سمجھتا ہے، تاکہ ادھوری چھانٹی حالت نہ بگاڑے۔

کیوں​

ایک صارف نے بتایا کہ 1.2.0 اب بھی Android AVD پورے صاف کرتا ہے، اور یہی دلیل ہر اس چیز پر لاگو ہونی چاہیے جو کیش نہیں بلکہ ٹول ہے: وہ سافٹ ویئر حذف نہ کریں جس پر کوئی دوسرا ٹول منحصر ہو، اور وہ سافٹ ویئر حذف نہ کریں جو صارف نے خود حال میں استعمال کیا۔

1.2.0 — 2026-05-10​

ڈیفالٹ حذف کی حکمت عملی صرف پرانی چیزوں کی بن گئی۔ ہدف کیش کے اندر کچھ بھی تب تک حذف نہیں ہوتا جب تک اس کی فائلیں — atime اور mtime دونوں — --days دنوں تک، ڈیفالٹ 100، اچھوتی نہ رہیں۔

تبدیل ہوا​

  • clean_target، ہر کیش ماڈیول کے پیچھے کا مشترکہ صاف کرنے والا، اب پورا صاف کرنے کے بجائے چھانٹتا ہے۔ یہ صرف حد پار کی فائلیں حذف کرتا ہے، پھر خالی فولڈرز صاف کرتا ہے۔ حال میں استعمال فائلیں بچتی ہیں اور فولڈر کا ڈھانچہ رہتا ہے تاکہ ٹولز اپنی ترتیب پاتے رہیں۔
  • --all-safe بھی ہر ہدف کو اسی طرح چھانٹتا ہے، اور اس کا خلاصہ ہر ہدف کے لیے خالی ہوئے اور رکھے گئے بائٹس بتاتا ہے۔
  • npm کیش صفائی غیر فعالیت کی رکاوٹ مانتی ہے، نہ کہ ہمیشہ npm cache clean --force چلاتی ہے، جو عمر کو مکمل نظرانداز کرتا تھا۔
  • رن سے پہلے کا بینر فعال حکمت عملی بتاتا ہے — "prune ≥Nd" یا "FULL PURGE"۔

شامل ہوا​

  • --purge-all 1.2.0 سے پہلے کا سب صاف کرنے والا رویہ واپس لاتا ہے، فائدے نقصان کے ساتھ دستاویز میں۔
  • prune_stale <root> <days> — ماڈیولز کے لیے ایک عوامی معاون جو محفوظ پاتھس رد کرتا ہے، صرف وہیں حذف کرتا ہے جہاں دونوں اوقات حد پار کریں، خالی فولڈرز صاف کرتا ہے، اور خالی ہوئے بائٹس بتاتا ہے۔

کیوں​

درست ہوا​

  • pnpm کے گلوبل پیکیجز صاف ہو رہے تھے۔ pnpm کنٹینٹ اسٹور کی صفائی کا ہدف ~/.local/share/pnpm (PNPM_HOME) تھا — جس میں گلوبل انسٹال پیکیجز، bin شمز اور pnpm setup سے آئی pnpm بائنری خود ہوتی ہے۔ اب یہ صرف ~/.local/share/pnpm/store کو ہدف بناتا ہے، جو دوبارہ بن سکنے والا مواد کے پتے والا کیش ہے۔

    اثر --all-safe، مینو کے آپشن 3، اسکین، واک تھرو اور --list-targets پر تھا۔

شامل ہوا — حفاظتی رکاوٹیں​

  • PROTECTED_EXACT — پیکیج مینیجرز کے انسٹال فولڈرز اور رن ٹائم ہوم پر بالکل ملان والی رکاوٹ: pnpm، npm، yarn، bun، deno، volta، nvm، fnm، cargo، rustup اور Go۔
  • PROTECTED_BASENAMES — ہر اس پاتھ کو رد کرتا ہے جس کا نام شیل-انٹ یا ہسٹری فائل ہو، چاہے وہ کہیں بھی ہو۔
  • --all-safe کے آغاز پر ایک جانچ جو کوئی محفوظ رن ٹائم فولڈر اہداف کی فہرست میں آنے پر BUG: پیغام کے ساتھ رک جاتی ہے، تاکہ خاموشی سے پرانی غلطی نہ لوٹے۔

شامل ہوا — bun اور deno​

  • bun: ~/.bun/install/cache پر کیش صفائی؛ ~/.bun/install/global محفوظ۔
  • deno: ~/.cache/deno پر کیش صفائی؛ ~/.deno/bin محفوظ۔
  • دونوں --all-safe، --scan اور گلوبل پیکیجز کی نئی جانچ سے جڑے۔

شامل ہوا — موڈز​

  • --globals — صرف پڑھنے والی جانچ جو npm، pnpm، yarn، bun اور deno سے سیدھے انسٹال گلوبل پیکیجز دکھاتی ہے، ہر ایک پر recently used، needed by: <pkg> یا STALE — safe to uninstall لگاتی ہے، اور کاپی کرنے لائق ان انسٹال کمانڈز دکھاتی ہے۔ کبھی کچھ حذف نہیں کرتی۔ پیکیج مینیجر کا CLI PATH پر نہ ہو تب بھی کام کرتی ہے۔
  • --doctor — ڈسک پر موجود مگر شیل-انٹ سے نہ جڑے رن ٹائمز (nvm، pnpm، bun، deno، cargo) پہچانتا ہے اور معیاری بلاک شامل کرنے کی پیشکش کرتا ہے۔ صرف شامل کرتا ہے، تصدیق کے ساتھ۔ موجودہ لائنیں کبھی حذف یا تبدیل نہیں کرتا۔

تبدیل ہوا​

  • --all-safe صاف طور پر "globals are PRESERVED" اور "shell-init files are NEVER touched" اطلاعات دکھاتا ہے۔

پہلی عوامی ریلیز۔

تقسیم​

  • npm پر شائع — npx linux-cleanup یا npm install -g linux-cleanup سے چلتا ہے۔ پیکیج میں ایک ہلکا Node لانچر ہے جو bash کا داخلی نقطہ ڈھونڈتا ہے اور لاگز و ریکارڈز کو ~/.linux-cleanup/ بھیجتا ہے تاکہ وہ npx کے عارضی فولڈر کے صاف ہونے سے بچے رہیں۔
  • سیدھا git clone بھی سپورٹ ہے، آؤٹ پٹ کلون کے اندر رہتا ہے۔

خصوصیات​

  • دس مراحل کا رہنمائی والا واک تھرو ڈیفالٹ موڈ کے طور پر، پیش رفت کے عنوانات، a / s / q سوالات، ہر مرحلے میں خالی ہوئے بائٹس اور جاری مجموعے کے ساتھ۔
  • اجازت فہرست پر مبنی حفاظت — چنی ہوئی محفوظ فہرست کے اندر کا ہر پاتھ رد، ساتھ میں اکیلا $HOME اور /۔
  • ذاتی ڈیٹا صرف انٹرایکٹو — کبھی ایک ساتھ نہیں، کبھی --yes سے نہیں۔
  • صفائی کے زمرے — پیکیج مینیجر کیش (yarn، npm، pnpm، pip، composer)؛ ایپ کیش (Chrome، Firefox، Brave، Chromium، Edge، Vivaldi، Gradle، Cypress، Playwright، TypeScript، Zoom)؛ ڈیولپر ٹولز (Android AVD، pub-cache، Dart، flatpak)؛ ایڈیٹر ایکسٹینشنز؛ پرانے node_modules؛ ادھورے ڈاؤن لوڈز اور پرانی ذاتی فائلیں؛ sudo کے ساتھ سسٹم صفائی۔
  • سیشن ریکارڈز — ہر رن میں معیاری JSON، مانگنے پر Markdown اور HTML ایکسپورٹ۔ HTML ڈارک موڈ سمجھنے والی اندرونی CSS استعمال کرتا ہے۔
  • رپورٹس مینیجر (--reports) اور غیر انٹرایکٹو --export FMT ID۔
  • خود جانچ (--self-test) انحصار، ہر شیل فائل کا سنٹیکس اور حفاظتی رکاوٹوں کی درستی جانچتا ہے — تصدیق کرتا ہے کہ /، $HOME، ~/Documents اور /etc کی حفاظت true لوٹائے۔
  • --feedback اور --debug-bundle منظم خرابی رپورٹس کے لیے۔
  • رازداری — صفر نیٹ ورک کالز۔ کوئی ٹیلی میٹری، اینالیٹکس یا کریش رپورٹنگ نہیں۔ آپ کی مشین سے باہر جانے والا واحد ڈیٹا وہی ہے جو آپ ای میل کرنا چنیں۔
  • ہر چیز پر حوالہ — لاگز اپنا ماخذ بتانے والے عنوان سے شروع ہوتے ہیں، ریکارڈز میں اوپری credits بلاک ہے، HTML آؤٹ پٹ کے فوٹر میں حوالہ ہے۔
  • سیٹ اپ معاون — --install-alias، --install-cron اور ان کے ان انسٹال والے ساتھی۔
  • NO_COLOR سپورٹ اور --no-color۔

حفاظت اور مضبوطی​

  • HTML آؤٹ پٹ JSON سے آئی ہر قدر کو jq کے @html فلٹر سے ایسکیپ کرتا ہے، تاکہ خراب ریکارڈ سے انجیکشن نہ ہو۔
  • ہر اختیاری انحصار (snap، crontab، xdg-open، jq) پر command -v جانچ۔
  • realpath -m کسی بھی محفوظ پاتھ کی جانچ سے پہلے سملنکس حل کرتا ہے، تاکہ سملنک اجازت فہرست سے بچ نہ سکے۔
