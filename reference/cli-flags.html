CLI flags

Every flag linux-cleanup accepts. Modes are mutually exclusive — pass one. Options combine with any mode.

linux-cleanup --help    # the same list, with your machine's real paths inlined

An unrecognised flag prints the help text and exits with code 2.

Pass at most one. With none, you get the walkthrough.

Options​

FlagDefaultEffect
-d N --days N100Staleness threshold. A file is eligible only when both atime and mtime exceed it. Lower is more aggressive
--purge-alloffDisables the staleness gate. Cache targets are wiped in full — pre-1.2.0 behaviour
-y --yesoffAuto-confirm regenerable caches. Valid only with --all-safe. Personal modes ignore it
--no-reportoffSkip JSON generation. Logs are still written
--cleanup-logsoffDelete this run's log at the end. Records are always kept
-n --dry-runoffWalk the selected mode without deleting files or changing settings. A local log remains; no JSON session report is written
--json-eventsoffVersion 1 NDJSON on stdout for --scan or --all-safe --yes; human text goes to stderr
--no-coloroffDisable ANSI colour. NO_COLOR is honoured too
-h --help—Print help and exit
--purge-all removes a safety guard

It turns off the staleness gate, so caches are wiped whole regardless of when they were last used. Expensive assets — Gradle wrapper distributions, Playwright browsers, Cypress binaries — go with them. The pre-run banner states which strategy is active.

Scan and dry run answer different questions

--scan reads the current paths and sizes. --dry-run walks the selected cleanup and shows proposed actions without deletion. See Preview before deleting.
