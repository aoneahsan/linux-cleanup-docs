Added `--dry-run`, a public release-record check on start, and `--refresh-app` for the persistent CLI copy.

<!-- truncate -->

Normal release notices allow the first run and block from the next start; urgent notices block an older copy at
once. Offline runs continue. A dry run does not remove cleanup targets or change settings, though it may write a
local log and update-check state. Read the [changelog](/changelog) for the full entry.
