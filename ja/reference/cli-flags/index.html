CLI のフラグ

linux-cleanup が受け付けるすべてのフラグです。 モードは同時に使えないので 1 つだけ渡してください。オプションはどのモードとも組み合わせられます。

linux-cleanup --help    # 同じ一覧を、あなたのマシンの実際のパスで表示

認識できないフラグはヘルプを表示し、コード 2 で終了します。

モード​

渡すのは 1 つまでです。何も渡さなければガイド付きの手順になります。

フラグ別名働き詳しいページ
（なし）-w --walkthrough10 の手順を案内し、各手順の前に確認するガイド付きの手順
-m--menu -i --interactive番号で直接移動できるメニューメニュー
-t--tui -g --guiwhiptail / dialog の画面メニューTUI
-a--all-safe作り直せるキャッシュをまとめて掃除完全安全
-s--scanすべての分類を読み取りのみで監査スキャン
-p--stale大きく使われていない個人ファイル（対話式）使われていない個人ファイル
--systemapt、ジャーナル、snap、/tmp、ページキャッシュ（sudo）システムのクリーンアップ
--partials取り残された途中のダウンロード（対話式）途中の・持ち主のないダウンロード
--audit$HOME の大きいもの上位 20 件ホームの監査
--node-modules使われていない node_modules（対話式）使われていない node_modules の検出
--globalsグローバルパッケージを読み取りのみで監査グローバルパッケージの監査
--doctorランタイムに足りないシェルの初期化を修復Doctor
--speed負荷と起動時の処理を調べ、変更の前に確認する速度の診断
--editor-ext置き換え済みの VS Code / Cursor のバージョンエディター拡張機能
--reportsセッション記録の対話式の管理レポート
--export FMT ID記録の対話なしの変換レポート
--feedback不具合報告の案内と、任意の mailto の下書き不具合を報告する
--debug-bundle最新のログと記録を tar.gz にまとめる不具合を報告する
--list-targets対象にできるパスと保護パスをすべて表示削除前のプレビュー
--self-test依存関係、構文、安全の関門を確認削除前のプレビュー
-V--versionバージョンと作者—
--install-aliasシェルのエイリアス cleanup を追加シェルのエイリアスと毎週の cron
--install-cron毎週日曜 03:00 に --all-safe -yシェルのエイリアスと毎週の cron
--uninstall-aliasエイリアスを削除アンインストール
--uninstall-croncron の行を削除アンインストール
--refresh-appエイリアスと cron が使う常設のコピーを更新インストール

オプション​

フラグ既定値効果
-d N --days N100アイドルのしきい値。atime と mtime の両方がこれを超えたファイルだけが対象です。小さいほど積極的になります
--purge-allオフアイドルの関門を無効にします。 対象のキャッシュを丸ごと消します（1.2.0 より前の動き）
-y --yesオフ作り直せるキャッシュを自動で承認します。--all-safe と一緒のときだけ有効です。個人データのモードは無視します
--no-reportオフJSON を作りません。ログは書き出します
--cleanup-logsオフ終了時にその回のログを削除します。記録は必ず残します
-n --dry-runオフ選んだモードをたどりますが、ファイルの削除も設定の変更もしません。ローカルのログは残り、JSON のセッションレポートは書きません
--json-eventsオフ--scan か --all-safe --yes のとき、stdout に 機械で読めるイベント を出します。人が読むテキストは stderr に出します
--no-colorオフANSI の色を消します。NO_COLOR にも従います
-h --help—ヘルプを表示して終了
--purge-all は安全の関門を 1 つ外します

アイドルの関門を無効にするので、最後にいつ使ったかに関係なくキャッシュを丸ごと消します。Gradle wrapper の配布物、Playwright のブラウザー、Cypress のバイナリなど、取り直しに手間のかかるものも一緒に消えます。実行前の表示で、どの方針が有効かがわかります。

スキャンとドライランは答える問いが違います

--scan は現在のパスとサイズを読み取ります。--dry-run は選んだクリーンアップをたどり、削除せずに予定の操作を表示します。削除前のプレビューを参照。

よく使う組み合わせ​

目的コマンド
インストールを確認するlinux-cleanup --self-test
取り戻せる容量を見るlinux-cleanup --scan
選んだキャッシュの掃除をプレビューするlinux-cleanup --all-safe --dry-run
読み取りのみのスキャンを JSON イベントで出すlinux-cleanup --scan --json-events
触れる可能性のあるパスをすべて見るlinux-cleanup --list-targets
ガイド付きで掃除するlinux-cleanup
確認なしで一度にまとめて掃除するlinux-cleanup --all-safe -y
積極的に掃除するlinux-cleanup --all-safe -y -d 30
入れ直す前にできるだけ取り戻すlinux-cleanup --all-safe -y --purge-all
画面メニューlinux-cleanup --tui
古いプロジェクトの依存関係のディレクトリlinux-cleanup --node-modules -d 90
システムの保守linux-cleanup --system
毎週の自動実行linux-cleanup --install-cron
最新の記録を HTML に変換するlinux-cleanup --export html latest
不具合を報告するlinux-cleanup --debug-bundle && linux-cleanup --feedback

環境変数​

よく使うものです。一覧は別ページにあります。

変数効果
NO_COLOR空でない値なら何でも色を消す
LINUX_CLEANUP_LOG_DIRログのディレクトリを上書き
LINUX_CLEANUP_REPORTS_DIRセッション記録のディレクトリを上書き
LINUX_CLEANUP_DATA_HOMEログ、記録、フィードバック用バンドルの親

終了コード​

コード意味
0正常に終了
2引数の解析エラー、またはイベント出力に対応していないモード
3リリース記録で止められた古いバージョン
130Ctrl-C で中断
143SIGTERM で終了
その他予期しない終了 — クラッシュ用バンドルを書く

一覧とクラッシュ時の処理のしくみ：終了コード。
