# Compare Linux cleaners

Ten tools that clean space on a Linux computer, each described from its own website or repository and
dated. A fact their pages do not state is written as "Not stated on the pages we checked", never as a no.
Links to other projects open in a new tab and carry `nofollow`.

*Last checked 2026-11-14.*

| Tool | What it is | Checked |
|---|---|---|
| [BleachBit](./bleachbit.md) | An open-source cleaner for disk space and privacy, with a graphical preview and CLI. | 2026-11-10 |
| [Stacer](./stacer.md) | A Linux system monitor and optimizer with a system cleaner. | 2026-11-10 |
| [Sweeper](./sweeper.md) | A KDE utility for clearing cookies, caches and other user traces. | 2026-11-10 |
| [Cross Cleaner](./cross-cleaner.md) | A cross-platform cleaner with window, terminal and command-line editions. | 2026-11-10 |
| [CleanMate](./cleanmate.md) | A macOS and Ubuntu cleaner with a desktop app, terminal app and review-before-removal flow. | 2026-11-10 |
| [TuxCleaner](./tuxcleaner.md) | A Linux CLI for cleanup, app uninstall, disk analysis and status. | 2026-11-10 |
| [Ubuntu Cleaner](./ubuntu-cleaner.md) | A Bash cleaner for Ubuntu, Debian and Linux Mint with package and developer-cache maintenance. | 2026-11-10 |
| [Disk Cleaner](./disk-cleaner.md) | A Linux GTK cleaner with disk visualizations and suggested cleanup tasks. | 2026-11-10 |
| [Czkawka](./czkawka.md) | A file-finding utility for duplicates, empty folders, similar media and other clutter. | 2026-11-10 |
| [Safe Disk Cleaner](./safe-disk-cleaner.md) | A GTK 4 app that explains disk categories and asks before deletion. | 2026-11-10 |
